Po dodaniu konta GitHub lub GitLab (zobacz [GitHub](/pl/docs/github/) i [GitLab](/pl/docs/gitlab/)) pasek boczny wyświetla pull requesty repozytorium (w GitLab: merge requesty).

![Pasek boczny z pull requestem i uruchomieniami GitHub Actions](/shots/actions-light.png)

## Tworzenie pull requesta

- **Repozytorium ▸ GitHub / GitLab ▸ Utwórz pull request…** dla bieżącej gałęzi.
- Albo upuść gałąź na inną gałąź w grafie.

Przycisk ▾ obok pól Recenzenci, Przypisani i Etykiety pozwala wybierać z list repozytorium. Gdy AI jest włączone, GitLoom może napisać opis (zobacz [Wybór dostawcy](/pl/docs/choosing-a-provider/)).

## Przegląd

Otwórz pull request, aby zobaczyć jego diff. Możesz komentować linie, zatwierdzać i scalać. W diffie *Odpowiedz* odpowiada w wątku przeglądu, a *Rozwiąż* go zamyka.

Komentarze do linii nie są jeszcze dostępne dla GitLab.

## Launchpad

**Launchpad** (<kbd>⇧⌘K</kbd>) wyświetla pull requesty i zgłoszenia czekające na Ciebie we wszystkich repozytoriach i kontach. Kliknij element prawym przyciskiem, aby otworzyć jego repozytorium, otworzyć go w przeglądarce lub odłożyć: na 1 godzinę, do jutra, do przyszłego tygodnia albo do czasu, aż się zmieni.
