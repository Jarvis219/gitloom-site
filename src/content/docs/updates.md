GitLoom checks for updates in the background. Updates are signed, and GitLoom only installs one whose signature it can verify.

## Check now

Choose **GitLoom ▸ Check for Updates…** at any time.

## Settings

The **Updates** section of **Settings ▸ General** has:

- *Check for updates automatically*, and how often: hourly, daily or weekly.
- *Download and install updates when quitting*.
- *Channel*: Stable or Beta.
- *Release Notes* and *Version History…*, and *Check Now*.

## Updates wait for your work

GitLoom waits to install an update while a clone, push, pull or commit is running, or while a file in the editor has unsaved changes. Settings then says the update is ready and will install when that work finishes. When the work can be cancelled, *Cancel It and Install Now* does that.
