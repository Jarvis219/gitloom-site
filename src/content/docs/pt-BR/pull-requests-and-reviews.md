Com uma conta do GitHub ou do GitLab adicionada (veja [GitHub](/pt-br/docs/github/) e [GitLab](/pt-br/docs/gitlab/)), a barra lateral lista as pull requests do repositório (merge requests no GitLab).

![A barra lateral com uma pull request e execuções do GitHub Actions](/shots/actions-light.png)

## Criar uma pull request

- **Repositório ▸ GitHub / GitLab ▸ Criar Pull Request…** para a branch atual.
- Ou solte uma branch sobre outra no grafo.

O ▾ ao lado de Revisores, Responsáveis e Rótulos escolhe nas listas do repositório. Com a IA ativada, o GitLoom pode escrever a descrição (veja [Escolher um provedor](/pt-br/docs/choosing-a-provider/)).

## Revisar

Abra uma pull request para ver o diff. Você pode comentar em linhas, aprovar e fazer merge. No diff, *Responder* responde numa conversa de revisão e *Resolver* a encerra.

Comentários em linhas ainda não estão disponíveis para o GitLab.

## Launchpad

O **Launchpad** (<kbd>⇧⌘K</kbd>) lista as pull requests e issues que esperam por você em todos os repositórios e contas. Clique com o botão direito num item para abrir o repositório dele ou abri-lo no navegador, ou para adiá-lo: por 1 hora, até amanhã, até a próxima semana ou até ele mudar.
