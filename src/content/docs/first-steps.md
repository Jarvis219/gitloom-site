Once GitLoom is installed, open a repository you already have or clone one. Everything GitLoom does is the same as the matching `git` command, so you can switch to the terminal at any moment.

## Open a repository

Drag the repository's folder onto the GitLoom window, or pick it from the start page or the recent list. <kbd>⌘O</kbd> opens a repository too; if the current tab already shows one, it opens in a new tab.

## Clone a repository

Press <kbd>⇧⌘C</kbd> and paste any URL. Once you have added a GitHub or GitLab account (see [GitHub](/docs/github/) and [GitLab](/docs/gitlab/)), you can also pick from your account's repositories.

## Tabs

Each repository opens in its own tab. <kbd>⌘T</kbd> opens a new tab and <kbd>⌃⇥</kbd> moves to the next one. Your tabs come back the next time you start GitLoom. To change that, use *At launch* in **Settings ▸ General**: reopen the last tabs, ask first, or start with no repository open.

## Your name and email

If git has no `user.name` or `user.email` yet, GitLoom asks for them before your first commit. If you use different identities for different kinds of work, set up [Profiles](/docs/profiles/).
