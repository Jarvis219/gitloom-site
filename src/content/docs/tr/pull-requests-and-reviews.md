Bir GitHub veya GitLab hesabı eklendiğinde (bkz. [GitHub](/tr/docs/github/) ve [GitLab](/tr/docs/gitlab/)) kenar çubuğu deponun pull request’lerini (GitLab’da merge request’ler) listeler.

![Bir pull request ve GitHub Actions çalıştırmalarının bulunduğu kenar çubuğu](/shots/actions-light.png)

## Pull request oluşturma

- Geçerli dal için **Depo ▸ GitHub / GitLab ▸ Pull Request Oluştur…**.
- Ya da grafikte bir dalı başka bir dalın üzerine bırak.

İnceleyenler, Atananlar ve Etiketler yanındaki ▾, deponun listelerinden seçim yapar. YZ açıkken GitLoom açıklamayı yazabilir (bkz. [Sağlayıcı seçme](/tr/docs/choosing-a-provider/)).

## İnceleme

Farkını görmek için bir pull request aç. Satırlara yorum yapabilir, onaylayabilir ve birleştirebilirsin. Farkta *Yanıtla* bir inceleme dizisinde yanıt verir, *Çöz* diziyi kapatır.

Satır yorumları GitLab için henüz kullanılamaz.

## Launchpad

**Launchpad** (<kbd>⇧⌘K</kbd>), depolar ve hesaplar genelinde seni bekleyen pull request’leri ve issue’ları listeler. Bir öğeye sağ tıklayarak deposunu açabilir, tarayıcıda açabilir veya erteleyebilirsin: 1 saatliğine, yarına kadar, gelecek haftaya kadar veya değişene kadar.
