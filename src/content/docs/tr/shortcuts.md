✎ ile işaretlenmiş 35 kısayolun tamamı menü çubuğundadır ve **Ayarlar ▸ Klavye** bölümünden değiştirilebilir. Diğerleri (<kbd>⌘W</kbd> ve <kbd>⌘Z</kbd> gibi sistem kısayolları ile yalnızca bir sayfa veya düzenleyici içinde çalışan tuşlar) sabittir. Menü her zaman geçerli tuşu gösterir ve buradaki her şey komut paletinde de (<kbd>⌘K</kbd>) bulunur.

## Her yerde

| Tuşlar | İşlem |
|---|---|
| <kbd>⌘K</kbd> ✎ | Komut paleti: `>` komutlar, `/` dosyalar, `:` işlemeler, `@` yazarlar, `#` pull request’ler ve issue’lar |
| <kbd>⌘P</kbd> ✎ | Deponun bir dosyasını Hızlı Aç |
| <kbd>⌘F</kbd> / <kbd>⌘G</kbd> / <kbd>⇧⌘G</kbd> ✎ | İşleme bul / sonraki eşleşme / önceki eşleşme |
| <kbd>⌘Z</kbd> / <kbd>⇧⌘Z</kbd> | Son Git işlemini geri al / yinele (bir metin alanında: yazmayı geri al) |
| <kbd>⌘T</kbd> ✎ | Yeni sekme |
| <kbd>⌘W</kbd> | Sekmeyi kapat |
| <kbd>⌃⇥</kbd> / <kbd>⌃⇧⇥</kbd> ✎ | Sonraki / önceki sekme |
| <kbd>⇧⌘C</kbd> ✎ | Depo klonla |
| <kbd>⌘O</kbd> ✎ | Depo aç (bu sekme zaten bir depo gösteriyorsa yeni sekmede) |
| <kbd>⇧⌘R</kbd> ✎ | Depoyu Finder’da göster |
| <kbd>⌥⌘T</kbd> ✎ | Depoyu terminal uygulamanda aç |
| <kbd>⇧⌘K</kbd> | Launchpad (GitHub ve GitLab hesaplarının pull request’leri ve issue’ları) |
| <kbd>⌥⇧⌘L</kbd> ✎ | Git Günlüğü (GitLoom’un çalıştırdığı her git komutu) |
| <kbd>⌘,</kbd> | Ayarlar |
| <kbd>⌘?</kbd> | GitLoom Yardım |

## Grafik, değişiklikler ve fark

| Tuşlar | İşlem |
|---|---|
| <kbd>↑</kbd> <kbd>↓</kbd> veya <kbd>J</kbd> <kbd>K</kbd> | Önceki / sonraki işleme |
| <kbd>⇧</kbd> ile tıklama, <kbd>⌘</kbd> ile tıklama | Aralık / birkaç işleme seç (karşılaştırma, squash, cherry-pick) |
| <kbd>⌘C</kbd> | Seçili işlemenin SHA’sını kopyala |
| <kbd>⌘Y</kbd> | Seçili dosyaya Hızlı Bakış |
| <kbd>⇧⌘A</kbd> | Tümünü hazırla |
| <kbd>⌥⇧⌘A</kbd> | Tümünü hazırlıktan çıkar |
| <kbd>⌘↩</kbd> | İşle (işleme iletisinde) |
| <kbd>⌥⌘G</kbd> | İşleme iletisini YZ ile yaz (YZ açıkken) |
| <kbd>⌥↑</kbd> / <kbd>⌥↓</kbd> | Dosyadaki önceki / sonraki değişiklik |
| <kbd>⌥⌘↑</kbd> / <kbd>⌥⌘↓</kbd> | Önceki / sonraki dosya |

## Düzenleyiciler

|---|---|
| <kbd>⌘E</kbd> ✎ | Açık dosyayı düzenle |
| <kbd>⌘S</kbd> ✎ | Kaydet |
| <kbd>⌥⌘S</kbd> ✎ | Kaydet ve hazırla |
| <kbd>⌘L</kbd> ✎ | Satıra git |
| <kbd>⌥⌘F</kbd> ✎ | Bul ve değiştir |
| <kbd>⌘/</kbd> ✎ | Seçili satırları yorum yap veya yorumu kaldır |
| <kbd>⌘]</kbd> / <kbd>⌘[</kbd> ✎ | Seçili satırların girintisini artır / azalt |
| <kbd>P</kbd> <kbd>R</kbd> <kbd>E</kbd> <kbd>S</kbd> <kbd>F</kbd> <kbd>C</kbd> <kbd>D</kbd> | Etkileşimli yeniden temellendirme: seçili satırlar için pick, reword, edit, squash, fixup, fixup -C, drop |
| <kbd>⌥↑</kbd> / <kbd>⌥↓</kbd> | Etkileşimli yeniden temellendirme: seçili satırları taşı (*Birleştirmeleri koru* ile yalnızca kendi dalları içinde) |
| <kbd>⌘Z</kbd> / <kbd>⇧⌘Z</kbd> | Etkileşimli yeniden temellendirme: plandaki bir değişikliği geri al / yinele (sen başlatana kadar git’e dokunulmaz) |
| <kbd>⌘↩</kbd> | Etkileşimli yeniden temellendirme: yeniden temellendirmeyi başlat (veya kalan planı kaydet) |
| Esc | Etkileşimli yeniden temellendirme: hiçbir şey yapmadan düzenleyiciyi kapat |
| <kbd>⌥⌘↑</kbd> / <kbd>⌥⌘↓</kbd> | Birleştirme çakışmaları: önceki / sonraki çakışma |
| <kbd>⌘S</kbd> | Birleştirme çakışmaları: kaydet ve dosyayı çözüldü olarak işaretle |
| <kbd>⌘[</kbd> / <kbd>⌘]</kbd> | Dosya geçmişi: geri / ileri |

## Terminal

| Tuşlar | İşlem |
|---|---|
| <kbd>⌃`</kbd> ✎ | Terminali göster veya gizle (odaktayken gizler) |
| <kbd>⌃⇧`</kbd> ✎ | Yeni terminal oturumu |
| <kbd>⌘+</kbd> / <kbd>⌘−</kbd> ✎ | Daha büyük / daha küçük terminal metni |
| <kbd>⇥</kbd> veya <kbd>→</kbd> | Seçili öneriyi ekle |
| <kbd>↑</kbd> <kbd>↓</kbd> | Bir öneri seç |
| Esc | Önerileri kapat; boş bir istemde grafiğe geri dön (terminali gizlemek de aynısını yapar) |
| <kbd>⌘</kbd> ile tıklama | İmlecin altındakini aç: bir SHA işlemeyi seçer, bir yol dosyayı açar, bir URL tarayıcıyı açar |
