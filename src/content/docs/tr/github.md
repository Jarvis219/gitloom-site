GitLoom’da pull request’leri, issue’ları, Launchpad’i ve Actions’ı kullanmak için GitHub’da oturum aç.

## Oturum açma

**Ayarlar ▸ Barındırma** bölümünü aç ve *GitHub ile Oturum Aç…* düğmesini tıkla. *Kod Al* sana bir kod verir; *Kodu Kopyala ve GitHub Aç* onu kopyalar ve kodu gireceğin sayfayı açar.

*Token Ekle…* ile ayrıntılı (fine-grained) veya klasik bir kişisel erişim token’ı da yapıştırabilirsin. GitLoom görebildiği kapsamları denetler.

Token’lar yalnızca macOS Anahtar Zinciri’nde tutulur.

## Neler yapabilirsin

- [Pull request’ler](/tr/docs/pull-requests-and-reviews/) oluştur, incele ve birleştir.
- [Issue’lar](/tr/docs/issues/) oluştur ve göz at.
- GitHub [Actions](/tr/docs/actions/) çalıştırmalarını işlemelerinin yanında gör.
- **Launchpad** (<kbd>⇧⌘K</kbd>), depolar genelinde seni bekleyen pull request’leri ve issue’ları listeler.
- **Pencere ▸ Kuruluşlar**, kuruluşlarını, ekiplerini ve üyelerini gösterir.
- **Depo ▸ GitHub / GitLab** menüsünde, depoyu GitHub’da oluşturan, `origin` olarak ekleyen ve geçerli dalı iten *Depoyu Yayımla…* ile *GitHub Üzerinde Fork Oluştur* bulunur.
- Hesaplarından ve kuruluşlarından klonla: <kbd>⇧⌘C</kbd> ▸ *Hesabınızdan Seçin…*.

## İşleme e-postan

Bir işlemeden önce GitLoom, e-posta GitHub hesabının e-postalarından biri değilse uyarır; çünkü GitHub işlemeyi seninle ilişkilendirmez.

## SSH anahtarları

Oturum açmak API içindir. Hangi oturum için hangi SSH anahtarının iteceği [SSH hesapları](/tr/docs/ssh-accounts/) bölümünde ayarlanır. **Ayarlar ▸ Barındırma** içindeki bir hesabın *SSH Anahtarları…* öğesi GitHub’daki anahtarları gösterir ve seninkini yükleyebilir.
