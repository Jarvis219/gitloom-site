當合併、重定基底、揀選或拉取遇到衝突時，操作會暫停，並有一條橫幅說明目前的情況。有衝突的檔案會列在詳情面板中。

![三方衝突編輯器，顯示你這一方、對方和結果](/shots/conflict-light.png)

## 合併編輯器

打開有衝突的檔案即可進入三方合併編輯器：你這一方、對方和結果。

- 逐個衝突或逐行選擇一方。
- 直接編輯結果。
- <kbd>⌥⌘↑</kbd> 和 <kbd>⌥⌘↓</kbd> 在衝突之間移動。
- 勾選*整個檔案*，即可將每一方顯示為含有衝突的完整檔案。各欄會對齊並同步捲動。

檔案無誤後，按一下*儲存並標記為已解決*（<kbd>⌘S</kbd>）。

## 特殊情況

- 由重新命名引起的衝突（兩方都重新命名，或一方重新命名而另一方刪除）會註明這一點。
- 二進位檔案可以在選擇前預覽兩方的內容。
- 當兩方只在行尾字元（CRLF / LF）上不同時，會有橫幅提醒。

## 你自己的合併工具

你也可以在外部合併工具中打開檔案。GitLoom 使用 git 的 `merge.tool`，或你在 **設定 ▸ 整合 ▸ 合併工具** 中選擇的工具。

## 完成或停止

所有檔案都解決後，按一下橫幅中的*繼續*。*跳過*會跳過重定基底或揀選中的目前提交；*中止*會讓一切恢復原狀。停在重定基底或合併途中的存放庫，在重新啟動 GitLoom 後仍會顯示該橫幅。
