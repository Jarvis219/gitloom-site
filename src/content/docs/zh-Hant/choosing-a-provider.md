AI 功能預設為關閉。開啟後，你可以選擇由誰來回答：使用你自己金鑰的雲端供應商，或在你的 Mac 上執行的模型。

## 開啟

打開 **設定 ▸ AI**，開啟*AI 功能*。GitLoom 會先說明將傳送什麼、傳送給誰。

選擇*供應商*：

- Anthropic、OpenAI、Google Gemini、OpenRouter、Groq、Mistral、DeepSeek、Qwen（阿里雲）、xAI 或 Together AI；
- 在本機執行的 Ollama 或 LM Studio，資料不會離開你的 Mac；
- 自訂供應商：任何支援 Anthropic、OpenAI、Gemini 或 Ollama API 的伺服器，例如公司閘道。用*新增自訂供應商…* 加入。

貼上你的 API 金鑰並按一下*儲存金鑰*。金鑰儲存在鑰匙圈中。*測試* 會檢查金鑰並載入供應商的模型，讓你選擇。

## AI 能做什麼

- 撰寫提交訊息（<kbd>⌥⌘G</kbd>）、拉取請求描述和儲藏訊息。
- 解釋一個提交、一個分支或你的更改，並可繼續追問。
- 建議衝突的解決方式。

在你提出要求之前，不會傳送任何內容。沒有網路時，✨ 按鈕會變暗；本機模型仍然可用。

## 調整寫作

在*寫入*下，選擇語言（English 或 Tiếng Việt）和提交風格：Conventional Commits、仿照存放庫歷史，或自由格式。

*顯示按功能的設定* 讓每個功能擁有自己的模型和*自訂指令*。旁邊的**範本**選單會填入現成的設定，例如 Conventional Commits、從分支名稱取得工單 ID、拉取請求大綱或只看錯誤的審查，你可以再依團隊需求調整。

## 為某個存放庫關閉

從提交訊息旁的 ✨ 選單中選擇*為此存放庫關閉 AI*。在 **設定 ▸ AI ▸ 已關閉 AI 的存放庫** 中重新開啟。

在傳送任何內容之前，你都可以查看確切的請求。請參閱[傳送哪些內容](/zh-hant/docs/what-gets-sent/)。
