GitLoom 同時使用一個淺色主題和一個深色主題。在 **設定 ▸ 外觀** 中選擇它們。

## 淺色和深色

*模式* 跟隨系統，或始終淺色、始終深色。選擇一個*淺色主題*和一個*深色主題*。內建主題有 Loom Paper 和 Loom Midnight（預設）、System Light 和 Dark、High Contrast Light 和 Dark，以及 Solarized 風格的 Light 和 Dark。一個小預覽會用所選顏色顯示提交圖和一段差異。

## 更容易分辨的顏色

- *差異顏色*：依主題（綠/紅）或藍/橙。
- *提交圖泳道*：依主題、色盲友善或單色。

當主題的文字與背景對比不足時，GitLoom 會發出警告。

## 製作或匯入主題

這些按鈕作用於目前使用的主題：

- *編輯…* 打開主題編輯器。內建主題會先被複製一份。
- *複製* 建立一個延伸此主題的新主題檔案。
- *匯入…* 支援 `.gitloomtheme`、VS Code `.json`、iTerm2 `.itermcolors`、Ghostty 和 Alacritty 主題。
- *匯出…* 將主題儲存為 `.gitloomtheme` 檔案。
- *開啟主題資料夾* 顯示你的主題所在的位置。

主題檔案也可以在任何編輯器中編輯；一儲存，GitLoom 就會套用。

## 更多外觀設定

同一個標籤頁中還有介面*文字大小*（小、中或大）、*強調色*、半透明側邊欄、Dock 圖像（預設、深色或經典）、大頭貼、日期，以及差異、檔案編輯器、合併編輯器和終端機所用的程式碼字體和大小。
