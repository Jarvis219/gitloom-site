選取*未提交的更改*列，暫存你想要的內容（請參閱[逐行暫存](/zh-hant/docs/staging-single-lines/)），撰寫訊息，然後按 <kbd>⌘↩</kbd>。

## 提交表單

- *修補* 會更改上一個提交，而不是建立新的提交。勾選時，該提交已更改的檔案也會列出。
- *共同作者* 會建議最近歷史中的人，包括你之前加入過的共同作者。
- 提交執行時，掛鉤輸出的內容（`pre-commit` 程式碼檢查、測試）會顯示在訊息下方。如果某個掛鉤一分鐘後仍在執行，GitLoom 會告訴你並提供*停止*。
- 有一行會顯示你將以誰的身分提交。當電子郵件與存放庫的[設定檔](/zh-hant/docs/profiles/)不符，或不是你 GitHub 帳號的電子郵件之一時（GitHub 將無法把該提交連結到你），它會發出警告。

開啟 AI 後，<kbd>⌥⌘G</kbd> 會為你撰寫提交訊息（請參閱[選擇供應商](/zh-hant/docs/choosing-a-provider/)）。

## 提交訊息設定

在 **設定 ▸ Git ▸ 提交訊息** 中，你可以設定表單的起始範本，以及摘要長度達到多少時計數器變成黃色和紅色（預設為 50 和 72 個字元）。它只會警告，不會截斷任何內容。存放庫自己的 `commit.template` 優先於該範本。

## git 不顯示的檔案

- 對一個已被追蹤的檔案選擇*忽略*，GitLoom 會提供*停止追蹤*（`git rm --cached`）：該檔案會在下次提交時離開存放庫，但仍保留在磁碟上。
- 對於你刻意更改的已追蹤檔案（例如本機設定），在已更改的檔案上按右鍵 ▸ *隱藏本機更改*。檔案列表上方有一行顯示隱藏了多少個，*顯示…* 可以讓它們重新出現。
- 在 Mac 磁碟上，用 Finder 將 `readme.md` 重新命名為 `README.md` 時，git 察覺不到。GitLoom 會注意到並提供*記錄重新命名*。

## 復原提交

<kbd>⌘Z</kbd> 復原上一次提交或修補。請參閱[復原和重做](/zh-hant/docs/undo-and-redo/)。
