互動式重定基底會改寫一系列提交。GitLoom 將計劃顯示為一個可編輯的列表；在你開始之前，存放庫不會有任何變化。

## 打開編輯器

- 在提交上按右鍵 ▸ *從此處開始互動式重定基底…*。
- 或者把一個分支拖放到另一個分支上，然後選擇*互動式重定基底*。
- 選取多個提交時，*互動式重定基底所選提交…* 會打開編輯器並選取這些提交。

它也能從第一個提交開始（`--root`）。編輯器會取代提交圖。

## 編輯計劃

每一列是一個提交，最舊的在最上面。從選單或用按鍵設定它的動作：

| 按鍵 | 動作 |
|---|---|
| <kbd>P</kbd> | pick |
| <kbd>R</kbd> | reword |
| <kbd>E</kbd> | edit |
| <kbd>S</kbd> | squash |
| <kbd>F</kbd> | fixup |
| <kbd>C</kbd> | fixup -C |
| <kbd>D</kbd> | drop |

拖曳列，或使用 <kbd>⌥↑</kbd> 和 <kbd>⌥↓</kbd> 來重新排序。<kbd>⌘Z</kbd> 復原對計劃的更改。

- reword 的訊息可以預先寫好，這樣重定基底執行時不會中途停下。
- 列的選單中有*在後面新增命令…*，可在該位置執行一個命令（一行 `exec`，例如失敗時會讓重定基底停下的測試）。
- 疊在被重定基底提交之上的分支會跟著移動（`--update-refs`），除非你取消勾選。
- 範圍內的合併預設會被攤平。勾選*保留合併*即可保留它們（`--rebase-merges`）。這時計劃還會顯示合併每一方的起點以及重新進行合併的位置，提交只能在自己那一方內移動。

## 開始或取消

<kbd>⌘↩</kbd> 開始，Esc 取消。完成後，整個重定基底算作一步復原。

## 更快的編輯

不打開編輯器也可以：

- 選取多個相鄰提交 ▸ *壓縮 N 個提交*（立即執行，訊息依從舊到新合併；選*…並編輯訊息*可自己撰寫）或*刪除 N 個提交…*；
- 在提交上按右鍵 ▸ *編輯訊息…*、*刪除提交…*、*上移/下移*。
