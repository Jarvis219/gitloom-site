加入 GitHub 或 GitLab 帳號後（請參閱 [GitHub](/zh-hant/docs/github/) 和 [GitLab](/zh-hant/docs/gitlab/)），側邊欄會列出存放庫的拉取請求（在 GitLab 上稱為合併請求）。

![顯示拉取請求和 GitHub Actions 執行的側邊欄](/shots/actions-light.png)

## 建立拉取請求

- 為目前的分支選擇 **存放庫 ▸ GitHub / GitLab ▸ 建立拉取請求…**。
- 或者在提交圖上把一個分支拖放到另一個分支上。

審查者、負責人和標籤旁的 ▾ 可以從存放庫的列表中選擇。開啟 AI 後，GitLoom 可以撰寫描述（請參閱[選擇供應商](/zh-hant/docs/choosing-a-provider/)）。

## 審查

打開拉取請求即可查看其差異。你可以對行留言、批准和合併。在差異中，*回覆* 在審查討論串中作答，*解決* 會關閉該討論串。

GitLab 暫不支援逐行留言。

## Launchpad

**Launchpad**（<kbd>⇧⌘K</kbd>）列出跨存放庫和帳號等你處理的拉取請求和議題。在某個項目上按右鍵可以開啟它的存放庫、在瀏覽器中開啟它，或延後它：延後 1 小時、到明天、到下週，或直到它有變化。
