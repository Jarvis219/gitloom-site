其他 AI 工具（Claude Code、Claude Desktop、Cursor、VS Code 等）可以透過 GitLoom 的 MCP 伺服器處理你的存放庫。在你開啟之前，它保持關閉。

## 開啟

在 **設定 ▸ 整合 ▸ MCP 伺服器** 中，將*外部 AI 工具可以*設為以下其中之一：

- *不執行任何操作（關閉）*；
- *讀取：狀態、歷史、差異、追溯*；
- *讀取並更改：還可提交、建分支、儲藏、拉取、推送*。

然後連接你的工具。對於 Claude Code，拷貝那裡顯示的那一行並在終端機中執行；它看起來像這樣：

```sh
claude mcp add gitloom -- "/Applications/GitLoom.app/Contents/Helpers/gitloom-mcp"
```

對於其他工具，將那裡顯示的 JSON 拷貝到該工具的 MCP 設定中。GitLoom 絕不編輯其他工具的檔案。`gitloom mcp` 指令也能執行該伺服器（請參閱[gitloom 命令列工具](/zh-hant/docs/the-gitloom-command-line-tool/)）。

## 讀取

工具可以查看已開啟或在開始頁面最近列表中的存放庫的狀態、歷史、差異、追溯、分支和儲藏。GitLoom 執行時，它們還可以詢問你正在查看什麼，例如所選的提交或開啟的檔案。它們無法更改任何內容。

## 讀取並更改

在 GitLoom 執行期間，對於在標籤頁中開啟的存放庫，工具還可以暫存、提交、建立和切換分支、儲藏、抓取、拉取（僅快轉）和推送。每次更改都會顯示在視窗中，附上工具的名稱和一個*復原*按鈕，並記入操作歷史。

開啟*推送前詢問*後，推送會在存放庫視窗中等待你的回答；60 秒後會被拒絕。

任何工具都不能強制推送、重置、丟棄、刪除或改寫歷史。

## 拉取請求、議題和 CI

開啟*透過我的帳號取得拉取請求、議題和 CI* 後，工具可以透過 GitLoom 中連結的帳號讀取存放庫的拉取請求、議題和 CI 執行。若選擇*讀取並更改*，它們還可以為目前的分支開啟拉取請求並留言。它們永遠看不到你的權杖，也無法合併、批准或關閉任何內容。

設定中的*最近活動*會顯示最近的呼叫。
