GitLoom 中的大多數問題都可以復原或得到解釋。從這裡開始。

## 存放庫出了問題

- **先復原**：<kbd>⌘Z</kbd> 或 **編輯 ▸ 操作歷史…**。大多數操作都可以復原（請參閱[復原和重做](/zh-hant/docs/undo-and-redo/)）。
- **提交似乎不見了**：**存放庫 ▸ Reflog…** 和 **尋找遺失的提交…** 能找到它們（請參閱[透過 reflog 救回](/zh-hant/docs/reflog-recovery/)）。
- **卡在重定基底或合併中**：停在途中的存放庫會顯示一條帶有*繼續*和*中止*的橫幅，重新啟動 GitLoom 後也是如此。

## 查看 GitLoom 做了什麼

**視窗 ▸ Git 記錄**（<kbd>⌥⇧⌘L</kbd>）列出 GitLoom 執行過的每個 git 指令：存放庫、指令、耗時和結束代碼。只保留指令列，絕不保留其輸出、輸入或憑證。

工具列下方有一條細細的移動線條，表示 git 正在與遠端通訊；將指標停在上面可查看詳情。耗時較長的操作，其訊息中會有*取消*。

## 常見問題

- **GitLoom 找不到 git，或顯示版本太舊。** 安裝 git 2.40 或以上版本（請參閱[安裝](/zh-hant/docs/install/)），或在 **設定 ▸ Git ▸ Git 執行檔** 中選擇其他 git。
- **掛鉤找不到 node、python 或程式碼檢查工具。** 在 **設定 ▸ Git ▸ 掛鉤** 的*額外 PATH* 中加入所需的資料夾。這會套用到之後開啟的存放庫。
- **掛鉤卡住了。** 如果掛鉤在一分鐘後仍在執行，提交會提示這一點並提供*停止*。**設定 ▸ Git ▸ 掛鉤** 中的*逾時後停止掛鉤* 會自動停止它（預設 10 分鐘後）。
- **使用了錯誤的 SSH 金鑰。** 設定 [SSH 帳號](/zh-hant/docs/ssh-accounts/)。

## 記錄和快取

在 **設定 ▸ 進階** 中：

- *寫入除錯記錄* 會把 GitLoom 執行的 git 指令及其結束狀態和耗時記錄到記錄資料夾中的一個檔案裡。URL 中的密碼和權杖會被隱藏。*顯示記錄資料夾* 會打開該資料夾。
- *清除快取…* 會移除為離線使用而保存的拉取請求和議題，以及快取的檔案版本。需要時會重新取得。
- 如果你的設定檔案無法讀取，GitLoom 會把它移到一旁，以預設設定啟動，並在這裡說明。

如果以上都沒有幫助，請[回報問題](/zh-hant/docs/report-an-issue/)。
