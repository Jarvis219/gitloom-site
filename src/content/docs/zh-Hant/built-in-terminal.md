<kbd>⌃`</kbd> 在提交圖下方打開一個終端機，位於存放庫資料夾中，使用你自己的登入 Shell。其中的 git 指令一結束，提交圖就會重新整理。

## 建議和連結

輸入 git 指令時，GitLoom 會建議子指令、分支、遠端和別名。<kbd>↑</kbd> <kbd>↓</kbd> 選擇建議，<kbd>⇥</kbd> 或 <kbd>→</kbd> 插入，Esc 關閉列表。

<kbd>⌘</kbd>-按一下指標下的內容：SHA 會選取該提交，路徑會打開檔案，URL 會打開瀏覽器。

## 按鍵

| 按鍵 | 動作 |
|---|---|
| <kbd>⌃`</kbd> | 顯示或隱藏終端機（終端機有焦點時隱藏它） |
| <kbd>⌃⇧`</kbd> | 新增終端機工作階段 |
| <kbd>⌘+</kbd> / <kbd>⌘−</kbd> | 放大 / 縮小終端機文字 |
| Esc | 在空白提示符號處時回到提交圖 |

如果關閉標籤頁時仍有指令在執行，GitLoom 會先詢問。

## 設定

**設定 ▸ 整合 ▸ 終端機** 包括：

- *Shell 整合*：讓 GitLoom 知道指令何時結束（即時重新整理、建議）。關閉後這些功能就會停止。無論開關與否，都不會編輯你的 dotfiles。
- *輸入時建議 git 命令*，只關閉建議。
- *回捲緩衝區*：每個工作階段保留多少行（預設 10,000 行）。
- *回顯 GitLoom 執行的 git 命令*：App 執行的每個指令都會顯示為一行暗色文字，方便學習 git。
- *安全鍵盤輸入*：終端機接收鍵盤輸入時，其他 App 無法讀取你輸入的內容。
- *Shell* 和*引數*：為新的工作階段使用其他 Shell，例如 `/opt/homebrew/bin/fish`。無法執行的路徑會改回使用你的登入 Shell。

更改會套用到新的終端機工作階段。終端機使用 **設定 ▸ 外觀** 中的程式碼字體。

## 你常用的終端機 App

<kbd>⌥⌘T</kbd> 改為在你的終端機 App 中開啟存放庫。在 **設定 ▸ 整合 ▸ 「在終端機中開啟」使用** 中選擇哪個 App。
