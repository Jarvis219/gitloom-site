GitLoom 可以顯示和編輯存放庫中的檔案，所以小修改不需要另開 App。

## 開啟檔案

- <kbd>⌘P</kbd>（快速開啟）開啟存放庫中的任何檔案。
- 側邊欄的「參照/檔案」切換鈕會顯示檔案樹。在那裡你還可以*新增檔案…* 或*新增資料夾…*、*重新命名…* 或*移到廢紙簍*，以及*顯示已忽略的檔案*。

檔案以檢視模式開啟。按 <kbd>⌘E</kbd> 或按一下*編輯檔案*即可編輯。Esc 回到提交圖。

## 編輯按鍵

| 按鍵 | 動作 |
|---|---|
| <kbd>⌘S</kbd> | 儲存 |
| <kbd>⌥⌘S</kbd> | 儲存並暫存 |
| <kbd>⌘L</kbd> | 前往行 |
| <kbd>⌥⌘F</kbd> | 尋找和取代 |
| <kbd>⌘/</kbd> | 將所選行加上或移除註解 |
| <kbd>⌘]</kbd> / <kbd>⌘[</kbd> | 增加 / 減少所選行的縮排 |

編輯器的選項包括*自動換行*、*顯示空格和定位字元*、*自動閉合括號和引號*以及*裝訂線與 HEAD 比較*。程式碼字體及其大小在 **設定 ▸ 外觀** 中設定。

## 檔案在磁碟上被更改時

如果在你有未儲存的編輯時另一個 App 更改了該檔案，GitLoom 會告訴你，並提供*保留我的版本*、*重新載入*或*比較*。含有衝突標記的檔案會提示：儲存它並不會將其標記為已解決；請使用[衝突編輯器](/zh-hant/docs/resolving-conflicts/)來處理。

檔案有未儲存的更改時，GitLoom 也會等待再安裝更新。

## 其他編輯器

*在外部編輯器中開啟* 會在 **設定 ▸ 整合 ▸ 開啟檔案方式** 中選擇的 App 裡開啟檔案。那裡的*自訂命令*優先於該設定；`$FILE`、`$LINE` 和 `$REPO` 會自動填入，例如：

```sh
code -g $FILE:$LINE
```
