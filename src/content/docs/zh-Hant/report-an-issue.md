請在 [GitHub Issues](https://github.com/Jarvis219/gitloom-site/issues) 上回報錯誤和提出功能建議。

## 應附上的資訊

- 你的 GitLoom 版本（**GitLoom ▸ 關於 GitLoom**，或 **設定 ▸ 一般 ▸ 更新**）和 macOS 版本。
- 導致問題的步驟。
- 你預期的結果，以及實際發生的情況。
- 截圖，如果它能說明問題。

如果問題與 git 做的某件事有關，**視窗 ▸ Git 記錄** 中的指令會有幫助（請參閱[疑難排解](/zh-hant/docs/troubleshooting/)）。要取得更多細節，請在 **設定 ▸ 進階** 中開啟*寫入除錯記錄*；其中 URL 裡的密碼和權杖會被隱藏。

> **Caution** 議題是公開的。切勿貼上權杖、密碼、SSH 金鑰或私有程式碼。附加記錄和截圖前請先檢查。

## 當機之後

如果 GitLoom 意外結束，下次啟動時會詢問是否回報。它提供：

- *在 GitHub 上回報…*：瀏覽器會打開一個新議題，其中已填好 GitLoom 和 macOS 版本、錯誤以及當機執行緒的頂端內容。讀一遍，補充你當時在做什麼，然後自己送出。
- *顯示報告*：在 Finder 中顯示 macOS 儲存的當機報告。
- *以後再說*。

除非你自己送出議題，否則不會傳送任何內容。勾選*不再提示此項*，或在 **設定 ▸ 進階** 中關閉*主動提供當機報告*，即可不再詢問。

**輔助說明 ▸ 報告問題…** 隨時會在瀏覽器中打開一個空白議題。
