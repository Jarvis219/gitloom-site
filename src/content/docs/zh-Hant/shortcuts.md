標有 ✎ 的 35 個快速鍵（也就是選單列中的全部快速鍵）可以在 **設定 ▸ 鍵盤** 中更改。其他快速鍵（例如 <kbd>⌘W</kbd> 和 <kbd>⌘Z</kbd> 等系統快速鍵，以及只在表單或編輯器中有效的按鍵）是固定的。選單一律顯示目前的按鍵，這裡的所有操作也都能在命令面板（<kbd>⌘K</kbd>）中找到。

## 隨處可用

| 按鍵 | 動作 |
|---|---|
| <kbd>⌘K</kbd> ✎ | 命令面板：`>` 命令、`/` 檔案、`:` 提交、`@` 作者、`#` 拉取請求和議題 |
| <kbd>⌘P</kbd> ✎ | 快速開啟存放庫中的檔案 |
| <kbd>⌘F</kbd> / <kbd>⌘G</kbd> / <kbd>⇧⌘G</kbd> ✎ | 尋找提交 / 下一個符合項目 / 上一個符合項目 |
| <kbd>⌘Z</kbd> / <kbd>⇧⌘Z</kbd> | 復原 / 重做上一次 Git 操作（在文字欄位中：復原輸入） |
| <kbd>⌘T</kbd> ✎ | 新增標籤頁 |
| <kbd>⌘W</kbd> | 關閉標籤頁 |
| <kbd>⌃⇥</kbd> / <kbd>⌃⇧⇥</kbd> ✎ | 下一個 / 上一個標籤頁 |
| <kbd>⇧⌘C</kbd> ✎ | 複製存放庫 |
| <kbd>⌘O</kbd> ✎ | 開啟存放庫（如果目前的標籤頁已顯示一個存放庫，則在新標籤頁中開啟） |
| <kbd>⇧⌘R</kbd> ✎ | 在 Finder 中顯示存放庫 |
| <kbd>⌥⌘T</kbd> ✎ | 在你的終端機 App 中開啟存放庫 |
| <kbd>⇧⌘K</kbd> | Launchpad（你的 GitHub 和 GitLab 帳號的拉取請求和議題） |
| <kbd>⌥⇧⌘L</kbd> ✎ | Git 記錄（GitLoom 執行過的每個 git 指令） |
| <kbd>⌘,</kbd> | 設定 |
| <kbd>⌘?</kbd> | GitLoom 說明 |

## 存放庫

| 按鍵 | 動作 |
|---|---|
| <kbd>⇧⌘L</kbd> ✎ | 抓取所有遠端 |
| <kbd>⇧⌘↓</kbd> ✎ | 拉取 |
| <kbd>⇧⌘↑</kbd> ✎ | 推送 |
| <kbd>⌘B</kbd> ✎ | 在所選提交處建立分支 |
| <kbd>⇧⌘S</kbd> ✎ | 儲藏所有更改 |
| <kbd>⌥⌘Y</kbd> ✎ | 所選檔案的歷史 |
| <kbd>⌥⌘B</kbd> ✎ | 所選檔案的追溯 |
| <kbd>⌘0</kbd> ✎ | 顯示或隱藏側邊欄 |
| <kbd>⌥⌘0</kbd> ✎ | 顯示或隱藏詳情面板 |
| <kbd>⌥⌘L</kbd> ✎ | 將詳情面板移到底部 / 移回右側 |

## 提交圖、更改和差異

| 按鍵 | 動作 |
|---|---|
| <kbd>↑</kbd> <kbd>↓</kbd> 或 <kbd>J</kbd> <kbd>K</kbd> | 上一個 / 下一個提交 |
| <kbd>⇧</kbd>-按一下、<kbd>⌘</kbd>-按一下 | 選取一個範圍 / 多個提交（比較、壓縮、揀選） |
| <kbd>⌘C</kbd> | 拷貝所選提交的 SHA |
| <kbd>⌘Y</kbd> | 快速檢視所選檔案 |
| <kbd>⇧⌘A</kbd> | 全部暫存 |
| <kbd>⌥⇧⌘A</kbd> | 全部取消暫存 |
| <kbd>⌘↩</kbd> | 提交（在提交訊息中） |
| <kbd>⌥⌘G</kbd> | 使用 AI 撰寫提交訊息（開啟 AI 時） |
| <kbd>⌥↑</kbd> / <kbd>⌥↓</kbd> | 檔案中的上一處 / 下一處更改 |
| <kbd>⌥⌘↑</kbd> / <kbd>⌥⌘↓</kbd> | 上一個 / 下一個檔案 |

## 編輯器

| 按鍵 | 動作 |
|---|---|
| <kbd>⌘E</kbd> ✎ | 編輯開啟的檔案 |
| <kbd>⌘S</kbd> ✎ | 儲存 |
| <kbd>⌥⌘S</kbd> ✎ | 儲存並暫存 |
| <kbd>⌘L</kbd> ✎ | 前往行 |
| <kbd>⌥⌘F</kbd> ✎ | 尋找和取代 |
| <kbd>⌘/</kbd> ✎ | 將所選行加上或移除註解 |
| <kbd>⌘]</kbd> / <kbd>⌘[</kbd> ✎ | 增加 / 減少所選行的縮排 |
| <kbd>P</kbd> <kbd>R</kbd> <kbd>E</kbd> <kbd>S</kbd> <kbd>F</kbd> <kbd>C</kbd> <kbd>D</kbd> | 互動式重定基底：為所選列設定 pick、reword、edit、squash、fixup、fixup -C、drop |
| <kbd>⌥↑</kbd> / <kbd>⌥↓</kbd> | 互動式重定基底：移動所選列（開啟*保留合併*時，只能在其所屬分支內移動） |
| <kbd>⌘Z</kbd> / <kbd>⇧⌘Z</kbd> | 互動式重定基底：復原 / 重做對計劃的更改（開始之前不會動到 git） |
| <kbd>⌘↩</kbd> | 互動式重定基底：開始重定基底（或儲存剩餘的計劃） |
| Esc | 互動式重定基底：關閉編輯器，不執行任何操作 |
| <kbd>⌥⌘↑</kbd> / <kbd>⌥⌘↓</kbd> | 合併衝突：上一個 / 下一個衝突 |
| <kbd>⌘S</kbd> | 合併衝突：儲存並將檔案標記為已解決 |
| <kbd>⌘[</kbd> / <kbd>⌘]</kbd> | 檔案歷史：上一頁 / 下一頁 |

## 終端機

| 按鍵 | 動作 |
|---|---|
| <kbd>⌃`</kbd> ✎ | 顯示或隱藏終端機（終端機有焦點時隱藏它） |
| <kbd>⌃⇧`</kbd> ✎ | 新增終端機工作階段 |
| <kbd>⌘+</kbd> / <kbd>⌘−</kbd> ✎ | 放大 / 縮小終端機文字 |
| <kbd>⇥</kbd> 或 <kbd>→</kbd> | 插入所選建議 |
| <kbd>↑</kbd> <kbd>↓</kbd> | 選擇建議 |
| Esc | 關閉建議；在空白提示符號處時回到提交圖（隱藏終端機也是如此） |
| <kbd>⌘</kbd>-按一下 | 開啟指標下的內容：SHA 選取提交，路徑開啟檔案，URL 開啟瀏覽器 |
