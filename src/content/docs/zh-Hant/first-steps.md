安裝 GitLoom 後，開啟一個現有的存放庫或複製（clone）一個存放庫。GitLoom 做的每件事都與對應的 `git` 指令相同，所以你隨時可以切換到終端機。

## 開啟存放庫

將存放庫的資料夾拖到 GitLoom 視窗上，或從開始頁面或最近列表中選擇。<kbd>⌘O</kbd> 也能開啟存放庫；如果目前的標籤頁已顯示一個存放庫，它會在新標籤頁中開啟。

## 複製存放庫

按 <kbd>⇧⌘C</kbd> 並貼上任何 URL。加入 GitHub 或 GitLab 帳號後（請參閱 [GitHub](/zh-hant/docs/github/) 和 [GitLab](/zh-hant/docs/gitlab/)），你也可以從帳號的存放庫中選擇。

## 標籤頁

每個存放庫都在自己的標籤頁中開啟。<kbd>⌘T</kbd> 開啟新標籤頁，<kbd>⌃⇥</kbd> 切換到下一個。下次啟動 GitLoom 時，你的標籤頁會恢復。要更改這一點，請使用 **設定 ▸ 一般** 中的*啟動時*：重新開啟上次的標籤頁、先詢問，或啟動時不開啟任何存放庫。

## 你的姓名和電子郵件

如果 git 還沒有 `user.name` 或 `user.email`，GitLoom 會在你第一次提交前詢問。如果你在不同類型的工作中使用不同身分，請設定[設定檔](/zh-hant/docs/profiles/)。

## 下一步

- 認識[視窗](/zh-hant/docs/the-window/)的各個部分。
- 完成你的第一次[提交](/zh-hant/docs/committing/)。
- 按 <kbd>⌘K</kbd> 打開命令面板，它可以執行任何命令，並跳到分支、檔案和提交。
