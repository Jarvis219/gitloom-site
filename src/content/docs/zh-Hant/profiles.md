設定檔保存你提交時使用的身分：姓名、電子郵件以及選用的簽章金鑰。例如，一個用於工作，一個用於個人專案。在 **設定 ▸ 設定檔** 中設定。

## 設定檔包含什麼

每個設定檔包括：

- 設定檔名稱，以及提交用的姓名（`user.name`）和電子郵件（`user.email`）；
- 簽章方式：不簽章、SSH、GPG 或 X.509，以及是否預設簽章提交；
- 選用的推送帳號，在 [SSH 帳號](/zh-hant/docs/ssh-accounts/)規則無法決定時使用；
- 自己的已開啟標籤頁和最近存放庫。

GitLoom 會將姓名、電子郵件和簽章金鑰寫入每個存放庫的 git 設定，因此終端機與 GitLoom 保持一致。

## 切換設定檔

從視窗右上角的標籤切換設定檔。其中一個設定檔是預設設定檔：GitLoom 啟動時使用它，使用中的設定檔被刪除時也會回到它。用*設為預設*更改預設設定檔。

## 身分不對

GitLoom 會在提交按鈕上方顯示你將以誰的身分提交。如果該電子郵件不是存放庫所屬設定檔的電子郵件，這一行會帶有警告標記；從工具列的設定檔標籤中選擇正確的設定檔即可修正。

## 移除設定檔

選取它並按一下 −。它的已開啟標籤頁和最近存放庫會被清除。已寫入存放庫的 git 設定維持不變。至少會保留一個設定檔。
