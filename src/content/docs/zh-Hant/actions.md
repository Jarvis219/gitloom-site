加入 GitHub 帳號後，GitLoom 會在側邊欄的「操作」群組中顯示 GitHub Actions 執行，並在提交圖的 CI 欄位中顯示在對應的提交旁。

![顯示拉取請求和 GitHub Actions 執行的側邊欄，其中一次執行的 build 作業已打開](/shots/actions-light.png)

## 執行和記錄

打開一次執行即可查看它的作業、註解和成品。打開一個作業即可閱讀其記錄。記錄檢視可以顯示時間戳記、自動換行或僅顯示錯誤，*儲存記錄…* 可以保留一份副本。

## 重新執行、取消和啟動

- *重新執行所有作業*、*重新執行失敗的作業*或*重新執行此作業*。
- *取消執行*。
- *執行工作流程…* 啟動帶有 `workflow_dispatch` 觸發條件的工作流程，並可填入輸入值。
- 下載執行的成品。

來自分叉、正在等待批准的執行會註明這一點，列出其拉取請求更改的工作流程檔案，並提供*批准並執行…*。請先檢查這些更改：獲准的工作流程會以存放庫的設定執行。

## 通知

你啟動的執行結束時，GitLoom 可以通知你。在 **設定 ▸ Git ▸ GitHub Actions ▸ 我啟動的 CI 完成時通知我** 中選擇何時通知：從不、僅在失敗時（預設）或一律通知。

> **Note** Actions 僅適用於 GitHub。對於 GitLab，暫不支援 CI 管線，Actions 群組會隱藏。
