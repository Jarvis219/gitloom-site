當你的 Mac 上安裝了 `git-lfs` 時，GitLoom 可以搭配 Git LFS 使用。沒有它，GitLoom 仍能列出 LFS 檔案，但無法下載或鎖定它們。

## 「GIT LFS」群組

在使用 LFS 的存放庫中，側邊欄有一個「GIT LFS」群組，列出 LFS 檔案。尚未下載（磁碟上只有指標）的檔案帶有下載圖像。已鎖定的檔案會顯示是誰鎖定的。按兩下檔案即可開啟。

在檔案上按右鍵可以：

- *開啟檔案*；
- *下載此檔案*，當這裡只有它的指標時；
- *鎖定* 或*解鎖*。

## 下載所有 LFS 檔案

**存放庫 ▸ 進階 ▸ 下載 Git LFS 檔案** 會執行 `git lfs pull`，下載此簽出中的大型檔案。

## 追蹤新的檔案類型

在暫存區中已更改的檔案上按右鍵 ▸ *使用 LFS 追蹤（\*.ext）*，即可追蹤所有帶該副檔名的檔案。在已經使用 LFS 的存放庫中，同一個選單還有*鎖定（LFS）*和*解鎖（LFS）*。
