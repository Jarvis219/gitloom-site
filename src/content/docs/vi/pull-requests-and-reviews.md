Khi đã thêm tài khoản GitHub hoặc GitLab (xem [GitHub](/vi/docs/github/) và [GitLab](/vi/docs/gitlab/)), sidebar liệt kê các pull request của repository (merge request trên GitLab).

![Sidebar với một pull request và các lần chạy GitHub Actions](/shots/actions-light.png)

## Tạo pull request

- **Repository ▸ GitHub / GitLab ▸ Tạo pull request…** cho branch hiện tại.
- Hoặc thả một branch lên branch khác trên graph.

Dấu ▾ cạnh Người review, Người được giao và Nhãn cho phép chọn từ danh sách của repository. Khi đã bật AI, GitLoom có thể viết phần mô tả (xem [Chọn provider](/vi/docs/choosing-a-provider/)).

## Review

Mở một pull request để xem diff của nó. Bạn có thể bình luận trên từng dòng, duyệt và merge. Trong diff, *Trả lời* phản hồi trong một luồng review và *Giải quyết* đóng luồng đó.

Bình luận theo dòng chưa có cho GitLab.

## Launchpad

**Launchpad** (<kbd>⇧⌘K</kbd>) liệt kê pull request và issue đang chờ bạn trên mọi repository và tài khoản. Nhấp chuột phải vào một mục để mở repository của nó, mở nó trong trình duyệt, hoặc tạm ẩn: trong 1 giờ, tới ngày mai, tới tuần sau, hoặc cho tới khi nó thay đổi.
