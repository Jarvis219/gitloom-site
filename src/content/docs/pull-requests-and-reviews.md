With a GitHub or GitLab account added (see [GitHub](/docs/github/) and [GitLab](/docs/gitlab/)), the sidebar lists the repository's pull requests (merge requests on GitLab).

![The sidebar with a pull request and GitHub Actions runs](/shots/actions-light.png)

## Create a pull request

- **Repository ▸ GitHub / GitLab ▸ Create Pull Request…** for the current branch.
- Or drop a branch on another branch on the graph.

The ▾ next to Reviewers, Assignees and Labels picks from the repository's lists. With AI turned on, GitLoom can write the description (see [Choosing a provider](/docs/choosing-a-provider/)).

## Review

Open a pull request to see its diff. You can comment on lines, approve and merge. In the diff, *Reply* answers in a review thread and *Resolve* closes it.

Line comments are not available for GitLab yet.

## Launchpad

**Launchpad** (<kbd>⇧⌘K</kbd>) lists the pull requests and issues waiting for you across repositories and accounts. Right-click an item to open its repository or open it in the browser, or snooze it: for 1 hour, until tomorrow, until next week, or until it changes.
