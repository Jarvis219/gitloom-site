GitLoom has a light theme and a dark theme in use at any time. Choose them in **Settings ▸ Appearance**.

## Light and dark

*Mode* follows the system, or stays always light or always dark. Pick a *Light theme* and a *Dark theme*. The built-in ones are Loom Paper and Loom Midnight (the defaults), System Light and Dark, High Contrast Light and Dark, and Solarized-style Light and Dark. A small preview shows the graph and a diff in the chosen colours.

## Colours that are easier to tell apart

- *Diff colors*: from the theme (green/red) or blue/orange.
- *Graph lanes*: from the theme, colour-blind friendly or monochrome.

GitLoom warns when a theme's text doesn't have enough contrast against its background.

## Make or import a theme

The buttons act on the theme in use now:

- *Edit…* opens the theme editor. A built-in theme is copied first.
- *Duplicate* makes a new theme file that extends this one.
- *Import…* takes `.gitloomtheme`, VS Code `.json`, iTerm2 `.itermcolors`, Ghostty and Alacritty themes.
- *Export…* saves the theme as a `.gitloomtheme` file.
- *Open Themes Folder* shows where your themes are.

Theme files can also be edited in any editor; GitLoom applies them as soon as you save.

## More appearance settings

The same tab has the interface *Text size* (small, medium or large), the *Accent* colour, a translucent sidebar, the Dock icon (default, dark or classic), avatars, dates, and the code font and size used by diffs, the file editor, the merge editor and the terminal.
