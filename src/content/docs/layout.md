**Settings ▸ Layout** controls where things are in the window. Changes apply at once.

## Panels and diffs

- *Detail panel*: on the right or under the graph. <kbd>⌥⌘L</kbd> switches it too.
- *Show the status bar*.
- *Open diffs*: over the graph, or below it so the graph stays visible.
- The diff style, and *Remember the diff style for each file*.
- The tab bar: the tab colour as the tab's dot, a colour line under the toolbar, and whether to show the tab when only one is open.

## Toolbar

Choose which buttons the toolbar shows, their order, and how their labels look.

## Graph columns

Turn the Branch / Tag, CI, Changes (+/−), Author, Date and SHA columns on or off for every repository. Graph and Commit message always show. Right-clicking the column header in the graph changes only that repository.

## Sidebar

Show, hide and reorder the sidebar groups. The extra groups (pull requests, Actions, issues, submodules, worktrees and Git LFS files) only show where they apply; hiding one here hides it everywhere. *Show local branches named "prefix/…" as folders* groups branches like `feature/login`.

## Presets

Type a name and click *Save Current Layout* to keep the current arrangement, for example for a small screen. Apply a preset here or from **View ▸ Layout**. *Reset to Default Layout* goes back to the default, and you can undo that from the same place.
