Con una cuenta de GitHub o GitLab añadida (consulta [GitHub](/es/docs/github/) y [GitLab](/es/docs/gitlab/)), la barra lateral muestra los pull requests del repositorio (merge requests en GitLab).

![La barra lateral con un pull request y ejecuciones de GitHub Actions](/shots/actions-light.png)

## Crear un pull request

- **Repositorio ▸ GitHub / GitLab ▸ Crear pull request…** para la rama actual.
- O suelta una rama sobre otra rama en el grafo.

El ▾ junto a Revisores, Asignados y Etiquetas elige de las listas del repositorio. Con la IA activada, GitLoom puede escribir la descripción (consulta [Elegir un proveedor](/es/docs/choosing-a-provider/)).

## Revisar

Abre un pull request para ver su diff. Puedes comentar líneas, aprobar y fusionar. En el diff, *Responder* contesta en un hilo de revisión y *Resolver* lo cierra.

Los comentarios en líneas aún no están disponibles para GitLab.

## Launchpad

**Launchpad** (<kbd>⇧⌘K</kbd>) muestra los pull requests y los issues que te esperan en todos tus repositorios y cuentas. Haz clic derecho en un elemento para abrir su repositorio o abrirlo en el navegador, o para posponerlo: 1 hora, hasta mañana, hasta la semana que viene o hasta que cambie.
