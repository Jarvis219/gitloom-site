Una vez instalado GitLoom, abre un repositorio que ya tengas o clona uno. Todo lo que hace GitLoom equivale al comando `git` correspondiente, así que puedes pasarte al terminal en cualquier momento.

## Abrir un repositorio

Arrastra la carpeta del repositorio a la ventana de GitLoom, o elígelo en la página de inicio o en la lista de recientes. <kbd>⌘O</kbd> también abre un repositorio; si la pestaña actual ya muestra uno, se abre en una pestaña nueva.

## Clonar un repositorio

Pulsa <kbd>⇧⌘C</kbd> y pega cualquier URL. Cuando hayas añadido una cuenta de GitHub o GitLab (consulta [GitHub](/es/docs/github/) y [GitLab](/es/docs/gitlab/)), también puedes elegir entre los repositorios de tu cuenta.

## Pestañas

Cada repositorio se abre en su propia pestaña. <kbd>⌘T</kbd> abre una pestaña nueva y <kbd>⌃⇥</kbd> pasa a la siguiente. Tus pestañas vuelven la próxima vez que abras GitLoom. Para cambiarlo, usa *Al iniciar* en **Ajustes ▸ General**: volver a abrir las últimas pestañas, preguntar primero o empezar sin ningún repositorio abierto.

## Tu nombre y tu correo

Si git aún no tiene `user.name` ni `user.email`, GitLoom te los pide antes de tu primer commit. Si usas identidades distintas para distintos tipos de trabajo, configura [Perfiles](/es/docs/profiles/).

## Siguientes pasos

- Conoce las partes de [la ventana](/es/docs/the-window/).
- Haz tu primer [commit](/es/docs/committing/).
- Pulsa <kbd>⌘K</kbd> para abrir la paleta de comandos, que ejecuta cualquier comando y salta a ramas, archivos y commits.
