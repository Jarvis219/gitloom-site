35 скорочень, позначених ✎ (усі вони є в рядку меню), можна змінити в **Параметри ▸ Клавіатура**. Решта (системні, як-от <kbd>⌘W</kbd> і <kbd>⌘Z</kbd>, і клавіші, що працюють лише всередині аркуша чи редактора) незмінні. Меню завжди показує поточну клавішу, а все, що тут описано, є й у палітрі команд (<kbd>⌘K</kbd>).

## Усюди

| Клавіші | Дія |
|---|---|
| <kbd>⌘K</kbd> ✎ | Палітра команд: `>` команди, `/` файли, `:` коміти, `@` автори, `#` pull request і задачі |
| <kbd>⌘P</kbd> ✎ | Швидке відкриття файлу репозиторію |
| <kbd>⌘F</kbd> / <kbd>⌘G</kbd> / <kbd>⇧⌘G</kbd> ✎ | Пошук комітів / наступний збіг / попередній збіг |
| <kbd>⌘Z</kbd> / <kbd>⇧⌘Z</kbd> | Скасувати / повторити останню операцію Git (у текстовому полі — скасувати введення) |
| <kbd>⌘T</kbd> ✎ | Нова вкладка |
| <kbd>⌘W</kbd> | Закрити вкладку |
| <kbd>⌃⇥</kbd> / <kbd>⌃⇧⇥</kbd> ✎ | Наступна / попередня вкладка |
| <kbd>⇧⌘C</kbd> ✎ | Клонувати репозиторій |
| <kbd>⌘O</kbd> ✎ | Відкрити репозиторій (у новій вкладці, якщо в цій уже відкрито репозиторій) |
| <kbd>⇧⌘R</kbd> ✎ | Показати репозиторій у Finder |
| <kbd>⌥⌘T</kbd> ✎ | Відкрити репозиторій у вашому застосунку термінала |
| <kbd>⇧⌘K</kbd> | Launchpad (pull request і задачі ваших облікових записів GitHub і GitLab) |
| <kbd>⌥⇧⌘L</kbd> ✎ | Журнал Git (усі команди git, які запускав GitLoom) |
| <kbd>⌘,</kbd> | Параметри |
| <kbd>⌘?</kbd> | Довідка GitLoom |

## Репозиторій

| Клавіші | Дія |
|---|---|
| <kbd>⇧⌘L</kbd> ✎ | Отримати з усіх віддалених репозиторіїв (fetch) |
| <kbd>⇧⌘↓</kbd> ✎ | Підтягнути (pull) |
| <kbd>⇧⌘↑</kbd> ✎ | Надіслати (push) |
| <kbd>⌘B</kbd> ✎ | Створити гілку на вибраному коміті |
| <kbd>⇧⌘S</kbd> ✎ | Сховати всі зміни (stash) |
| <kbd>⌥⌘Y</kbd> ✎ | Історія вибраного файлу |
| <kbd>⌥⌘B</kbd> ✎ | Blame вибраного файлу |
| <kbd>⌘0</kbd> ✎ | Показати чи сховати бічну панель |
| <kbd>⌥⌘0</kbd> ✎ | Показати чи сховати панель подробиць |
| <kbd>⌥⌘L</kbd> ✎ | Перенести панель подробиць униз / назад праворуч |

## Граф, зміни й diff

| Клавіші | Дія |
|---|---|
| <kbd>↑</kbd> <kbd>↓</kbd> або <kbd>J</kbd> <kbd>K</kbd> | Попередній / наступний коміт |
| Клацання з <kbd>⇧</kbd>, клацання з <kbd>⌘</kbd> | Вибрати діапазон / кілька комітів (порівняти, squash, cherry-pick) |
| <kbd>⌘C</kbd> | Копіювати SHA вибраного коміту |
| <kbd>⌘Y</kbd> | Швидкий перегляд вибраного файлу |
| <kbd>⇧⌘A</kbd> | Додати все до індексу |
| <kbd>⌥⇧⌘A</kbd> | Вилучити все з індексу |
| <kbd>⌘↩</kbd> | Закомітити (у полі повідомлення коміту) |
| <kbd>⌥⌘G</kbd> | Написати повідомлення коміту за допомогою ШІ (коли ШІ ввімкнено) |
| <kbd>⌥↑</kbd> / <kbd>⌥↓</kbd> | Попередня / наступна зміна у файлі |
| <kbd>⌥⌘↑</kbd> / <kbd>⌥⌘↓</kbd> | Попередній / наступний файл |

## Редактори

| Клавіші | Дія |
|---|---|
| <kbd>⌘E</kbd> ✎ | Редагувати відкритий файл |
| <kbd>⌘S</kbd> ✎ | Зберегти |
| <kbd>⌥⌘S</kbd> ✎ | Зберегти й додати до індексу |
| <kbd>⌘L</kbd> ✎ | Перейти до рядка |
| <kbd>⌥⌘F</kbd> ✎ | Знайти й замінити |
| <kbd>⌘/</kbd> ✎ | Закоментувати чи розкоментувати вибрані рядки |
| <kbd>⌘]</kbd> / <kbd>⌘[</kbd> ✎ | Збільшити / зменшити відступ вибраних рядків |
| <kbd>P</kbd> <kbd>R</kbd> <kbd>E</kbd> <kbd>S</kbd> <kbd>F</kbd> <kbd>C</kbd> <kbd>D</kbd> | Інтерактивний rebase: pick, reword, edit, squash, fixup, fixup -C, drop для вибраних рядків |
| <kbd>⌥↑</kbd> / <kbd>⌥↓</kbd> | Інтерактивний rebase: перемістити вибрані рядки (з *Зберігати злиття* — лише в межах їхньої гілки) |
| <kbd>⌘Z</kbd> / <kbd>⇧⌘Z</kbd> | Інтерактивний rebase: скасувати / повторити зміну плану (git не чіпається, доки ви не почнете) |
| <kbd>⌘↩</kbd> | Інтерактивний rebase: почати rebase (або зберегти решту плану) |
| Esc | Інтерактивний rebase: закрити редактор, нічого не роблячи |
| <kbd>⌥⌘↑</kbd> / <kbd>⌥⌘↓</kbd> | Конфлікти злиття: попередній / наступний конфлікт |
| <kbd>⌘S</kbd> | Конфлікти злиття: зберегти й позначити файл розв’язаним |
| <kbd>⌘[</kbd> / <kbd>⌘]</kbd> | Історія файлу: назад / вперед |

## Термінал

| Клавіші | Дія |
|---|---|
| <kbd>⌃`</kbd> ✎ | Показати чи сховати термінал (ховає його, коли він у фокусі) |
| <kbd>⌃⇧`</kbd> ✎ | Новий сеанс термінала |
| <kbd>⌘+</kbd> / <kbd>⌘−</kbd> ✎ | Більший / менший текст термінала |
| <kbd>⇥</kbd> або <kbd>→</kbd> | Вставити вибрану підказку |
| <kbd>↑</kbd> <kbd>↓</kbd> | Вибрати підказку |
| Esc | Закрити підказки; у порожньому запрошенні — повернутися до графа (так само, як і приховання термінала) |
| Клацання з <kbd>⌘</kbd> | Відкрити те, що під вказівником: SHA вибирає коміт, шлях відкриває файл, URL відкриває браузер |
