Інші інструменти ШІ (Claude Code, Claude Desktop, Cursor, VS Code та інші) можуть працювати з вашими репозиторіями через сервер MCP у GitLoom. Він вимкнений, доки ви його не ввімкнете.

## Як увімкнути

У **Параметри ▸ Інтеграції ▸ Сервер MCP** установіть для *Зовнішні інструменти ШІ можуть* одне зі значень:

- *Нічого не робити (вимкнено)*;
- *Читати: стан, історію, різниці, авторство рядків*;
- *Читати й змінювати: також коміт, гілки, схованки, підтягування, надсилання*.

Потім підключіть свій інструмент. Для Claude Code скопіюйте показаний там рядок і виконайте його в терміналі; він виглядає так:

```sh
claude mcp add gitloom -- "/Applications/GitLoom.app/Contents/Helpers/gitloom-mcp"
```

Для інших інструментів скопіюйте показаний там JSON у конфігурацію MCP інструмента. GitLoom ніколи не змінює файли інших інструментів. Сервер також запускає команда `gitloom mcp` (див. [Інструмент командного рядка gitloom](/uk/docs/the-gitloom-command-line-tool/)).

## Читання

Інструменти бачать стан, історію, різниці, авторство рядків, гілки й схованки репозиторіїв, відкритих або наявних у списку нещодавніх на початковій сторінці. Поки працює GitLoom, вони також можуть запитати, що ви зараз переглядаєте, наприклад вибраний коміт або відкритий файл. Змінювати щось вони не можуть.

## Читання й зміни

Інструменти також можуть індексувати, комітити, створювати гілки й перемикатися між ними, ховати зміни, отримувати, підтягувати (лише fast-forward) і надсилати — у репозиторіях, відкритих у вкладці, поки працює GitLoom. Кожна зміна з’являється у вікні з назвою інструмента й кнопкою *Скасувати дію*, а також в Історії операцій.

Коли ввімкнено *Запитувати перед надсиланням*, надсилання чекає на вашу відповідь у вікні репозиторію; через 60 секунд його буде відхилено.

Жоден інструмент не може робити force-push, reset, відкидати зміни, видаляти чи переписувати історію.

## Pull request, задачі й CI

Коли ввімкнено *Pull request, задачі й CI через мої облікові записи*, інструменти можуть читати pull request, задачі й запуски CI репозиторію через обліковий запис, підключений у GitLoom. З рівнем *Read and change* вони також можуть відкрити pull request для поточної гілки й коментувати його. Вони ніколи не бачать вашого токена й не можуть нічого зливати, схвалювати чи закривати.

Параметри показують останні виклики в розділі *Недавня активність*.
