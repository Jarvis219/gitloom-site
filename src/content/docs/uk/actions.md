Коли додано обліковий запис GitHub, GitLoom показує запуски GitHub Actions у групі ACTIONS бічної панелі та поруч із їхніми комітами в стовпці CI графа.

![Бічна панель із pull request і запусками GitHub Actions, відкрито завдання build одного із запусків](/shots/actions-light.png)

## Запуски й журнали

Відкрийте запуск, щоб побачити його завдання, анотації й артефакти. Відкрийте завдання, щоб прочитати його журнал. Перегляд журналу може показувати мітки часу, переносити рядки або показувати лише помилки, а *Зберегти журнал…* зберігає копію.

## Перезапуск, скасування й запуск

- *Перезапустити всі завдання*, *Перезапустити невдалі завдання* або *Перезапустити це завдання*.
- *Скасувати запуск*.
- *Запустити workflow…* запускає workflow із тригером `workflow_dispatch` разом з його вхідними параметрами.
- Завантажуйте артефакти запуску.

Запуск із форку, що чекає схвалення, повідомляє про це, показує файли workflow, які змінює його pull request, і пропонує *Схвалити й запустити…*. Спершу перевірте зміни: схвалені workflow виконуються з параметрами репозиторію.

## Сповіщення

GitLoom може сповістити вас, коли завершиться запущений вами запуск. Виберіть, коли саме, у **Параметри ▸ Git ▸ GitHub Actions ▸ Сповіщати, коли завершується запущений мною CI**: ніколи, лише в разі невдачі (за замовчуванням) або завжди.

> **Note** Actions доступні лише для GitHub. Для GitLab конвеєри CI поки не підтримуються, і групу Actions приховано.
