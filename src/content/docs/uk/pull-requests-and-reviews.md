Коли додано обліковий запис GitHub чи GitLab (див. [GitHub](/uk/docs/github/) і [GitLab](/uk/docs/gitlab/)), бічна панель показує pull request репозиторію (у GitLab — merge request).

![Бічна панель із pull request і запусками GitHub Actions](/shots/actions-light.png)

## Створення pull request

- **Репозиторій ▸ GitHub / GitLab ▸ Створити pull request…** для поточної гілки.
- Або киньте гілку на іншу гілку на графі.

Кнопка ▾ поруч із полями «Рецензенти», «Виконавці» й «Мітки» дає вибрати зі списків репозиторію. Якщо ШІ ввімкнено, GitLoom може написати опис (див. [Вибір провайдера](/uk/docs/choosing-a-provider/)).

## Рецензування

Відкрийте pull request, щоб побачити його diff. Можна коментувати рядки, схвалювати й зливати. У diff *Відповісти* відповідає в гілці обговорення рецензії, а *Розв’язати* закриває її.

Коментарі до рядків для GitLab поки недоступні.

## Launchpad

**Launchpad** (<kbd>⇧⌘K</kbd>) показує pull request і задачі, які чекають на вас, з усіх репозиторіїв і облікових записів. Клацніть елемент правою кнопкою, щоб відкрити його репозиторій чи відкрити його в браузері, або відкласти: на 1 годину, до завтра, до наступного тижня чи доки він не зміниться.
