GitLoom — безкоштовний Git-клієнт для Mac. Він запускає ваш власний `git`, тож діють усі ваші налаштування, хуки, облікові дані й псевдоніми.

## Вимоги

- macOS 14 Sonoma або новіша на Mac з Apple silicon.
- git 2.40 або новіший. Підійде як git з Xcode Command Line Tools, так і з Homebrew.

Щоб отримати git від Apple, виконайте в Терміналі:

```sh
xcode-select --install
```

Під час запуску GitLoom повідомить, якщо не знайде достатньо нову версію git. Якщо git у вас лежить у незвичному місці, виберіть його в **Параметри ▸ Git**.

## Завантаження

Завантажте `GitLoom.dmg` (42 МБ) з [останнього випуску](https://github.com/Jarvis219/gitloom-site/releases/latest/download/GitLoom.dmg) або в Терміналі:

```sh
curl -LO https://github.com/Jarvis219/gitloom-site/releases/latest/download/GitLoom.dmg
```

Відкрийте образ диска й перетягніть GitLoom у папку «Програми».

## Перше відкриття

GitLoom ще не нотаризовано Apple, тому macOS блокує перший запуск. Щоб відкрити його:

1. Один раз відкрийте GitLoom. macOS повідомить, що його неможливо відкрити.
2. Перейдіть у **Системні параметри ▸ Приватність і безпека** й натисніть *Усе одно відкрити* поруч із повідомленням про GitLoom.
3. Підтвердьте. Відтепер GitLoom відкривається як зазвичай.

Це потрібно зробити лише один раз. Новіші версії надходять через власний механізм оновлення GitLoom (див. [Оновлення](/uk/docs/updates/)).

## Необов’язково: інструмент командного рядка

Виберіть **GitLoom ▸ Інсталювати інструмент командного рядка…**, щоб додати команду `gitloom`: тоді `gitloom .` відкриває папку, у якій ви перебуваєте. Див. [Інструмент командного рядка gitloom](/uk/docs/the-gitloom-command-line-tool/).
