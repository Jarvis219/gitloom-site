Профіль містить дані, від імені яких ви комітите: ім’я, пошту й необов’язковий ключ підпису. Наприклад, один профіль для роботи, інший — для особистих проєктів. Налаштуйте їх у **Параметри ▸ Профілі**.

## Що містить профіль

Кожен профіль має:

- назву профілю, а також ім’я (`user.name`) і пошту (`user.email`) для комітів;
- спосіб підпису: не підписувати, SSH, GPG або X.509 — і чи підписувати коміти за замовчуванням;
- необов’язковий обліковий запис для надсилання, якщо правила [облікових записів SSH](/uk/docs/ssh-accounts/) цього не визначають;
- власні відкриті вкладки й нещодавні репозиторії.

GitLoom записує ім’я, пошту й ключ підпису в git config кожного репозиторію, тож термінал узгоджується з GitLoom.

## Перемикання профілів

Перемикайте профілі кнопкою в правому верхньому куті вікна. Один профіль є стандартним: з ним GitLoom запускається і до нього повертається, якщо поточний профіль видалено. Щоб змінити стандартний, скористайтеся *Зробити стандартним*.

## Не ті дані автора

Над кнопкою коміту GitLoom показує, від чийого імені ви комітите. Якщо ця пошта не збігається з поштою профілю репозиторію, рядок позначається попередженням; щоб виправити, виберіть потрібний профіль кнопкою на панелі інструментів.

## Видалення профілю

Виберіть його й натисніть −. Його відкриті вкладки й нещодавні репозиторії буде забуто. Git config, уже записаний у репозиторії, залишається як є. Завжди існує щонайменше один профіль.
