Команда `gitloom` відкриває GitLoom із термінала. За потреби вона запускає GitLoom.

## Встановлення

Виберіть **GitLoom ▸ Інсталювати інструмент командного рядка…**. Це додає посилання `~/.local/bin/gitloom` без пароля адміністратора. Якщо `~/.local/bin` ще немає у вашому PATH, GitLoom про це скаже; додайте такий рядок у `~/.zshrc`:

```sh
export PATH="$HOME/.local/bin:$PATH"
```

Щоб установити команду для всіх оболонок, не змінюючи PATH, скористайтеся *Інсталювати в /usr/local/bin…* у **Параметри ▸ Інтеграції ▸ Інструмент командного рядка**. macOS запитає пароль адміністратора. У тому ж розділі показано, де встановлено `gitloom`.

GitLoom замінює лише власне посилання. Якщо там уже є інший файл із назвою `gitloom`, його не чіпають, і GitLoom про це повідомляє.

## Команди

| Команда | Що робить |
|---|---|
| `gitloom [path]` | Відкриває репозиторій, що містить `path` (за замовчуванням — поточну папку) |
| `gitloom clone <url> [dir]` | Відкриває заповнене вікно клонування |
| `gitloom diff [<rev>]` | Відкриває репозиторій, у якому ви перебуваєте, і вибирає `<rev>` (за замовчуванням — рядок незакомічених змін) |
| `gitloom log <file>` | Відкриває історію файлу |
| `gitloom blame <file>[:<line>]` | Відкриває blame файлу на вказаному рядку |
| `gitloom mcp` | Запускає MCP-сервер GitLoom через stdio (див. [MCP-сервер](/uk/docs/mcp-server/)) |

Наприклад:

```sh
cd ~/Projects/my-app
gitloom .
gitloom blame src/main.swift:42
```
