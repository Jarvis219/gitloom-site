GitLoom працює з Git LFS, коли на вашому Mac установлено `git-lfs`. Без нього GitLoom усе одно може показувати файли LFS, але не може їх завантажувати чи блокувати.

## Група GIT LFS

У репозиторії, що використовує LFS, на бічній панелі є група GIT LFS зі списком файлів LFS. Файл, який ще не завантажено (на диску є лише вказівник), позначено значком завантаження. Для заблокованого файлу показано, хто його заблокував. Двічі клацніть файл, щоб відкрити його.

Клацніть файл правою кнопкою, щоб вибрати:

- *Відкрити файл*;
- *Завантажити цей файл*, коли тут є лише його вказівник;
- *Заблокувати* або *Розблокувати*.

## Завантаження всіх файлів LFS

**Репозиторій ▸ Додатково ▸ Завантажити файли Git LFS** виконує `git lfs pull` і завантажує великі файли цієї робочої копії.

## Відстежування нового типу файлів

Клацніть правою кнопкою змінений файл в області індексування ▸ *Відстежувати через LFS (\*.ext)*, щоб відстежувати всі файли з цим розширенням. У репозиторії, що вже використовує LFS, у тому самому меню є *Заблокувати (LFS)* і *Розблокувати (LFS)*.
