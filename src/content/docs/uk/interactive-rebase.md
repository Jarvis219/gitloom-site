Інтерактивне перебазування (rebase) переписує низку комітів. GitLoom показує план як список, який ви редагуєте; з репозиторієм нічого не відбувається, доки ви не почнете.

## Як відкрити редактор

- Клацніть коміт правою кнопкою ▸ *Інтерактивне перебазування звідси…*.
- Або киньте гілку на іншу й виберіть *Інтерактивне перебазування*.
- Якщо вибрано кілька комітів, *Інтерактивно перебазувати вибрані коміти…* відкриває редактор із ними вибраними.

Це працює й від найпершого коміту (`--root`). Редактор замінює граф.

## Редагування плану

Кожен рядок — це коміт, найстаріший угорі. Задайте його дію через меню або клавішею:

| Клавіша | Дія |
|---|---|
| <kbd>P</kbd> | pick |
| <kbd>R</kbd> | reword |
| <kbd>E</kbd> | edit |
| <kbd>S</kbd> | squash |
| <kbd>F</kbd> | fixup |
| <kbd>C</kbd> | fixup -C |
| <kbd>D</kbd> | drop |

Щоб змінити порядок, перетягуйте рядки або використовуйте <kbd>⌥↑</kbd> і <kbd>⌥↓</kbd>. <kbd>⌘Z</kbd> скасовує зміну плану.

- Нові повідомлення для reword можна написати заздалегідь, щоб перебазування виконалося без зупинок.
- У меню рядка є *Додати команду після…*, щоб виконати команду в цьому місці (рядок `exec`, наприклад тест, що зупиняє перебазування в разі невдачі).
- Гілки, що лежать поверх перебазованих комітів, переміщуються разом із ними (`--update-refs`), якщо ви не знімете цей прапорець.
- Злиття в діапазоні за замовчуванням вирівнюються. Позначте *Зберігати злиття*, щоб зберегти їх (`--rebase-merges`). Тоді план також показує, де починається кожна сторона злиття і де злиття створюється знову, а коміти можна переміщувати лише в межах їхньої сторони.

## Запуск або скасування

<kbd>⌘↩</kbd> запускає, а Esc скасовує. Після цього все перебазування — один крок скасування.

## Швидші правки

Не відкриваючи редактор:

- виберіть кілька сусідніх комітів ▸ *Об’єднати N комітів (squash)* (виконується одразу, повідомлення об’єднуються, найстаріше першим; *Об’єднати N комітів і змінити повідомлення…*, щоб написати його самостійно) або *Відкинути N комітів…*;
- клацніть коміт правою кнопкою ▸ *Редагувати повідомлення…*, *Відкинути коміт…*, *Перемістити вгору/вниз*.
