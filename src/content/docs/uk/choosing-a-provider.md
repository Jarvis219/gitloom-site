Функції ШІ за замовчуванням вимкнено. Увімкнувши їх, ви вибираєте, хто відповідає: хмарний постачальник із вашим власним ключем або модель, що працює на вашому Mac.

## Як увімкнути

Відкрийте **Параметри ▸ ШІ** й увімкніть *Функції ШІ*. Спершу GitLoom пояснить, що й кому буде надіслано.

Виберіть *Постачальника*:

- Anthropic, OpenAI, Google Gemini, OpenRouter, Groq, Mistral, DeepSeek, Qwen (Alibaba Cloud), xAI або Together AI;
- Ollama чи LM Studio, що працюють локально, — тоді дані не залишають ваш Mac;
- власний постачальник: будь-який сервер, що підтримує API Anthropic, OpenAI, Gemini або Ollama, наприклад корпоративний шлюз. Додайте його через *Додати власного постачальника…*.

Вставте ключ API й натисніть *Зберегти ключ*. Ключі зберігаються у В’язці ключів. *Перевірити* перевіряє ключ і завантажує моделі постачальника, щоб ви могли вибрати одну.

## Що вміє ШІ

- Писати повідомлення комітів (<kbd>⌥⌘G</kbd>), описи pull request і повідомлення схованок.
- Пояснювати коміт, гілку чи ваші зміни, з уточнювальними запитаннями.
- Пропонувати розв’язання конфліктів.

Нічого не надсилається, доки ви не попросите. Без мережі кнопки ✨ неактивні; локальна модель і далі працює.

## Налаштування тексту

У розділі *Запис* виберіть мову (English або Tiếng Việt) і стиль комітів: Conventional Commits, як в історії репозиторію, або довільний.

*Показати параметри функцій* дає кожній функції власну модель і *Власні інструкції*. Меню **Шаблони** поруч із ними заповнює готовий набір — наприклад, Conventional Commits, ID задачі з назви гілки, структуру pull request чи рецензію лише на помилки, — який потім можна адаптувати для своєї команди.

## Вимкнення для одного репозиторію

Виберіть *Вимкнути ШІ для цього репозиторію* в меню ✨ поруч із повідомленням коміту. Увімкнути знову можна в **Параметри ▸ ШІ ▸ ШІ вимкнено для**.

Перш ніж щось буде надіслано, ви можете побачити точний запит. Див. [Що надсилається](/uk/docs/what-gets-sent/).
