Увійдіть у GitHub, щоб користуватися в GitLoom pull request, задачами, Launchpad і Actions.

## Вхід

Відкрийте **Параметри ▸ Хостинг** і натисніть *Увійти через GitHub…*. *Отримати код* видає вам код; *Copy Code & Open GitHub* копіює його й відкриває сторінку, де його треба ввести.

Також можна скористатися *Додати токен…* і вставити персональний токен доступу — fine-grained або classic. GitLoom перевіряє області дії, які може побачити.

Токени зберігаються лише у В’язці ключів macOS.

## Що можна робити

- Створювати, рецензувати й зливати [pull request](/uk/docs/pull-requests-and-reviews/).
- Створювати й переглядати [задачі](/uk/docs/issues/).
- Бачити запуски GitHub [Actions](/uk/docs/actions/) поруч із їхніми комітами.
- **Launchpad** (<kbd>⇧⌘K</kbd>) показує pull request і задачі, що чекають на вас, з усіх репозиторіїв.
- **Вікно ▸ Організації** показує ваші організації, їхні команди й учасників.
- У **Репозиторій ▸ GitHub / GitLab** є *Опублікувати репозиторій…* — створює репозиторій на GitHub, додає його як `origin` і надсилає поточну гілку, — а також *Fork on GitHub*.
- Клонуйте з ваших облікових записів і організацій: <kbd>⇧⌘C</kbd> ▸ *Вибрати з вашого облікового запису…*.

## Ваш email для комітів

Перед комітом GitLoom попереджає, коли email не входить до адрес вашого облікового запису GitHub, бо GitHub не пов’яже такий коміт із вами.

## Ключі SSH

Вхід потрібен для API. Який ключ SSH надсилає зміни для якого логіна, задається в [Облікових записах SSH](/uk/docs/ssh-accounts/). Пункт *Ключі SSH…* облікового запису в **Параметри ▸ Хостинг** показує ключі на GitHub і може вивантажити ваш.
