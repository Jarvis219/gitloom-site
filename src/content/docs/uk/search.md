У GitLoom є три способи щось знайти: пошук комітів, палітра команд для будь-чого й швидке відкриття для файлів.

## Пошук комітів

<kbd>⌘F</kbd> шукає в повідомленнях комітів, авторах, SHA, шляхах файлів або змінах (`-S`, тобто коміти, що додають чи вилучають певний фрагмент тексту). Пошук може відфільтрувати граф до збігів. <kbd>⌘G</kbd> і <kbd>⇧⌘G</kbd> переходять до наступного й попереднього збігу.

- Діакритика не має значення: «nguoi» знаходить «người».
- `re:` приймає регулярний вираз для всього повідомлення, наприклад `re:^fix(ed)?:`.

## Палітра команд

<kbd>⌘K</kbd> виконує будь-яку команду й переходить до гілок, файлів, комітів, авторів і pull request. Почніть із символу, щоб шукати щось одного виду:

| Префікс | Шукає |
|---|---|
| `>` | команди |
| `/` | файли |
| `:` | коміти |
| `@` | авторів |
| `#` | pull request і задачі |

## Швидке відкриття

<kbd>⌘P</kbd> відкриває будь-який файл репозиторію. Коли його відкрито, <kbd>⌘E</kbd> дає змогу його редагувати (див. [Редактор файлів](/uk/docs/file-editor/)).
