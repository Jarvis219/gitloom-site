Коли додано обліковий запис GitHub або GitLab, GitLoom показує задачі репозиторію на бічній панелі.

## Створення й перегляд

- **Репозиторій ▸ GitHub / GitLab ▸ Нова задача…** створює задачу.
- Переглядайте задачі репозиторію в групі «Задачі» на бічній панелі. Їх можна фільтрувати за мітками й віхами.
- Клацніть задачу правою кнопкою, щоб вибрати *Створити гілку із задачі*, *Відкрити в браузері* або *Копіювати посилання*.
- У палітрі команд (<kbd>⌘K</kbd>) введіть `#`, щоб знайти pull request і задачі.
- **Launchpad** (<kbd>⇧⌘K</kbd>) показує задачі, що чекають на вас, з усіх репозиторіїв.

## Гілка із задачі

*Створити гілку із задачі* створює гілку, названу за задачею. Назва формується за шаблоном у **Параметри ▸ Git ▸ Гілка із задачі**, за замовчуванням `{type}/{number}-{slug}`, де `{type}` — це `fix` або `feat`. Шаблон команди в `.gitloom/team.json` має перевагу над вашим.
