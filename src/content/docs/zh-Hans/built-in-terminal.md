<kbd>⌃`</kbd> 在提交图下方打开一个终端，位于仓库文件夹中，使用你自己的登录 Shell。其中的 git 命令一结束，提交图就会刷新。

## 建议和链接

输入 git 命令时，GitLoom 会建议子命令、分支、远程和别名。<kbd>↑</kbd> <kbd>↓</kbd> 选择建议，<kbd>⇥</kbd> 或 <kbd>→</kbd> 插入，Esc 关闭列表。

<kbd>⌘</kbd>-点按指针下的内容：SHA 会选中该提交，路径会打开文件，URL 会打开浏览器。

## 按键

| 按键 | 动作 |
|---|---|
| <kbd>⌃`</kbd> | 显示或隐藏终端（终端有焦点时隐藏它） |
| <kbd>⌃⇧`</kbd> | 新建终端会话 |
| <kbd>⌘+</kbd> / <kbd>⌘−</kbd> | 放大 / 缩小终端文字 |
| Esc | 在空提示符处时返回提交图 |

如果关闭标签页时仍有命令在运行，GitLoom 会先询问。

## 设置

**设置 ▸ 集成 ▸ 终端** 包括：

- *Shell 集成*：让 GitLoom 知道命令何时结束（即时刷新、建议）。关闭后这些功能就会停止。无论开关与否，都不会编辑你的 dotfiles。
- *输入时建议 git 命令*，只关闭建议。
- *回滚缓冲*：每个会话保留多少行（默认 10,000 行）。
- *回显 GitLoom 运行的 git 命令*：应用运行的每条命令都会显示为一行暗色文字，方便学习 git。
- *安全键盘输入*：终端接收键盘输入时，其他应用无法读取你输入的内容。
- *Shell* 和*参数*：为新会话使用其他 Shell，例如 `/opt/homebrew/bin/fish`。无法运行的路径会回退到你的登录 Shell。

更改对新的终端会话生效。终端使用 **设置 ▸ 外观** 中的代码字体。

## 你常用的终端应用

<kbd>⌥⌘T</kbd> 改为在你的终端应用中打开仓库。在 **设置 ▸ 集成 ▸ “在终端中打开”使用** 中选择哪个应用。
