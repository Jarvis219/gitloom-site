AI 功能默认关闭。开启后，你可以选择由谁来回答：使用你自己密钥的云端提供商，或在你的 Mac 上运行的模型。

## 开启

打开 **设置 ▸ AI**，开启*AI 功能*。GitLoom 会先说明将发送什么、发送给谁。

选择*提供商*：

- Anthropic、OpenAI、Google Gemini、OpenRouter、Groq、Mistral、DeepSeek、Qwen（阿里云）、xAI 或 Together AI；
- 在本地运行的 Ollama 或 LM Studio，数据不会离开你的 Mac；
- 自定义提供商：任何支持 Anthropic、OpenAI、Gemini 或 Ollama API 的服务器，例如公司网关。用*添加自定义提供商…* 添加。

粘贴你的 API 密钥并点按*保存密钥*。密钥存储在钥匙串中。*测试* 会检查密钥并载入提供商的模型，供你选择。

## AI 能做什么

- 撰写提交信息（<kbd>⌥⌘G</kbd>）、拉取请求描述和贮藏信息。
- 解释一个提交、一个分支或你的更改，并可继续追问。
- 建议冲突的解决方案。

在你提出请求之前，不会发送任何内容。没有网络时，✨ 按钮会变暗；本地模型仍然可用。

## 调整写作

在*写入*下，选择语言（English 或 Tiếng Việt）和提交风格：Conventional Commits、仿照仓库历史，或自由格式。

*显示按功能的设置* 让每个功能拥有自己的模型和*自定义指令*。旁边的**模板**菜单会填入现成的设置，例如 Conventional Commits、从分支名提取工单 ID、拉取请求大纲或只关注错误的审查，你可以再按团队需要调整。

## 为某个仓库关闭

从提交信息旁的 ✨ 菜单中选择*为此仓库关闭 AI*。在 **设置 ▸ AI ▸ 已关闭 AI 的仓库** 中重新开启。

在发送任何内容之前，你都可以查看确切的请求。参阅[发送哪些内容](/zh-hans/docs/what-gets-sent/)。
