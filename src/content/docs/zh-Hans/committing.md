选中*未提交的更改*行，暂存你想要的内容（参阅[按行暂存](/zh-hans/docs/staging-single-lines/)），撰写信息，然后按 <kbd>⌘↩</kbd>。

## 提交表单

- *修订* 会更改上一个提交，而不是新建一个提交。勾选时，该提交已更改的文件也会列出。
- *合著者* 会推荐最近历史中的人，包括你以前添加过的合著者。
- 提交运行时，钩子输出的内容（`pre-commit` 代码检查、测试）会显示在信息下方。如果某个钩子一分钟后仍在运行，GitLoom 会告诉你并提供*停止*。
- 有一行会显示你将以谁的身份提交。当邮箱与仓库的[档案](/zh-hans/docs/profiles/)不符，或不是你 GitHub 账户的邮箱之一时（GitHub 将无法把该提交关联到你），它会发出警告。

开启 AI 后，<kbd>⌥⌘G</kbd> 会为你撰写提交信息（参阅[选择提供商](/zh-hans/docs/choosing-a-provider/)）。

## 提交信息设置

在 **设置 ▸ Git ▸ 提交信息** 中，你可以设置表单的初始模板，以及摘要长度达到多少时计数器变为黄色和红色（默认 50 和 72 个字符）。它只会警告，不会截断任何内容。仓库自己的 `commit.template` 优先于该模板。

## git 不显示的文件

- 对一个已被跟踪的文件选择*忽略*，GitLoom 会提供*停止跟踪*（`git rm --cached`）：该文件会在下次提交时离开仓库，但仍保留在磁盘上。
- 对于你有意更改的已跟踪文件（例如本地配置），右键点按已更改的文件 ▸ *隐藏本地更改*。文件列表上方有一行显示隐藏了多少个，*显示…* 可以让它们重新出现。
- 在 Mac 磁盘上，用访达将 `readme.md` 重命名为 `README.md` 时，git 察觉不到。GitLoom 会注意到并提供*记录重命名*。

## 撤销提交

<kbd>⌘Z</kbd> 撤销上一次提交或修订。参阅[撤销和重做](/zh-hans/docs/undo-and-redo/)。
