添加 GitHub 账户后，GitLoom 会在侧边栏的“操作”组中显示 GitHub Actions 运行，并在提交图的 CI 列中显示在对应提交旁。

![显示拉取请求和 GitHub Actions 运行的侧边栏，其中一次运行的 build 作业已打开](/shots/actions-light.png)

## 运行和日志

打开一次运行即可查看它的作业、注释和产物。打开一个作业即可阅读其日志。日志视图可以显示时间戳、自动换行或仅显示错误，*保存日志…* 可以保留一份副本。

## 重新运行、取消和启动

- *重新运行所有作业*、*重新运行失败的作业*或*重新运行此作业*。
- *取消运行*。
- *运行工作流…* 启动带有 `workflow_dispatch` 触发器的工作流，并可填写输入。
- 下载运行的产物。

来自复刻、正在等待批准的运行会注明这一点，列出其拉取请求更改的工作流文件，并提供*批准并运行…*。请先检查这些更改：获批的工作流会以仓库的设置运行。

## 通知

你启动的运行结束时，GitLoom 可以通知你。在 **设置 ▸ Git ▸ GitHub Actions ▸ 我启动的 CI 完成时通知我** 中选择何时通知：从不、仅在失败时（默认）或总是。

> **Note** Actions 仅适用于 GitHub。对于 GitLab，暂不支持 CI 流水线，Actions 组会隐藏。
