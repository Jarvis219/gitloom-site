请在 [GitHub Issues](https://github.com/Jarvis219/gitloom-site/issues) 上报告错误和提出功能建议。

## 应包含的信息

- 你的 GitLoom 版本（**GitLoom ▸ 关于 GitLoom**，或 **设置 ▸ 通用 ▸ 更新**）和 macOS 版本。
- 导致问题的步骤。
- 你预期的结果，以及实际发生的情况。
- 截图，如果它能说明问题。

如果问题与 git 做的某件事有关，**窗口 ▸ Git 日志** 中的命令会有帮助（参阅[故障排除](/zh-hans/docs/troubleshooting/)）。要获取更多细节，请在 **设置 ▸ 高级** 中开启*写入调试日志*；其中 URL 里的密码和令牌会被隐藏。

> **Caution** 议题是公开的。切勿粘贴令牌、密码、SSH 密钥或私有代码。附加日志和截图前请先检查。

## 崩溃之后

如果 GitLoom 意外退出，下次启动时会询问是否报告。它提供：

- *在 GitHub 上报告…*：浏览器会打开一个新议题，其中已填好 GitLoom 和 macOS 版本、错误信息以及崩溃线程的顶部内容。阅读一遍，补充你当时在做什么，然后自己发送。
- *显示报告*：在访达中显示 macOS 保存的崩溃报告。
- *以后再说*。

除非你自己发送议题，否则不会发送任何内容。勾选*不再提示*，或在 **设置 ▸ 高级** 中关闭*提议报告崩溃*，即可不再询问。

**帮助 ▸ 报告问题…** 随时会在浏览器中打开一个空白议题。
