标有 ✎ 的 35 个快捷键（也就是菜单栏中的全部快捷键）可以在 **设置 ▸ 键盘** 中更改。其他快捷键（例如 <kbd>⌘W</kbd> 和 <kbd>⌘Z</kbd> 等系统快捷键，以及只在表单或编辑器中有效的按键）是固定的。菜单始终显示当前的按键，这里的所有操作也都可以在命令面板（<kbd>⌘K</kbd>）中找到。

## 随处可用

| 按键 | 动作 |
|---|---|
| <kbd>⌘K</kbd> ✎ | 命令面板：`>` 命令、`/` 文件、`:` 提交、`@` 作者、`#` 拉取请求和议题 |
| <kbd>⌘P</kbd> ✎ | 快速打开仓库中的文件 |
| <kbd>⌘F</kbd> / <kbd>⌘G</kbd> / <kbd>⇧⌘G</kbd> ✎ | 查找提交 / 下一个匹配项 / 上一个匹配项 |
| <kbd>⌘Z</kbd> / <kbd>⇧⌘Z</kbd> | 撤销 / 重做上一次 Git 操作（在文本栏中：撤销输入） |
| <kbd>⌘T</kbd> ✎ | 新建标签页 |
| <kbd>⌘W</kbd> | 关闭标签页 |
| <kbd>⌃⇥</kbd> / <kbd>⌃⇧⇥</kbd> ✎ | 下一个 / 上一个标签页 |
| <kbd>⇧⌘C</kbd> ✎ | 克隆仓库 |
| <kbd>⌘O</kbd> ✎ | 打开仓库（如果当前标签页已显示一个仓库，则在新标签页中打开） |
| <kbd>⇧⌘R</kbd> ✎ | 在访达中显示仓库 |
| <kbd>⌥⌘T</kbd> ✎ | 在你的终端应用中打开仓库 |
| <kbd>⇧⌘K</kbd> | Launchpad（你的 GitHub 和 GitLab 账户的拉取请求和议题） |
| <kbd>⌥⇧⌘L</kbd> ✎ | Git 日志（GitLoom 运行过的每条 git 命令） |
| <kbd>⌘,</kbd> | 设置 |
| <kbd>⌘?</kbd> | GitLoom 帮助 |

## 仓库

| 按键 | 动作 |
|---|---|
| <kbd>⇧⌘L</kbd> ✎ | 抓取所有远程 |
| <kbd>⇧⌘↓</kbd> ✎ | 拉取 |
| <kbd>⇧⌘↑</kbd> ✎ | 推送 |
| <kbd>⌘B</kbd> ✎ | 在所选提交处创建分支 |
| <kbd>⇧⌘S</kbd> ✎ | 贮藏所有更改 |
| <kbd>⌥⌘Y</kbd> ✎ | 所选文件的历史 |
| <kbd>⌥⌘B</kbd> ✎ | 所选文件的追溯 |
| <kbd>⌘0</kbd> ✎ | 显示或隐藏侧边栏 |
| <kbd>⌥⌘0</kbd> ✎ | 显示或隐藏详情面板 |
| <kbd>⌥⌘L</kbd> ✎ | 将详情面板移到底部 / 移回右侧 |

## 提交图、更改和差异

| 按键 | 动作 |
|---|---|
| <kbd>↑</kbd> <kbd>↓</kbd> 或 <kbd>J</kbd> <kbd>K</kbd> | 上一个 / 下一个提交 |
| <kbd>⇧</kbd>-点按、<kbd>⌘</kbd>-点按 | 选择一个范围 / 多个提交（比较、压缩、拣选） |
| <kbd>⌘C</kbd> | 拷贝所选提交的 SHA |
| <kbd>⌘Y</kbd> | 快速查看所选文件 |
| <kbd>⇧⌘A</kbd> | 全部暂存 |
| <kbd>⌥⇧⌘A</kbd> | 全部取消暂存 |
| <kbd>⌘↩</kbd> | 提交（在提交信息中） |
| <kbd>⌥⌘G</kbd> | 用 AI 撰写提交信息（开启 AI 时） |
| <kbd>⌥↑</kbd> / <kbd>⌥↓</kbd> | 文件中的上一处 / 下一处更改 |
| <kbd>⌥⌘↑</kbd> / <kbd>⌥⌘↓</kbd> | 上一个 / 下一个文件 |

## 编辑器

| 按键 | 动作 |
|---|---|
| <kbd>⌘E</kbd> ✎ | 编辑打开的文件 |
| <kbd>⌘S</kbd> ✎ | 保存 |
| <kbd>⌥⌘S</kbd> ✎ | 保存并暂存 |
| <kbd>⌘L</kbd> ✎ | 前往行 |
| <kbd>⌥⌘F</kbd> ✎ | 查找和替换 |
| <kbd>⌘/</kbd> ✎ | 注释或取消注释所选行 |
| <kbd>⌘]</kbd> / <kbd>⌘[</kbd> ✎ | 增加 / 减少所选行的缩进 |
| <kbd>P</kbd> <kbd>R</kbd> <kbd>E</kbd> <kbd>S</kbd> <kbd>F</kbd> <kbd>C</kbd> <kbd>D</kbd> | 交互式变基：为所选行设置 pick、reword、edit、squash、fixup、fixup -C、drop |
| <kbd>⌥↑</kbd> / <kbd>⌥↓</kbd> | 交互式变基：移动所选行（开启*保留合并*时，只能在其所在分支内移动） |
| <kbd>⌘Z</kbd> / <kbd>⇧⌘Z</kbd> | 交互式变基：撤销 / 重做对计划的更改（开始之前不会动到 git） |
| <kbd>⌘↩</kbd> | 交互式变基：开始变基（或保存剩余的计划） |
| Esc | 交互式变基：关闭编辑器，不执行任何操作 |
| <kbd>⌥⌘↑</kbd> / <kbd>⌥⌘↓</kbd> | 合并冲突：上一个 / 下一个冲突 |
| <kbd>⌘S</kbd> | 合并冲突：保存并将文件标记为已解决 |
| <kbd>⌘[</kbd> / <kbd>⌘]</kbd> | 文件历史：后退 / 前进 |

## 终端

| 按键 | 动作 |
|---|---|
| <kbd>⌃`</kbd> ✎ | 显示或隐藏终端（终端有焦点时隐藏它） |
| <kbd>⌃⇧`</kbd> ✎ | 新建终端会话 |
| <kbd>⌘+</kbd> / <kbd>⌘−</kbd> ✎ | 放大 / 缩小终端文字 |
| <kbd>⇥</kbd> 或 <kbd>→</kbd> | 插入所选建议 |
| <kbd>↑</kbd> <kbd>↓</kbd> | 选择建议 |
| Esc | 关闭建议；在空提示符处时返回提交图（隐藏终端也是如此） |
| <kbd>⌘</kbd>-点按 | 打开指针下的内容：SHA 选中提交，路径打开文件，URL 打开浏览器 |
