GitLoom 有三种查找方式：用“查找”找提交，用命令面板找任何东西，用“快速打开”找文件。

## 查找提交

<kbd>⌘F</kbd> 搜索提交信息、作者、SHA、文件路径或更改内容（`-S`，即添加或删除某段文本的提交）。它可以将提交图筛选为只显示匹配项。<kbd>⌘G</kbd> 和 <kbd>⇧⌘G</kbd> 前往下一个和上一个匹配项。

- 不区分变音符号：“nguoi” 能找到 “người”。
- `re:` 后接针对整条信息的正则表达式，例如 `re:^fix(ed)?:`。

## 命令面板

<kbd>⌘K</kbd> 运行任何命令，并跳转到分支、文件、提交、作者和拉取请求。以某个字符开头即可只搜索一类内容：

| 前缀 | 搜索 |
|---|---|
| `>` | 命令 |
| `/` | 文件 |
| `:` | 提交 |
| `@` | 作者 |
| `#` | 拉取请求和议题 |

## 快速打开

<kbd>⌘P</kbd> 打开仓库中的任意文件。打开后，<kbd>⌘E</kbd> 让你编辑它（参阅[文件编辑器](/zh-hans/docs/file-editor/)）。
