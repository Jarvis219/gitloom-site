添加 GitHub 或 GitLab 账户后（参阅 [GitHub](/zh-hans/docs/github/) 和 [GitLab](/zh-hans/docs/gitlab/)），侧边栏会列出仓库的拉取请求（在 GitLab 上称为合并请求）。

![显示拉取请求和 GitHub Actions 运行的侧边栏](/shots/actions-light.png)

## 创建拉取请求

- 为当前分支选择 **仓库 ▸ GitHub / GitLab ▸ 创建拉取请求…**。
- 或者在提交图上把一个分支拖放到另一个分支上。

审查者、负责人和标签旁的 ▾ 可以从仓库的列表中选择。开启 AI 后，GitLoom 可以撰写描述（参阅[选择提供商](/zh-hans/docs/choosing-a-provider/)）。

## 审查

打开拉取请求即可查看其差异。你可以对行发表评论、批准和合并。在差异中，*回复* 在审查讨论中作答，*解决* 关闭该讨论。

GitLab 暂不支持行评论。

## Launchpad

**Launchpad**（<kbd>⇧⌘K</kbd>）列出跨仓库和账户等待你处理的拉取请求和议题。右键点按某一项可以打开它的仓库、在浏览器中打开它，或推迟它：推迟 1 小时、到明天、到下周，或直到它有变化。
