**设置 ▸ 布局** 控制窗口中各部分的位置。更改立即生效。

## 面板和差异

- *详情面板*：在右侧或提交图下方。<kbd>⌥⌘L</kbd> 也能切换。
- *显示状态栏*。
- *打开差异*：覆盖在提交图上，或显示在其下方，让提交图保持可见。
- 差异样式，以及*为每个文件记住差异样式*。
- 标签栏：将标签页颜色显示为标签页上的圆点、在工具栏下方显示颜色线条，以及只有一个标签页时是否显示标签栏。

## 工具栏

选择工具栏显示哪些按钮、它们的顺序，以及标签文字的样式。

## 提交图列

为所有仓库开启或关闭“分支 / 标签”、CI、“更改（+/−）”、作者、日期和 SHA 列。“提交图”和“提交信息”始终显示。在提交图中右键点按列标题只会更改该仓库。

## 侧边栏

显示、隐藏侧边栏分组并调整其顺序。额外的分组（拉取请求、Actions、议题、子模块、工作树和 Git LFS 文件）只在适用时显示；在这里隐藏某个分组，会在所有地方隐藏它。*将名为“prefix/…”的本地分支显示为文件夹* 会将 `feature/login` 这类分支归入文件夹。

## 预设

输入名称并点按*保存当前布局*，即可保留当前的排列，例如用于小屏幕。在这里或从 **显示 ▸ 布局** 应用预设。*恢复默认布局* 会回到默认布局，你也可以在同一处撤销这一操作。
