GitLoom 中的大多数问题都可以撤销或得到解释。从这里开始。

## 仓库出了问题

- **先撤销**：<kbd>⌘Z</kbd> 或 **编辑 ▸ 操作历史…**。大多数操作都可以撤销（参阅[撤销和重做](/zh-hans/docs/undo-and-redo/)）。
- **提交似乎不见了**：**仓库 ▸ Reflog…** 和 **查找丢失的提交…** 能找到它们（参阅[通过 reflog 恢复](/zh-hans/docs/reflog-recovery/)）。
- **卡在变基或合并中**：停在中途的仓库会显示一条带有*继续*和*中止*的横幅，重新启动 GitLoom 后也是如此。

## 查看 GitLoom 做了什么

**窗口 ▸ Git 日志**（<kbd>⌥⇧⌘L</kbd>）列出 GitLoom 运行过的每条 git 命令：仓库、命令、耗时和退出码。只保留命令行，绝不保留其输出、输入或凭据。

工具栏下方有一条细细的移动线条，表示 git 正在与远程通信；将指针悬停其上可查看详情。耗时较长的操作，其消息中会有*取消*。

## 常见问题

- **GitLoom 找不到 git，或提示版本太旧。** 安装 git 2.40 或更高版本（参阅[安装](/zh-hans/docs/install/)），或在 **设置 ▸ Git ▸ Git 可执行文件** 中选择其他 git。
- **钩子找不到 node、python 或代码检查工具。** 在 **设置 ▸ Git ▸ 钩子** 的*额外 PATH* 中添加所需的文件夹。这适用于之后打开的仓库。
- **钩子卡住了。** 如果钩子在一分钟后仍在运行，提交会提示这一点并提供*停止*。**设置 ▸ Git ▸ 钩子** 中的*超时后停止钩子* 会自动停止它（默认 10 分钟后）。
- **使用了错误的 SSH 密钥。** 设置 [SSH 账户](/zh-hans/docs/ssh-accounts/)。

## 日志和缓存

在 **设置 ▸ 高级** 中：

- *写入调试日志* 会把 GitLoom 运行的 git 命令及其退出状态和耗时记录到日志文件夹中的一个文件里。URL 中的密码和令牌会被隐藏。*显示日志文件夹* 会打开该文件夹。
- *清除缓存…* 会移除为离线使用而保存的拉取请求和议题，以及缓存的文件版本。需要时会重新获取。
- 如果你的设置文件无法读取，GitLoom 会把它移到一旁，以默认设置启动，并在这里说明。

如果以上都没有帮助，请[报告问题](/zh-hans/docs/report-an-issue/)。
