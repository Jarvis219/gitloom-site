档案保存你提交时使用的身份：姓名、邮箱以及可选的签名密钥。例如，一个用于工作，一个用于个人项目。在 **设置 ▸ 档案** 中设置。

## 档案包含什么

每个档案包括：

- 档案名称，以及提交用的姓名（`user.name`）和邮箱（`user.email`）；
- 签名方式：不签名、SSH、GPG 或 X.509，以及是否默认签名提交；
- 可选的推送账户，在 [SSH 账户](/zh-hans/docs/ssh-accounts/)规则无法决定时使用；
- 自己的已打开标签页和最近仓库。

GitLoom 会将姓名、邮箱和签名密钥写入每个仓库的 git 配置，因此终端与 GitLoom 保持一致。

## 切换档案

通过窗口右上角的标签切换档案。其中一个档案是默认档案：GitLoom 启动时使用它，正在使用的档案被删除时也会回到它。用*设为默认*更改默认档案。

## 身份不对

GitLoom 会在提交按钮上方显示你将以谁的身份提交。如果该邮箱不是仓库所属档案的邮箱，这一行会带有警告标记；从工具栏的档案标签中选择正确的档案即可修正。

## 移除档案

选中它并点按 −。它的已打开标签页和最近仓库会被清除。已写入仓库的 git 配置保持不变。始终至少保留一个档案。
