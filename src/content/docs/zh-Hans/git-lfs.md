当你的 Mac 上安装了 `git-lfs` 时，GitLoom 可以配合 Git LFS 使用。没有它，GitLoom 仍能列出 LFS 文件，但无法下载或锁定它们。

## “GIT LFS”组

在使用 LFS 的仓库中，侧边栏有一个“GIT LFS”组，列出 LFS 文件。尚未下载（磁盘上只有指针）的文件带有下载图标。已锁定的文件会显示是谁锁定的。连按两下文件即可打开。

右键点按文件可以：

- *打开文件*；
- *下载此文件*，当这里只有它的指针时；
- *锁定* 或*解锁*。

## 下载所有 LFS 文件

**仓库 ▸ 高级 ▸ 下载 Git LFS 文件** 会运行 `git lfs pull`，下载此检出中的大文件。

## 跟踪新的文件类型

右键点按暂存区中已更改的文件 ▸ *用 LFS 跟踪（\*.ext）*，即可跟踪所有带该扩展名的文件。在已经使用 LFS 的仓库中，同一菜单还有*锁定（LFS）*和*解锁（LFS）*。
