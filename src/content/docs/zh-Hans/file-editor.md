GitLoom 可以显示和编辑仓库中的文件，所以小修改不需要另开应用。

## 打开文件

- <kbd>⌘P</kbd>（快速打开）打开仓库中的任意文件。
- 侧边栏的“引用/文件”开关显示文件树。在那里你还可以*新建文件…* 或*新建文件夹…*、*重命名…* 或*移到废纸篓*，以及*显示已忽略的文件*。

文件以查看模式打开。按 <kbd>⌘E</kbd> 或点按*编辑文件*即可编辑。Esc 返回提交图。

## 编辑按键

| 按键 | 动作 |
|---|---|
| <kbd>⌘S</kbd> | 保存 |
| <kbd>⌥⌘S</kbd> | 保存并暂存 |
| <kbd>⌘L</kbd> | 前往行 |
| <kbd>⌥⌘F</kbd> | 查找和替换 |
| <kbd>⌘/</kbd> | 注释或取消注释所选行 |
| <kbd>⌘]</kbd> / <kbd>⌘[</kbd> | 增加 / 减少所选行的缩进 |

编辑器的选项包括*自动换行*、*显示空格和制表符*、*自动闭合括号和引号*以及*装订线与 HEAD 比较*。代码字体及其大小在 **设置 ▸ 外观** 中设置。

## 文件在磁盘上被更改时

如果在你有未保存的编辑时另一个应用更改了该文件，GitLoom 会告诉你，并提供*保留我的版本*、*重新载入*或*比较*。带有冲突标记的文件会提示：保存它并不会将其标记为已解决；请使用[冲突编辑器](/zh-hans/docs/resolving-conflicts/)来完成。

文件有未保存的更改时，GitLoom 也会等待再安装更新。

## 其他编辑器

*在外部编辑器中打开* 会在 **设置 ▸ 集成 ▸ 打开文件方式** 中选择的应用里打开文件。那里的*自定义命令*优先于该设置；`$FILE`、`$LINE` 和 `$REPO` 会被自动填入，例如：

```sh
code -g $FILE:$LINE
```
