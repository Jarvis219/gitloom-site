安装 GitLoom 后，打开一个已有的仓库或克隆一个仓库。GitLoom 做的每件事都与对应的 `git` 命令相同，所以你随时可以切换到终端。

## 打开仓库

将仓库的文件夹拖到 GitLoom 窗口上，或从开始页面或最近列表中选择。<kbd>⌘O</kbd> 也能打开仓库；如果当前标签页已显示一个仓库，它会在新标签页中打开。

## 克隆仓库

按 <kbd>⇧⌘C</kbd> 并粘贴任意 URL。添加 GitHub 或 GitLab 账户后（参阅 [GitHub](/zh-hans/docs/github/) 和 [GitLab](/zh-hans/docs/gitlab/)），你也可以从账户的仓库中选择。

## 标签页

每个仓库都在自己的标签页中打开。<kbd>⌘T</kbd> 打开新标签页，<kbd>⌃⇥</kbd> 切换到下一个。下次启动 GitLoom 时，你的标签页会恢复。要更改这一点，请使用 **设置 ▸ 通用** 中的*启动时*：重新打开上次的标签页、先询问，或启动时不打开任何仓库。

## 你的姓名和邮箱

如果 git 还没有 `user.name` 或 `user.email`，GitLoom 会在你第一次提交前询问。如果你在不同类型的工作中使用不同身份，请设置[档案](/zh-hans/docs/profiles/)。

## 下一步

- 认识[窗口](/zh-hans/docs/the-window/)的各个部分。
- 完成你的第一次[提交](/zh-hans/docs/committing/)。
- 按 <kbd>⌘K</kbd> 打开命令面板，它可以运行任何命令，并跳转到分支、文件和提交。
