其他 AI 工具（Claude Code、Claude Desktop、Cursor、VS Code 等）可以通过 GitLoom 的 MCP 服务器处理你的仓库。在你开启之前，它保持关闭。

## 开启

在 **设置 ▸ 集成 ▸ MCP 服务器** 中，将*外部 AI 工具可以*设为以下之一：

- *不执行任何操作（关闭）*；
- *读取：状态、历史、差异、追溯*；
- *读取并更改：还可提交、建分支、贮藏、拉取、推送*。

然后连接你的工具。对于 Claude Code，拷贝那里显示的那行命令并在终端中运行；它看起来像这样：

```sh
claude mcp add gitloom -- "/Applications/GitLoom.app/Contents/Helpers/gitloom-mcp"
```

对于其他工具，将那里显示的 JSON 拷贝到该工具的 MCP 配置中。GitLoom 从不编辑其他工具的文件。`gitloom mcp` 命令也能运行该服务器（参阅[gitloom 命令行工具](/zh-hans/docs/the-gitloom-command-line-tool/)）。

## 读取

工具可以查看已打开或在开始页面最近列表中的仓库的状态、历史、差异、追溯、分支和贮藏。GitLoom 运行时，它们还可以询问你正在查看什么，例如所选的提交或打开的文件。它们不能更改任何内容。

## 读取并更改

在 GitLoom 运行期间，对于在标签页中打开的仓库，工具还可以暂存、提交、创建和切换分支、贮藏、抓取、拉取（仅快进）和推送。每次更改都会显示在窗口中，附带工具的名称和一个*撤销*按钮，并记入操作历史。

开启*推送前询问*后，推送会在仓库窗口中等待你的回答；60 秒后会被拒绝。

任何工具都不能强制推送、重置、丢弃、删除或改写历史。

## 拉取请求、议题和 CI

开启*通过我的账户获取拉取请求、议题和 CI* 后，工具可以通过 GitLoom 中连接的账户读取仓库的拉取请求、议题和 CI 运行。若选择*读取并更改*，它们还可以为当前分支创建拉取请求并发表评论。它们永远看不到你的令牌，也不能合并、批准或关闭任何内容。

设置中的*最近活动*会显示最近的调用。
