프로필에는 커밋에 쓰는 신원이 담깁니다: 이름, 이메일, 그리고 선택적으로 서명 키입니다. 예를 들어 업무용과 개인 프로젝트용으로 하나씩 쓰세요. **설정 ▸ 프로필**에서 설정합니다.

## 프로필에 담기는 것

각 프로필에는 다음이 있습니다:

- 프로필 이름, 그리고 커밋 이름(`user.name`)과 이메일(`user.email`);
- 서명 방식: 서명 안 함, SSH, GPG, X.509, 그리고 기본적으로 커밋에 서명할지 여부;
- [SSH 계정](/ko/docs/ssh-accounts/) 규칙으로 정해지지 않을 때 푸시에 쓸 계정(선택 사항);
- 프로필별로 열린 탭과 최근 저장소.

GitLoom은 이름, 이메일, 서명 키를 각 저장소의 git 설정에 기록하므로 터미널도 GitLoom과 같게 동작합니다.

## 프로필 전환

창 오른쪽 위의 칩에서 프로필을 전환하세요. 프로필 하나가 기본값입니다. GitLoom은 이 프로필로 시작하며, 사용 중인 프로필이 삭제되면 이 프로필로 돌아갑니다. 기본 프로필을 바꾸려면 *기본값으로 설정*을 사용하세요.

## 잘못된 신원

GitLoom은 커밋 버튼 위에 어떤 신원으로 커밋하는지 보여 줍니다. 그 이메일이 저장소 프로필의 이메일과 다르면 그 줄에 경고가 표시됩니다. 도구 막대의 칩에서 올바른 프로필을 골라 고치세요.

## 프로필 제거

프로필을 선택하고 −를 클릭하세요. 열려 있던 탭과 최근 저장소는 잊힙니다. 이미 저장소에 기록된 git 설정은 그대로 남습니다. 프로필은 항상 하나 이상 있습니다.
