GitHub 또는 GitLab 계정을 추가하면([GitHub](/ko/docs/github/)와 [GitLab](/ko/docs/gitlab/) 참고) 사이드바에 저장소의 풀 리퀘스트(GitLab에서는 머지 리퀘스트)가 표시됩니다.

![풀 리퀘스트와 GitHub Actions 실행이 있는 사이드바](/shots/actions-light.png)

## 풀 리퀘스트 만들기

- 현재 브랜치에 대해 **저장소 ▸ GitHub / GitLab ▸ 풀 리퀘스트 만들기…**.
- 또는 그래프에서 브랜치를 다른 브랜치 위에 놓습니다.

리뷰어, 담당자, 레이블 옆의 ▾로 저장소의 목록에서 고를 수 있습니다. AI를 켜 두었다면 GitLoom이 설명을 써 줄 수 있습니다([제공자 선택](/ko/docs/choosing-a-provider/) 참고).

## 리뷰

풀 리퀘스트를 열면 diff를 볼 수 있습니다. 줄에 댓글을 달고, 승인하고, 병합할 수 있습니다. diff에서 *답글*은 리뷰 스레드에 답하고 *해결*은 스레드를 닫습니다.

GitLab에서는 아직 줄 댓글을 사용할 수 없습니다.

## Launchpad

**Launchpad**(<kbd>⇧⌘K</kbd>)는 여러 저장소와 계정에 걸쳐 나를 기다리는 풀 리퀘스트와 이슈를 나열합니다. 항목을 오른쪽 클릭해 저장소를 열거나, 브라우저에서 열거나, 다시 알림을 설정할 수 있습니다: 1시간, 내일까지, 다음 주까지, 변경될 때까지.
