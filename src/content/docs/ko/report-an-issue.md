버그 신고와 기능 요청은 [GitHub Issues](https://github.com/Jarvis219/gitloom-site/issues)에서 하세요.

## 포함할 내용

- GitLoom 버전(**GitLoom ▸ GitLoom에 관하여** 또는 **설정 ▸ 일반 ▸ 업데이트**)과 macOS 버전.
- 문제로 이어지는 단계.
- 기대한 결과와 실제로 일어난 일.
- 문제가 보인다면 스크린샷.

git이 한 일에 관한 문제라면 **윈도우 ▸ Git 로그**의 명령이 도움이 됩니다([문제 해결](/ko/docs/troubleshooting/) 참고). 더 자세한 정보가 필요하면 **설정 ▸ 고급**에서 *디버그 로그 기록*을 켜세요. URL의 암호와 토큰은 그곳에서 숨겨집니다.

> **Caution** 이슈는 공개됩니다. 토큰, 암호, SSH 키, 비공개 코드를 절대 붙여 넣지 마세요. 로그와 스크린샷은 첨부하기 전에 확인하세요.

## 충돌 후

GitLoom이 예기치 않게 종료되면 다음 실행 시 보고할지 묻습니다. 다음을 제안합니다:

- *GitHub에 보고…*: 브라우저에 GitLoom과 macOS 버전, 오류, 충돌한 스레드의 윗부분이 채워진 새 이슈가 열립니다. 내용을 읽고, 하던 작업을 덧붙인 다음 직접 보내세요.
- *보고서 보기*: macOS가 저장한 충돌 보고서를 Finder에서 보여 줍니다.
- *나중에*.

이슈를 직접 보내지 않으면 아무것도 전송되지 않습니다. 질문을 그만 받으려면 *다시 제안하지 않음*을 체크하거나 **설정 ▸ 고급**에서 *충돌 보고 제안*을 끄세요.

**도움말 ▸ 문제 신고…** 는 언제든 브라우저에 빈 이슈를 엽니다.
