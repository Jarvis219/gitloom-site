<kbd>⌃`</kbd>를 누르면 그래프 아래에 저장소 폴더에서 로그인 셸로 터미널이 열립니다. 터미널에서 git 명령이 끝나는 즉시 그래프가 새로 고쳐집니다.

## 제안과 링크

git 명령을 입력하는 동안 GitLoom이 하위 명령, 브랜치, 원격, 별칭을 제안합니다. <kbd>↑</kbd> <kbd>↓</kbd>로 제안을 고르고, <kbd>⇥</kbd> 또는 <kbd>→</kbd>로 삽입하며, Esc로 목록을 닫습니다.

포인터 아래의 항목을 <kbd>⌘</kbd>-클릭하세요: SHA는 그 커밋을 선택하고, 경로는 파일을 열고, URL은 브라우저를 엽니다.

## 키

| 키 | 동작 |
|---|---|
| <kbd>⌃`</kbd> | 터미널 표시 또는 숨기기(포커스가 있으면 숨김) |
| <kbd>⌃⇧`</kbd> | 새 터미널 세션 |
| <kbd>⌘+</kbd> / <kbd>⌘−</kbd> | 터미널 글자 크게 / 작게 |
| Esc | 빈 프롬프트에서 그래프로 돌아가기 |

탭을 닫을 때 명령이 아직 실행 중이면 GitLoom이 먼저 묻습니다.

## 설정

**설정 ▸ 통합 ▸ 터미널**에는 다음이 있습니다:

- *셸 통합*: GitLoom이 명령이 끝나는 시점을 알 수 있게 합니다(즉시 새로 고침, 제안). 끄면 이 기능들이 멈춥니다. 어느 쪽이든 dotfile은 절대 수정하지 않습니다.
- *입력하는 동안 git 명령 제안*: 제안만 끌 때 사용합니다.
- *스크롤백*: 세션마다 보관할 줄 수(기본값 10,000).
- *GitLoom이 실행하는 git 명령 표시*: 앱이 실행하는 명령마다 흐린 줄을 표시해 git을 배울 수 있습니다.
- *보안 키보드 입력*: 터미널이 키보드를 사용하는 동안 다른 앱이 입력 내용을 읽을 수 없습니다.
- *셸*과 *인수*: `/opt/homebrew/bin/fish`처럼 새 세션에 쓸 다른 셸. 실행할 수 없는 경로이면 로그인 셸로 대체됩니다.

변경 사항은 새 터미널 세션에 적용됩니다. 터미널은 **설정 ▸ 모양**의 코드 글꼴을 사용합니다.

## 평소 쓰는 터미널 앱

<kbd>⌥⌘T</kbd>는 대신 평소 쓰는 터미널 앱에서 저장소를 엽니다. 어떤 앱을 쓸지는 **설정 ▸ 통합 ▸ “터미널에서 열기”에 사용**에서 선택하세요.
