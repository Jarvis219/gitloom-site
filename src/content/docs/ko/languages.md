GitLoom의 인터페이스는 16개 언어로 제공됩니다. 기본적으로 시스템 언어를 따릅니다.

## 언어 선택

**설정 ▸ 일반 ▸ 언어**를 열고 언어를 고르거나, macOS를 따르려면 *시스템*을 고르세요. 새 언어는 GitLoom을 다시 시작한 뒤 적용됩니다. *지금 재시작*을 누르면 탭을 유지한 채 다시 시작합니다.

## 영어로 남는 것

git 명령과 용어(commit, branch, merge 등)의 이름은 영어로 남습니다. GitLoom 실행 중에 만들어지는 일부 메시지는 현재 영어로만 제공됩니다.

## AI가 쓰는 언어

AI가 쓰는 커밋 메시지와 그 밖의 텍스트는 별도 설정이 있습니다: **설정 ▸ AI ▸ 작성 ▸ 언어**, English 또는 Tiếng Việt.
