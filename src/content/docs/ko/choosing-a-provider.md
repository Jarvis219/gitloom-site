AI 기능은 기본적으로 꺼져 있습니다. 켜면 누가 답할지 고릅니다: 본인 키를 쓰는 클라우드 제공자, 또는 Mac에서 실행되는 모델.

## 켜기

**설정 ▸ AI**를 열고 *AI 기능*을 켜세요. GitLoom이 먼저 무엇이 누구에게 전송되는지 설명합니다.

*제공자*를 선택하세요:

- Anthropic, OpenAI, Google Gemini, OpenRouter, Groq, Mistral, DeepSeek, Qwen(Alibaba Cloud), xAI, Together AI;
- 로컬에서 실행되는 Ollama 또는 LM Studio. 데이터가 Mac을 떠나지 않습니다;
- 사용자 지정 제공자: 회사 게이트웨이처럼 Anthropic, OpenAI, Gemini, Ollama API를 지원하는 서버. *사용자 지정 제공자 추가…* 로 추가합니다.

API 키를 붙여 넣고 *키 저장*을 클릭하세요. 키는 키체인에 저장됩니다. *테스트*는 키를 확인하고 제공자의 모델을 불러오므로 하나를 고를 수 있습니다.

## AI가 할 수 있는 일

- 커밋 메시지(<kbd>⌥⌘G</kbd>), 풀 리퀘스트 설명, 스태시 메시지 작성.
- 커밋, 브랜치, 변경 사항 설명과 후속 질문.
- 충돌 해결 방법 제안.

요청하기 전에는 아무것도 전송되지 않습니다. 네트워크가 없으면 ✨ 버튼이 흐리게 표시되지만, 로컬 모델은 계속 작동합니다.

## 작성 방식 조정

*작성*에서 언어(English 또는 Tiếng Việt)와 커밋 스타일을 고르세요: Conventional Commits, 저장소 기록과 같게, 자유.

*기능별 설정 보기*를 누르면 기능마다 고유한 모델과 *사용자 지정 지침*을 지정할 수 있습니다. 옆에 있는 **템플릿** 메뉴는 Conventional Commits, 브랜치에서 가져온 티켓 ID, 풀 리퀘스트 개요, 버그만 보는 리뷰 같은 미리 만든 설정을 채워 주며, 팀에 맞게 고쳐 쓸 수 있습니다.

## 저장소 하나에서 끄기

커밋 메시지 옆의 ✨ 메뉴에서 *이 저장소에서 AI 끄기*를 선택하세요. 다시 켜려면 **설정 ▸ AI ▸ AI를 끈 대상**을 사용하세요.

전송하기 전에 정확한 요청 내용을 볼 수 있습니다. [전송되는 내용](/ko/docs/what-gets-sent/)을 참고하세요.
