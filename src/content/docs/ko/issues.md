GitHub 또는 GitLab 계정을 추가하면 GitLoom이 사이드바에 저장소의 이슈를 표시합니다.

## 만들기와 둘러보기

- **저장소 ▸ GitHub / GitLab ▸ 새 이슈…** 는 이슈를 만듭니다.
- 사이드바의 이슈 그룹에서 저장소의 이슈를 둘러봅니다. 레이블과 마일스톤으로 필터링할 수 있습니다.
- 이슈를 오른쪽 클릭하면 *이슈에서 브랜치 만들기*, *브라우저에서 열기*, *링크 복사*를 사용할 수 있습니다.
- 명령 팔레트(<kbd>⌘K</kbd>)에서 `#`을 입력하면 풀 리퀘스트와 이슈를 찾습니다.
- **Launchpad**(<kbd>⇧⌘K</kbd>)는 여러 저장소에 걸쳐 나를 기다리는 이슈를 나열합니다.

## 이슈에서 브랜치 시작하기

*이슈에서 브랜치 만들기*는 이슈 이름을 딴 브랜치를 만듭니다. 이름은 **설정 ▸ Git ▸ 이슈에서 브랜치 만들기**의 템플릿을 따르며, 기본값은 `{type}/{number}-{slug}`입니다. 여기서 `{type}`은 `fix` 또는 `feat`입니다. 팀의 `.gitloom/team.json` 템플릿이 내 템플릿보다 우선합니다.
