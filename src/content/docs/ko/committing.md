*Uncommitted changes* 행을 선택하고, 원하는 내용을 스테이징한 다음([한 줄씩 스테이징](/ko/docs/staging-single-lines/) 참고), 메시지를 쓰고 <kbd>⌘↩</kbd>를 누르세요.

## 커밋 양식

- *수정*은 새 커밋을 만드는 대신 마지막 커밋을 고칩니다. 체크되어 있는 동안에는 그 커밋이 이미 변경한 파일도 함께 표시됩니다.
- *공동 작성자*는 최근 기록에 있는 사람을 제안하며, 전에 추가한 공동 작성자도 포함합니다.
- 커밋이 실행되는 동안 훅이 출력하는 내용(`pre-commit` 린터, 테스트)이 메시지 아래에 표시됩니다. 1분이 지나도 훅이 계속 실행 중이면 GitLoom이 알리고 *중지*를 제안합니다.
- 어떤 신원으로 커밋하는지 보여 주는 줄이 있습니다. 이메일이 저장소의 [프로필](/ko/docs/profiles/)과 맞지 않거나 GitHub 계정의 이메일이 아니면(GitHub가 커밋을 본인과 연결하지 못함) 경고합니다.

AI를 켜 두었다면 <kbd>⌥⌘G</kbd>로 메시지를 대신 쓰게 할 수 있습니다([제공자 선택](/ko/docs/choosing-a-provider/) 참고).

## 메시지 설정

**설정 ▸ Git ▸ 커밋 메시지**에서 양식의 시작 템플릿과, 요약 길이 카운터가 노란색과 빨간색으로 바뀌는 길이(기본값 50자와 72자)를 설정할 수 있습니다. 경고만 할 뿐 잘라 내지는 않습니다. 저장소 자체의 `commit.template`이 이 템플릿보다 우선합니다.

## git이 보여 주지 않는 파일

- 이미 추적 중인 파일을 *무시*하면 GitLoom이 *추적 중지*(`git rm --cached`)를 제안합니다. 파일은 다음 커밋에서 저장소에서 빠지고 디스크에는 남습니다.
- 로컬 설정처럼 일부러 변경하는 추적 파일은 변경된 파일을 오른쪽 클릭 ▸ *로컬 변경 숨기기*를 선택하세요. 파일 목록 위의 줄에 숨긴 파일 수가 표시되고, *보기…* 로 다시 표시할 수 있습니다.
- Mac 디스크에서는 Finder에서 `readme.md`를 `README.md`로 이름을 바꿔도 git이 알아차리지 못합니다. GitLoom은 이를 감지하고 *이름 변경 기록*을 제안합니다.

## 커밋 실행 취소

<kbd>⌘Z</kbd>는 마지막 커밋이나 수정을 실행 취소합니다. [실행 취소와 다시 실행](/ko/docs/undo-and-redo/)을 참고하세요.
