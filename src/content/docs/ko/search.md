GitLoom에서 무언가를 찾는 방법은 세 가지입니다. 커밋은 찾기, 무엇이든 명령 팔레트, 파일은 빠른 열기입니다.

## 커밋 찾기

<kbd>⌘F</kbd>는 커밋 메시지, 작성자, SHA, 파일 경로, 변경 내용(`-S`, 어떤 텍스트를 추가하거나 제거한 커밋)을 검색합니다. 그래프를 일치하는 항목만 남도록 필터링할 수 있습니다. <kbd>⌘G</kbd>와 <kbd>⇧⌘G</kbd>로 다음 및 이전 일치 항목으로 이동합니다.

- 악센트 부호는 무시됩니다: “nguoi”로 “người”를 찾습니다.
- `re:`는 메시지 전체에 대한 정규 표현식을 받습니다. 예: `re:^fix(ed)?:`.

## 명령 팔레트

<kbd>⌘K</kbd>는 어떤 명령이든 실행하고 브랜치, 파일, 커밋, 작성자, 풀 리퀘스트로 바로 이동합니다. 특정 문자로 시작하면 한 종류만 검색합니다:

| 접두사 | 검색 대상 |
|---|---|
| `>` | 명령 |
| `/` | 파일 |
| `:` | 커밋 |
| `@` | 작성자 |
| `#` | 풀 리퀘스트와 이슈 |

## 빠른 열기

<kbd>⌘P</kbd>는 저장소의 아무 파일이나 엽니다. 파일이 열리면 <kbd>⌘E</kbd>로 편집할 수 있습니다([파일 편집기](/ko/docs/file-editor/) 참고).
