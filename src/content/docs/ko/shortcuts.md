✎ 표시가 있는 단축키 35개는 모두 메뉴 막대에 있으며, **설정 ▸ 키보드**에서 바꿀 수 있습니다. 나머지(<kbd>⌘W</kbd>와 <kbd>⌘Z</kbd> 같은 시스템 단축키, 시트나 편집기 안에서만 작동하는 키)는 고정되어 있습니다. 메뉴에는 항상 현재 키가 표시되며, 여기 있는 모든 기능은 명령 팔레트(<kbd>⌘K</kbd>)에도 있습니다.

## 어디서나

| 키 | 동작 |
|---|---|
| <kbd>⌘K</kbd> ✎ | 명령 팔레트: `>` 명령, `/` 파일, `:` 커밋, `@` 작성자, `#` 풀 리퀘스트와 이슈 |
| <kbd>⌘P</kbd> ✎ | 저장소의 파일 빠른 열기 |
| <kbd>⌘F</kbd> / <kbd>⌘G</kbd> / <kbd>⇧⌘G</kbd> ✎ | 커밋 찾기 / 다음 일치 항목 / 이전 일치 항목 |
| <kbd>⌘Z</kbd> / <kbd>⇧⌘Z</kbd> | 마지막 Git 작업 실행 취소 / 다시 실행(텍스트 필드에서는 입력 실행 취소) |
| <kbd>⌘T</kbd> ✎ | 새 탭 |
| <kbd>⌘W</kbd> | 탭 닫기 |
| <kbd>⌃⇥</kbd> / <kbd>⌃⇧⇥</kbd> ✎ | 다음 / 이전 탭 |
| <kbd>⇧⌘C</kbd> ✎ | 저장소 복제 |
| <kbd>⌘O</kbd> ✎ | 저장소 열기(현재 탭에 이미 저장소가 있으면 새 탭에서) |
| <kbd>⇧⌘R</kbd> ✎ | Finder에서 저장소 보기 |
| <kbd>⌥⌘T</kbd> ✎ | 평소 쓰는 터미널 앱에서 저장소 열기 |
| <kbd>⇧⌘K</kbd> | Launchpad(GitHub와 GitLab 계정의 풀 리퀘스트와 이슈) |
| <kbd>⌥⇧⌘L</kbd> ✎ | Git 로그(GitLoom이 실행한 모든 git 명령) |
| <kbd>⌘,</kbd> | 설정 |
| <kbd>⌘?</kbd> | GitLoom 도움말 |

## 저장소

| 키 | 동작 |
|---|---|
| <kbd>⇧⌘L</kbd> ✎ | 모든 원격 페치 |
| <kbd>⇧⌘↓</kbd> ✎ | 풀 |
| <kbd>⇧⌘↑</kbd> ✎ | 푸시 |
| <kbd>⌘B</kbd> ✎ | 선택한 커밋에 브랜치 만들기 |
| <kbd>⇧⌘S</kbd> ✎ | 모든 변경 사항 스태시 |
| <kbd>⌥⌘Y</kbd> ✎ | 선택한 파일의 기록 |
| <kbd>⌥⌘B</kbd> ✎ | 선택한 파일의 blame |
| <kbd>⌘0</kbd> ✎ | 사이드바 표시 또는 숨기기 |
| <kbd>⌥⌘0</kbd> ✎ | 세부 정보 패널 표시 또는 숨기기 |
| <kbd>⌥⌘L</kbd> ✎ | 세부 정보 패널을 아래로 / 다시 오른쪽으로 이동 |

## 그래프, 변경 사항, diff

| 키 | 동작 |
|---|---|
| <kbd>↑</kbd> <kbd>↓</kbd> 또는 <kbd>J</kbd> <kbd>K</kbd> | 이전 / 다음 커밋 |
| <kbd>⇧</kbd>-클릭, <kbd>⌘</kbd>-클릭 | 범위 / 여러 커밋 선택(비교, 스쿼시, 체리픽) |
| <kbd>⌘C</kbd> | 선택한 커밋의 SHA 복사 |
| <kbd>⌘Y</kbd> | 선택한 파일 훑어보기 |
| <kbd>⇧⌘A</kbd> | 모두 스테이지 |
| <kbd>⌥⇧⌘A</kbd> | 모두 스테이지 취소 |
| <kbd>⌘↩</kbd> | 커밋(커밋 메시지에서) |
| <kbd>⌥⌘G</kbd> | AI로 커밋 메시지 작성(AI가 켜져 있을 때) |
| <kbd>⌥↑</kbd> / <kbd>⌥↓</kbd> | 파일 안의 이전 / 다음 변경 |
| <kbd>⌥⌘↑</kbd> / <kbd>⌥⌘↓</kbd> | 이전 / 다음 파일 |

## 편집기

| 키 | 동작 |
|---|---|
| <kbd>⌘E</kbd> ✎ | 열린 파일 편집 |
| <kbd>⌘S</kbd> ✎ | 저장 |
| <kbd>⌥⌘S</kbd> ✎ | 저장 후 스테이징 |
| <kbd>⌘L</kbd> ✎ | 줄로 이동 |
| <kbd>⌥⌘F</kbd> ✎ | 찾기 및 바꾸기 |
| <kbd>⌘/</kbd> ✎ | 선택한 줄 주석 처리 또는 해제 |
| <kbd>⌘]</kbd> / <kbd>⌘[</kbd> ✎ | 선택한 줄 들여쓰기 / 내어쓰기 |
| <kbd>P</kbd> <kbd>R</kbd> <kbd>E</kbd> <kbd>S</kbd> <kbd>F</kbd> <kbd>C</kbd> <kbd>D</kbd> | 대화형 리베이스: 선택한 행을 pick, reword, edit, squash, fixup, fixup -C, drop으로 |
| <kbd>⌥↑</kbd> / <kbd>⌥↓</kbd> | 대화형 리베이스: 선택한 행 이동(*병합 유지* 시에는 자기 브랜치 안에서만) |
| <kbd>⌘Z</kbd> / <kbd>⇧⌘Z</kbd> | 대화형 리베이스: 계획 변경 실행 취소 / 다시 실행(시작하기 전까지 git은 건드리지 않음) |
| <kbd>⌘↩</kbd> | 대화형 리베이스: 리베이스 시작(또는 남은 계획 저장) |
| Esc | 대화형 리베이스: 아무것도 하지 않고 편집기 닫기 |
| <kbd>⌥⌘↑</kbd> / <kbd>⌥⌘↓</kbd> | 병합 충돌: 이전 / 다음 충돌 |
| <kbd>⌘S</kbd> | 병합 충돌: 저장 후 파일을 해결됨으로 표시 |
| <kbd>⌘[</kbd> / <kbd>⌘]</kbd> | 파일 기록: 뒤로 / 앞으로 |

## 터미널

| 키 | 동작 |
|---|---|
| <kbd>⌃`</kbd> ✎ | 터미널 표시 또는 숨기기(포커스가 있으면 숨김) |
| <kbd>⌃⇧`</kbd> ✎ | 새 터미널 세션 |
| <kbd>⌘+</kbd> / <kbd>⌘−</kbd> ✎ | 터미널 글자 크게 / 작게 |
| <kbd>⇥</kbd> 또는 <kbd>→</kbd> | 선택한 제안 삽입 |
| <kbd>↑</kbd> <kbd>↓</kbd> | 제안 고르기 |
| Esc | 제안 닫기. 빈 프롬프트에서는 그래프로 돌아가기(터미널을 숨겨도 마찬가지) |
| <kbd>⌘</kbd>-클릭 | 포인터 아래 항목 열기: SHA는 커밋 선택, 경로는 파일 열기, URL은 브라우저 열기 |
