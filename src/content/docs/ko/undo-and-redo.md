<kbd>⌘Z</kbd>는 마지막 Git 작업을 실행 취소하고 <kbd>⇧⌘Z</kbd>는 다시 실행합니다. 뭔가 잘못되었다면 먼저 실행 취소를 시도하세요.

## 실행 취소할 수 있는 작업

커밋, 수정, 체크아웃, 브랜치와 태그 변경, 버리기, 재설정, 스태시, 풀, 병합, 리베이스, 체리픽 등.

병합, 리베이스, 재설정은 작업 트리가 깨끗할 때만 다시 실행됩니다.

## 작업 기록

**편집 ▸ 작업 기록…** 에는 GitLoom이 한 모든 작업이 표시됩니다. 그중 원하는 시점까지 실행 취소할 수 있습니다.

## 작업을 잃기 전에

작업을 버리게 될 실행 취소(예: 그 뒤에 새 변경을 만든 경우) 전에는 GitLoom이 무슨 일이 일어날지 알려 주고 묻습니다.

## 텍스트와 리베이스 편집기

텍스트 필드에서는 <kbd>⌘Z</kbd>가 평소처럼 입력을 실행 취소합니다. [대화형 리베이스](/ko/docs/interactive-rebase/) 편집기에서는 계획의 변경을 실행 취소합니다.

실행 취소한 뒤에도 커밋이 사라진 것 같다면 [Reflog 복구](/ko/docs/reflog-recovery/)를 참고하세요.
