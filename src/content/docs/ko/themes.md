GitLoom은 항상 라이트 테마 하나와 다크 테마 하나를 사용합니다. **설정 ▸ 모양**에서 선택하세요.

## 라이트와 다크

*모드*는 시스템 설정을 따르거나, 항상 라이트 또는 항상 다크로 유지합니다. *라이트 테마*와 *다크 테마*를 고르세요. 기본 제공 테마는 Loom Paper와 Loom Midnight(기본값), System Light와 Dark, High Contrast Light와 Dark, Solarized 스타일 Light와 Dark입니다. 작은 미리 보기에 선택한 색으로 그래프와 diff가 표시됩니다.

## 구별하기 쉬운 색상

- *Diff 색상*: 테마에서(초록/빨강) 또는 파랑/주황.
- *그래프 레인*: 테마에서, 색각 이상 친화, 단색.

테마의 텍스트가 배경에 비해 대비가 충분하지 않으면 GitLoom이 경고합니다.

## 테마 만들기와 가져오기

버튼은 지금 사용 중인 테마에 적용됩니다:

- *편집…* 은 테마 편집기를 엽니다. 기본 제공 테마는 먼저 복사됩니다.
- *복제본 만들기*는 이 테마를 확장하는 새 테마 파일을 만듭니다.
- *가져오기…* 는 `.gitloomtheme`, VS Code `.json`, iTerm2 `.itermcolors`, Ghostty, Alacritty 테마를 받습니다.
- *내보내기…* 는 테마를 `.gitloomtheme` 파일로 저장합니다.
- *테마 폴더 열기*는 테마가 있는 위치를 보여 줍니다.

테마 파일은 아무 편집기에서나 편집할 수도 있으며, 저장하는 즉시 GitLoom에 적용됩니다.

## 그 밖의 모양 설정

같은 탭에는 인터페이스 *글자 크기*(작게, 보통, 크게), *강조 색상*, 반투명 사이드바, Dock 아이콘(기본, 다크, 클래식), 아바타, 날짜, 그리고 diff, 파일 편집기, 병합 편집기, 터미널에 쓰는 코드 글꼴과 크기가 있습니다.
