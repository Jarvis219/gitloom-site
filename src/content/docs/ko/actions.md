GitHub 계정을 추가하면 GitLoom이 사이드바의 작업(ACTIONS) 그룹과 그래프의 CI 열에서 해당 커밋 옆에 GitHub Actions 실행을 표시합니다.

![풀 리퀘스트와 GitHub Actions 실행이 있는 사이드바, 그리고 열려 있는 실행의 build 작업](/shots/actions-light.png)

## 실행과 로그

실행을 열면 작업, 주석, 아티팩트를 볼 수 있습니다. 작업을 열면 로그를 읽을 수 있습니다. 로그 보기는 타임스탬프 표시, 줄 바꿈, 오류만 표시가 가능하며, *로그 저장…* 으로 사본을 보관할 수 있습니다.

## 다시 실행, 취소, 시작

- *모든 작업 다시 실행*, *실패한 작업 다시 실행*, *이 작업 다시 실행*.
- *실행 취소*.
- *워크플로 실행…* 은 `workflow_dispatch` 트리거가 있는 워크플로를 입력값과 함께 시작합니다.
- 실행의 아티팩트를 다운로드합니다.

포크에서 온 실행이 승인을 기다리고 있으면 그렇게 표시되고, 그 풀 리퀘스트가 변경하는 워크플로 파일을 나열하며, *승인 후 실행…* 을 제안합니다. 먼저 변경 내용을 확인하세요. 승인된 워크플로는 저장소의 설정으로 실행됩니다.

## 알림

GitLoom은 내가 시작한 실행이 끝나면 알림을 보낼 수 있습니다. **설정 ▸ Git ▸ GitHub Actions ▸ 내가 시작한 CI가 끝나면 알림**에서 시점을 고르세요: 안 함, 실패할 때만(기본값), 항상.

> **Note** Actions는 GitHub 전용입니다. GitLab에서는 CI 파이프라인이 아직 지원되지 않으며 Actions 그룹이 숨겨집니다.
