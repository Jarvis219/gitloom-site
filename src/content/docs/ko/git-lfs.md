Mac에 `git-lfs`가 설치되어 있으면 GitLoom은 Git LFS와 함께 작동합니다. 설치되어 있지 않아도 LFS 파일을 나열할 수는 있지만, 다운로드하거나 잠글 수는 없습니다.

## GIT LFS 그룹

LFS를 쓰는 저장소에서는 사이드바에 LFS 파일을 나열하는 GIT LFS 그룹이 있습니다. 아직 다운로드하지 않아 디스크에 포인터만 있는 파일에는 다운로드 아이콘이 표시됩니다. 잠긴 파일에는 누가 잠갔는지 표시됩니다. 파일을 두 번 클릭하면 열립니다.

파일을 오른쪽 클릭하면 다음을 사용할 수 있습니다:

- *파일 열기*;
- 포인터만 있을 때 *이 파일 다운로드*;
- *잠금* 또는 *잠금 해제*.

## 모든 LFS 파일 다운로드

**저장소 ▸ 고급 ▸ Git LFS 파일 다운로드**는 `git lfs pull`을 실행해 이 체크아웃의 대용량 파일을 다운로드합니다.

## 새로운 종류의 파일 추적

스테이징 영역에서 변경된 파일을 오른쪽 클릭 ▸ *LFS로 추적 (\*.ext)* 을 선택하면 그 확장자를 가진 모든 파일을 추적합니다. 이미 LFS를 쓰는 저장소에서는 같은 메뉴에 *잠금 (LFS)* 과 *잠금 해제 (LFS)* 가 있습니다.
