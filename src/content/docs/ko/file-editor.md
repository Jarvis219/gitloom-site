GitLoom은 저장소의 파일을 보여 주고 편집할 수 있으므로, 작은 수정에 다른 앱이 필요하지 않습니다.

## 파일 열기

- <kbd>⌘P</kbd>(빠른 열기)는 저장소의 아무 파일이나 엽니다.
- 사이드바의 Ref/파일 전환 버튼을 누르면 파일 트리가 표시됩니다. 여기서 *새 파일…* 이나 *새 폴더…* 를 만들고, *이름 변경…* 이나 *휴지통으로 이동*을 하고, *무시된 파일 보기*를 할 수도 있습니다.

파일은 보기 모드로 열립니다. 편집하려면 <kbd>⌘E</kbd>를 누르거나 *파일 편집*을 클릭하세요. Esc를 누르면 그래프로 돌아갑니다.

## 편집 키

| 키 | 동작 |
|---|---|
| <kbd>⌘S</kbd> | 저장 |
| <kbd>⌥⌘S</kbd> | 저장 후 스테이징 |
| <kbd>⌘L</kbd> | 줄로 이동 |
| <kbd>⌥⌘F</kbd> | 찾기 및 바꾸기 |
| <kbd>⌘/</kbd> | 선택한 줄 주석 처리 또는 해제 |
| <kbd>⌘]</kbd> / <kbd>⌘[</kbd> | 선택한 줄 들여쓰기 / 내어쓰기 |

편집기 옵션에는 *줄 바꿈*, *공백과 탭 보기*, *괄호와 따옴표 자동 닫기*, *거터를 HEAD와 비교*가 있습니다. 코드 글꼴과 크기는 **설정 ▸ 모양**에서 정합니다.

## 디스크에서 파일이 바뀌었을 때

저장하지 않은 편집이 있는데 다른 앱이 파일을 바꾸면 GitLoom이 알려 주고 *내 것 유지*, *다시 불러오기*, *비교*를 제안합니다. 충돌 표시가 있는 파일은 저장해도 해결됨으로 표시되지 않는다고 알려 줍니다. 그럴 때는 [충돌 편집기](/ko/docs/resolving-conflicts/)를 사용하세요.

파일에 저장하지 않은 변경 사항이 있는 동안에는 GitLoom이 업데이트 설치도 기다립니다.

## 다른 편집기

*외부 편집기에서 열기*는 **설정 ▸ 통합 ▸ 파일 열기 프로그램**에서 선택한 앱으로 파일을 엽니다. 그곳의 *사용자 지정 명령*이 이를 대신하며, `$FILE`, `$LINE`, `$REPO`가 채워집니다. 예:

```sh
code -g $FILE:$LINE
```
