**설정 ▸ 레이아웃**에서 창 안의 배치를 정합니다. 변경 사항은 바로 적용됩니다.

## 패널과 diff

- *세부 정보 패널*: 오른쪽 또는 그래프 아래. <kbd>⌥⌘L</kbd>로도 전환할 수 있습니다.
- *상태 막대 표시*.
- *diff 열기*: 그래프 위에 겹쳐서, 또는 그래프가 계속 보이도록 그래프 아래에.
- diff 스타일, 그리고 *파일별 diff 스타일 기억*.
- 탭 막대: 탭 색상을 탭의 점으로 표시할지, 도구 막대 아래에 색상 선을 표시할지, 탭이 하나만 열려 있을 때도 탭을 표시할지.

## 도구 막대

도구 막대에 표시할 버튼, 순서, 레이블 모양을 선택하세요.

## 그래프 열

브랜치 / 태그, CI, 변경 (+/−), 작성자, 날짜, SHA 열을 모든 저장소에 대해 켜거나 끕니다. 그래프와 커밋 메시지 열은 항상 표시됩니다. 그래프에서 열 머리글을 오른쪽 클릭해 바꾸면 해당 저장소에만 적용됩니다.

## 사이드바

사이드바 그룹을 표시하거나 숨기고 순서를 바꿉니다. 추가 그룹(풀 리퀘스트, Actions, 이슈, 서브모듈, 워크트리, Git LFS 파일)은 해당하는 경우에만 표시되며, 여기서 숨기면 모든 곳에서 숨겨집니다. *“prefix/…” 형식의 로컬 브랜치를 폴더로 표시*는 `feature/login` 같은 브랜치를 묶어 줍니다.

## 프리셋

이름을 입력하고 *현재 레이아웃 저장*을 클릭하면 현재 배치를 보관할 수 있습니다. 예를 들어 작은 화면용으로 쓸 수 있습니다. 프리셋은 여기서 또는 **보기 ▸ 레이아웃**에서 적용합니다. *기본 레이아웃으로 재설정*은 기본값으로 되돌리며, 같은 곳에서 이를 실행 취소할 수 있습니다.
