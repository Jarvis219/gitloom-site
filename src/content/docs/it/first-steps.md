Una volta installato GitLoom, apri un repository che hai già o clonane uno. Tutto ciò che fa GitLoom equivale al comando `git` corrispondente, quindi puoi passare al terminale in qualsiasi momento.

## Aprire un repository

Trascina la cartella del repository sulla finestra di GitLoom, oppure sceglila dalla pagina iniziale o dall’elenco dei recenti. Anche <kbd>⌘O</kbd> apre un repository; se la scheda attuale ne mostra già uno, si apre in una nuova scheda.

## Clonare un repository

Premi <kbd>⇧⌘C</kbd> e incolla un URL qualsiasi. Dopo aver aggiunto un account GitHub o GitLab (vedi [GitHub](/it/docs/github/) e [GitLab](/it/docs/gitlab/)), puoi anche scegliere tra i repository del tuo account.

## Schede

Ogni repository si apre nella propria scheda. <kbd>⌘T</kbd> apre una nuova scheda e <kbd>⌃⇥</kbd> passa alla successiva. Le schede si riaprono al successivo avvio di GitLoom. Per cambiare questo comportamento usa *All’avvio* in **Impostazioni ▸ Generali**: riapri le ultime schede, chiedi prima o parti senza repository aperti.

## Nome ed email

Se git non ha ancora `user.name` o `user.email`, GitLoom te li chiede prima del primo commit. Se usi identità diverse per tipi di lavoro diversi, configura i [profili](/it/docs/profiles/).

## E poi

- Scopri le parti della [finestra](/it/docs/the-window/).
- Fai il tuo primo [commit](/it/docs/committing/).
- Premi <kbd>⌘K</kbd> per la tavolozza comandi, che esegue qualsiasi comando e ti porta a branch, file e commit.
