Dopo aver aggiunto un account GitHub o GitLab (vedi [GitHub](/it/docs/github/) e [GitLab](/it/docs/gitlab/)), la barra laterale elenca le pull request del repository (merge request su GitLab).

![La barra laterale con una pull request ed esecuzioni di GitHub Actions](/shots/actions-light.png)

## Creare una pull request

- **Repository ▸ GitHub / GitLab ▸ Crea pull request…** per il branch corrente.
- Oppure rilascia un branch su un altro branch nel grafico.

Il ▾ accanto a Revisori, Assegnatari ed Etichette permette di scegliere dagli elenchi del repository. Con l’IA attiva, GitLoom può scrivere la descrizione (vedi [Scegliere un provider](/it/docs/choosing-a-provider/)).

## Revisione

Apri una pull request per vederne il diff. Puoi commentare le righe, approvare e unire. Nel diff, *Rispondi* risponde in un thread di revisione e *Risolvi* lo chiude.

I commenti sulle righe non sono ancora disponibili per GitLab.

## Launchpad

**Launchpad** (<kbd>⇧⌘K</kbd>) elenca le pull request e le issue che ti aspettano in tutti i repository e gli account. Fai clic destro su un elemento per aprirne il repository, aprirlo nel browser o posticiparlo: di 1 ora, a domani, alla settimana prossima o finché non cambia.
