Une fois un compte GitHub ou GitLab ajouté (voir [GitHub](/fr/docs/github/) et [GitLab](/fr/docs/gitlab/)), la barre latérale liste les pull requests du dépôt (merge requests sur GitLab).

![La barre latérale avec une pull request et des exécutions GitHub Actions](/shots/actions-light.png)

## Créer une pull request

- **Dépôt ▸ GitHub / GitLab ▸ Créer une pull request…** pour la branche actuelle.
- Ou déposez une branche sur une autre branche dans le graphe.

Le ▾ à côté de Relecteurs, Responsables et Libellés permet de choisir dans les listes du dépôt. Si l’IA est activée, GitLoom peut rédiger la description (voir [Choisir un fournisseur](/fr/docs/choosing-a-provider/)).

## Revue

Ouvrez une pull request pour voir son diff. Vous pouvez commenter des lignes, approuver et fusionner. Dans le diff, *Répondre* répond dans un fil de revue et *Résoudre* le ferme.

Les commentaires de ligne ne sont pas encore disponibles pour GitLab.

## Launchpad

**Launchpad** (<kbd>⇧⌘K</kbd>) liste les pull requests et tickets qui vous attendent dans tous vos dépôts et comptes. Cliquez avec le bouton droit sur un élément pour ouvrir son dépôt, l’ouvrir dans le navigateur ou le reporter : 1 heure, jusqu’à demain, jusqu’à la semaine prochaine ou jusqu’à ce qu’il change.
