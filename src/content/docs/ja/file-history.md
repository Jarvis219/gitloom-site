ファイルの履歴には、1 つのファイルを変更したすべてのコミットが、名前変更をたどって表示されます。

## 開く

ファイルを選んで <kbd>⌥⌘Y</kbd> を押すか、**リポジトリ ▸ ファイルの履歴…** を選びます。ファイルが選ばれていない場合はコマンドパレットが開き、ファイルを選べます。ターミナルから `gitloom log <file>` を実行しても開きます（[gitloom コマンドラインツール](/ja/docs/the-gitloom-command-line-tool/)を参照）。

## 読み方

各項目はそのファイルを変更したコミットで、作成者と日付が表示されます。名前変更があった場合は、ファイルの元の場所が表示されます。*名前変更を追跡* はオフにできます。2 つのバージョンを選ぶと、その間の差分が表示されます。

<kbd>⌘[</kbd> と <kbd>⌘]</kbd> で戻る・進むができます。Esc でグラフに戻ります。

## 古いバージョン

項目を右クリックすると、次の操作ができます:

- *このバージョンを表示*、または*このバージョンを外部エディタで開く*。
- *グラフに表示*。
- *このコミット時点で Blame*（[Blame](/ja/docs/blame/) を参照）。
- *ファイルをこのバージョンに復元…*。ファイルにコミットしていない変更がある場合は置き換えられますが、<kbd>⌘Z</kbd> で元に戻せます。

## シャロークローン

シャロークローンでは、履歴はクローンの範囲で終わり、一覧にもその旨が表示されます。
