GitLoom では、ライトテーマとダークテーマを 1 つずつ使います。**設定 ▸ 外観** で選びます。

## ライトとダーク

*モード* は、システムに合わせるか、常にライトまたは常にダークにします。*ライトテーマ* と*ダークテーマ* を選びます。内蔵テーマは、Loom Paper と Loom Midnight（デフォルト）、System Light と Dark、High Contrast Light と Dark、Solarized 風の Light と Dark です。小さなプレビューに、選んだ色でグラフと差分が表示されます。

## 見分けやすい色

- *差分の色*: テーマに合わせる（緑/赤）か、青/オレンジ。
- *グラフのレーン*: テーマに合わせる、色覚多様性に配慮した配色、モノクロ。

テーマの文字と背景のコントラストが足りない場合は、GitLoom が警告します。

## テーマを作る・読み込む

ボタンは現在使っているテーマに対して動作します:

- *編集…* はテーマエディタを開きます。内蔵テーマは先に複製されます。
- *複製* は、このテーマを拡張する新しいテーマファイルを作ります。
- *読み込む…* は `.gitloomtheme`、VS Code の `.json`、iTerm2 の `.itermcolors`、Ghostty と Alacritty のテーマを読み込みます。
- *書き出す…* はテーマを `.gitloomtheme` ファイルとして保存します。
- *テーマフォルダを開く* はテーマの保存場所を表示します。

テーマファイルは任意のエディタでも編集でき、保存するとすぐに GitLoom に反映されます。

## そのほかの外観の設定

同じタブには、インターフェイスの*文字サイズ*（小、中、大）、*アクセント* カラー、半透明のサイドバー、Dock アイコン（デフォルト、ダーク、クラシック）、アバター、日付、そして差分、ファイルエディタ、マージエディタ、ターミナルで使うコードフォントとサイズがあります。
