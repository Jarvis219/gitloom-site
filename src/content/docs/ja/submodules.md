リポジトリにサブモジュールがあると、サイドバーに「サブモジュール」グループが表示され、各サブモジュールとその状態が一覧表示されます。

## 一覧の見方

各行にはサブモジュールのパスと状態が表示されます:

- 最新の状態なら ✓ とチェックアウトされたコミット、変更がある場合は*変更された内容* / *追跡されていない内容*。
- 同期がずれている場合は*アップデート*: チェックアウトされたコミットが、メインリポジトリに記録されたコミットと異なります（ポインタを置くと両方が表示されます）。
- まだ初期化されていない場合は*初期化*。
- 記録されたコミットがコンフリクトしている場合は*コンフリクト*。

## サブモジュールで作業する

サブモジュールをダブルクリックすると、専用のタブで開きます。右クリックすると、次の操作ができます:

- *新規タブで開く*。
- *記録されたコミットに更新*、または*リモートの最新に更新*。
- *初期化*（初期化されていないもの）。
- *Finder に表示*。
- *サブモジュールを削除…*。

サブモジュールにコミットしていない変更がある場合、更新の前に確認があります。変更が邪魔になる場合は git が停止し、強制されることはありません。

新しいコミットを取り込むプルのたびにサブモジュールを更新するには、**設定 ▸ Git** で*プル後にサブモジュールを更新*をオンにします。

## サブモジュールを追加する

**リポジトリ ▸ 詳細 ▸ サブモジュールを追加…** で、URL、パス、必要に応じてブランチを入力します。

## サブモジュールを削除する

*サブモジュールを削除…* はサブモジュールの初期化を解除し、インデックスから削除します。リポジトリのデータ（`.git/modules/<name>`）はゴミ箱に移されるので、コミットは復元可能なまま残ります。最後にコミットして完了です。サブモジュールにコミットしていない変更、どのリモートにもないコミット、スタッシュがある場合は、GitLoom が先にそれらを一覧表示します。
