プロファイルは、コミットに使う名義を保持します: 名前、メール、任意で署名鍵です。たとえば、仕事用と個人プロジェクト用に 1 つずつ使います。設定は **設定 ▸ プロファイル** で行います。

## プロファイルが保持するもの

各プロファイルには次のものがあります:

- プロファイル名と、コミットの名前（`user.name`）とメール（`user.email`）。
- 署名方法: 署名しない、SSH、GPG、X.509 と、デフォルトでコミットに署名するかどうか。
- [SSH アカウント](/ja/docs/ssh-accounts/)のルールで決まらないときにプッシュに使うアカウント（任意）。
- 専用の開いているタブと最近使ったリポジトリ。

GitLoom は名前、メール、署名鍵を各リポジトリの git config に書き込むので、ターミナルでも GitLoom と同じ設定になります。

## プロファイルを切り替える

プロファイルはウインドウ右上のチップから切り替えます。プロファイルの 1 つがデフォルトです。GitLoom はデフォルトのプロファイルで起動し、使用中のプロファイルが削除されたときもそこに戻ります。どれをデフォルトにするかは*デフォルトにする* で変更します。

## 名義が違うとき

コミットボタンの上に、誰の名義でコミットするかが表示されます。そのメールがリポジトリのプロファイルのものでない場合は、その行に警告が付きます。ツールバーのチップから正しいプロファイルを選んで直してください。

## プロファイルを削除する

プロファイルを選んで − をクリックします。そのプロファイルの開いているタブと最近使ったリポジトリは消去されます。すでにリポジトリに書き込まれた git config はそのまま残ります。プロファイルは常に少なくとも 1 つあります。
