AI 機能はデフォルトでオフです。オンにするときは、誰が答えるかを選びます。自分のキーを使うクラウドプロバイダか、Mac 上で動くモデルです。

## オンにする

**設定 ▸ AI** を開き、*AI 機能* をオンにします。GitLoom は最初に、何が誰に送信されるかを説明します。

*プロバイダ* を選びます:

- Anthropic、OpenAI、Google Gemini、OpenRouter、Groq、Mistral、DeepSeek、Qwen（Alibaba Cloud）、xAI、Together AI。
- ローカルで動く Ollama または LM Studio。データは Mac の外に出ません。
- カスタムプロバイダ: 会社のゲートウェイなど、Anthropic、OpenAI、Gemini、Ollama の API を話すサーバーなら何でも使えます。*カスタムプロバイダを追加…* で追加します。

API キーを貼り付けて*キーを保存* をクリックします。キーはキーチェーンに保存されます。*テスト* はキーを確認してプロバイダのモデルを読み込むので、その中から選べます。

## AI にできること

- コミットメッセージ（<kbd>⌥⌘G</kbd>）、プルリクエストの説明、スタッシュのメッセージを書く。
- コミット、ブランチ、あなたの変更を説明し、追加の質問にも答える。
- コンフリクトの解決方法を提案する。

あなたが頼むまで何も送信されません。ネットワークがないときは ✨ ボタンが淡色表示になりますが、ローカルモデルは使えます。

## 文章を調整する

*文章* では、言語（English または Tiếng Việt）とコミットのスタイル（Conventional Commits、リポジトリの履歴に合わせる、自由）を選びます。

*機能ごとの設定を表示* を使うと、機能ごとに専用のモデルと*カスタム指示* を設定できます。その横の **テンプレート** メニューは、Conventional Commits、ブランチからのチケット ID、プルリクエストの構成、バグだけを指摘するレビューなど、既製の設定を入力します。それをチームに合わせて調整できます。

## 特定のリポジトリでオフにする

コミットメッセージの横にある ✨ メニューから*このリポジトリで AI をオフにする* を選びます。再びオンにするには **設定 ▸ AI ▸ AI をオフにした対象** を使います。

何かが送信される前に、正確なリクエストを確認できます。[送信される内容](/ja/docs/what-gets-sent/)を参照してください。
