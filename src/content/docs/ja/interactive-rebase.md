インタラクティブリベースは、一連のコミットを書き換えます。GitLoom はプランを編集できるリストとして表示し、開始するまでリポジトリには何も起きません。

## エディタを開く

- コミットを右クリック ▸ *ここからインタラクティブリベース…*。
- または、ブランチを別のブランチにドロップして*インタラクティブリベース*を選びます。
- 複数のコミットを選んでいるときは、*選択したコミットをインタラクティブリベース…* でそれらを選択した状態のエディタが開きます。

最初のコミット（`--root`）からでも使えます。エディタはグラフの位置に表示されます。

## プランを編集する

各行が 1 つのコミットで、一番上が最も古いコミットです。メニューまたはキーでアクションを設定します:

| キー | アクション |
|---|---|
| <kbd>P</kbd> | pick |
| <kbd>R</kbd> | reword |
| <kbd>E</kbd> | edit |
| <kbd>S</kbd> | squash |
| <kbd>F</kbd> | fixup |
| <kbd>C</kbd> | fixup -C |
| <kbd>D</kbd> | drop |

行をドラッグするか、<kbd>⌥↑</kbd> と <kbd>⌥↓</kbd> で並べ替えます。<kbd>⌘Z</kbd> でプランへの変更を取り消せます。

- reword のメッセージは前もって書いておけるので、リベースは途中で止まらずに実行されます。
- 行のメニューの*後にコマンドを追加…* で、その時点でコマンドを実行できます（`exec` 行。たとえば失敗したらリベースを止めるテストなど）。
- リベースするコミットの上に積まれたブランチは、チェックを外さない限り一緒に移動します（`--update-refs`）。
- 範囲内のマージは、デフォルトでは平坦化されます。保持するには*マージを保持*にチェックを入れます（`--rebase-merges`）。その場合、プランにはマージの各側の開始位置とマージが再び作られる位置も表示され、コミットは自分の側の中でのみ移動できます。

## 開始またはキャンセル

<kbd>⌘↩</kbd> で開始し、Esc でキャンセルします。完了後は、リベース全体が 1 回の取り消しステップになります。

## すばやい編集

エディタを開かずに:

- 隣り合う複数のコミットを選択 ▸ *N 件のコミットをスカッシュ*（メッセージを古い順に結合してすぐに実行します。自分で書くには *…してメッセージを編集*）または *N 件のコミットを削除…*。
- コミットを右クリック ▸ *メッセージを編集…*、*コミットを削除…*、*上へ移動/下へ移動*。
