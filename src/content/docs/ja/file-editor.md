GitLoom ではリポジトリのファイルを表示・編集できるので、ちょっとした修正にほかのアプリは要りません。

## ファイルを開く

- <kbd>⌘P</kbd>（クイックオープン）でリポジトリ内の任意のファイルを開きます。
- サイドバーの参照/ファイルの切り替えでファイルツリーを表示します。そこでは*新規ファイル…* や*新規フォルダ…* の作成、*名前を変更…* や*ゴミ箱に入れる*、*無視されたファイルを表示* もできます。

ファイルは閲覧用に開きます。編集するには <kbd>⌘E</kbd> を押すか、*ファイルを編集* をクリックします。Esc でグラフに戻ります。

## 編集のキー

| キー | 操作 |
|---|---|
| <kbd>⌘S</kbd> | 保存 |
| <kbd>⌥⌘S</kbd> | 保存してステージ |
| <kbd>⌘L</kbd> | 行へ移動 |
| <kbd>⌥⌘F</kbd> | 検索と置換 |
| <kbd>⌘/</kbd> | 選択した行をコメント化 / コメント解除 |
| <kbd>⌘]</kbd> / <kbd>⌘[</kbd> | 選択した行をインデント / インデント解除 |

エディタのオプションには、*行を折り返す*、*スペースとタブを表示*、*括弧と引用符を自動で閉じる*、*ガターは HEAD と比較* があります。コードフォントとそのサイズは **設定 ▸ 外観** で設定します。

## ディスク上でファイルが変わったとき

保存していない編集がある間にほかのアプリがファイルを変更すると、GitLoom がそれを知らせ、*自分の変更を採用*、*再読み込み*、*比較* を提案します。コンフリクトマーカーを含むファイルでは、保存しても解決済みにはならないことが表示されます。解決には[コンフリクトエディタ](/ja/docs/resolving-conflicts/)を使ってください。

ファイルに保存していない変更がある間は、GitLoom はアップデートのインストールも待ちます。

## ほかのエディタ

*外部エディタで開く* は、**設定 ▸ 連携 ▸ ファイルを開くアプリ** で選んだアプリでファイルを開きます。そこで*カスタムコマンド* を設定するとそちらが優先され、`$FILE`、`$LINE`、`$REPO` が埋め込まれます。例:

```sh
code -g $FILE:$LINE
```
