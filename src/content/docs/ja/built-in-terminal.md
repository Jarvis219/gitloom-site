<kbd>⌃`</kbd> を押すと、グラフの下にターミナルが開きます。場所はリポジトリのフォルダで、シェルはあなたのログインシェルです。ターミナルで git コマンドが終わると、すぐにグラフが更新されます。

## 候補とリンク

git コマンドを入力している間、GitLoom はサブコマンド、ブランチ、リモート、エイリアスを候補として表示します。<kbd>↑</kbd> <kbd>↓</kbd> で候補を選び、<kbd>⇥</kbd> または <kbd>→</kbd> で挿入し、Esc で一覧を閉じます。

ポインタの下にあるものを <kbd>⌘</kbd>-クリックすると、SHA ならそのコミットを選択し、パスならファイルを開き、URL ならブラウザで開きます。

## キー

| キー | 操作 |
|---|---|
| <kbd>⌃`</kbd> | ターミナルを表示または非表示（フォーカスがあるときは非表示） |
| <kbd>⌃⇧`</kbd> | 新しいターミナルセッション |
| <kbd>⌘+</kbd> / <kbd>⌘−</kbd> | ターミナルの文字を大きく / 小さく |
| Esc | 空のプロンプトでグラフに戻る |

タブを閉じるときにコマンドがまだ実行中であれば、GitLoom が先に確認します。

## 設定

**設定 ▸ 連携 ▸ ターミナル** には次の項目があります:

- *シェル統合*: コマンドが終わったことを GitLoom が検知できるようにします（即時更新、候補）。オフにするとそれらは止まります。どちらの場合も、dotfiles が編集されることはありません。
- *入力中に git コマンドを提案*: 候補だけをオフにします。
- *スクロールバック*: 各セッションが保持する行数（デフォルトは 10,000）。
- *GitLoom が実行する git コマンドを表示*: アプリが実行する各コマンドを薄い色の行で表示します。git を学ぶのに役立ちます。
- *キーボード入力のセキュリティ保護*: ターミナルがキーボードを使っている間、ほかのアプリは入力内容を読み取れません。
- *シェル* と *引数*: 新しいセッションで使う別のシェル（`/opt/homebrew/bin/fish` など）。実行できないパスの場合はログインシェルが使われます。

変更は新しいターミナルセッションに適用されます。ターミナルは **設定 ▸ 外観** のコードフォントを使います。

## いつものターミナルアプリ

<kbd>⌥⌘T</kbd> を押すと、代わりにお使いのターミナルアプリでリポジトリを開きます。使うアプリは **設定 ▸ 連携 ▸ 「ターミナルで開く」に使うアプリ** で選びます。
