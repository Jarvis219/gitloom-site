GitHub または GitLab のアカウントを追加すると（[GitHub](/ja/docs/github/) と [GitLab](/ja/docs/gitlab/) を参照）、サイドバーにリポジトリのプルリクエスト（GitLab ではマージリクエスト）が一覧表示されます。

![プルリクエストと GitHub Actions の実行が表示されたサイドバー](/shots/actions-light.png)

## プルリクエストを作成する

- 現在のブランチについては **リポジトリ ▸ GitHub / GitLab ▸ プルリクエストを作成…**。
- または、グラフ上でブランチを別のブランチにドロップします。

レビュアー、担当者、ラベルの横にある ▾ で、リポジトリの一覧から選べます。AI をオンにしていれば、GitLoom が説明文を書けます（[プロバイダの選び方](/ja/docs/choosing-a-provider/)を参照）。

## レビュー

プルリクエストを開くと差分が表示されます。行へのコメント、承認、マージができます。差分の中では、*返信* でレビューのスレッドに答え、*解決* でスレッドを閉じます。

GitLab ではまだ行コメントを使えません。

## Launchpad

**Launchpad**（<kbd>⇧⌘K</kbd>）は、リポジトリとアカウントをまたいで対応待ちのプルリクエストとイシューを一覧表示します。項目を右クリックすると、リポジトリを開く、ブラウザで開く、またはスヌーズ（1 時間、明日まで、来週まで、変更があるまで）ができます。
