GitLoom のほとんどの問題は、取り消すか原因を確認できます。まずはここから始めてください。

## リポジトリで何かがおかしくなった

- **まず取り消す**: <kbd>⌘Z</kbd> または **編集 ▸ 操作履歴…**。ほとんどの操作は取り消せます（[取り消しとやり直し](/ja/docs/undo-and-redo/)を参照）。
- **コミットが消えたように見える**: **リポジトリ ▸ Reflog…** と **失われたコミットを探す…** で見つけられます（[reflog からの復元](/ja/docs/reflog-recovery/)を参照）。
- **リベースやマージの途中で止まった**: 途中のまま残ったリポジトリには、*続行* と *中止* のあるバナーが表示されます。GitLoom を再起動した後も同様です。

## GitLoom が実行した内容を見る

**ウインドウ ▸ Git ログ**（<kbd>⌥⇧⌘L</kbd>）には、GitLoom が実行したすべての git コマンドが一覧表示されます: リポジトリ、コマンド、所要時間、終了コードです。保存されるのはコマンドラインだけで、出力、入力、認証情報は保存されません。

ツールバーの下に細い線が動いているときは、git がリモートと通信しています。ポインタを置くと内容が表示されます。時間のかかる操作のメッセージには*キャンセル* があります。

## よくある問題

- **GitLoom が git を見つけられない、または古すぎると表示される。** git 2.40 以降をインストールするか（[インストール](/ja/docs/install/)を参照）、**設定 ▸ Git ▸ Git バイナリ** で別の git を選びます。
- **フックが node、python、リンターを見つけられない。** 必要なフォルダを **設定 ▸ Git ▸ フック** の*追加の PATH* に追加します。これはその後に開いたリポジトリに適用されます。
- **フックが止まらない。** 1 分経ってもフックが実行中のコミットはその旨を表示し、*停止* を提案します。**設定 ▸ Git ▸ フック** の*フックを停止するまでの時間* を設定すると、自動的に停止します（デフォルトは 10 分後）。
- **間違った SSH 鍵が使われる。** [SSH アカウント](/ja/docs/ssh-accounts/)を設定します。

## ログとキャッシュ

**設定 ▸ 詳細** では:

- *デバッグログを書き出す* は、GitLoom が実行する git コマンドを終了ステータスと時間とともに、ログフォルダのファイルに記録します。URL に含まれるパスワードとトークンは隠されます。*ログフォルダを表示* でフォルダを開きます。
- *キャッシュを消去…* は、オフライン用に保存したプルリクエストとイシュー、キャッシュしたファイルのバージョンを削除します。必要になれば再取得されます。
- 設定ファイルを読み込めない場合、GitLoom はそれを別の場所に移し、デフォルトの設定で起動して、ここにその旨を表示します。

どれも役に立たなければ、[問題を報告](/ja/docs/report-an-issue/)してください。
