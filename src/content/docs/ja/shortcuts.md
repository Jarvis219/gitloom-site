✎ の付いた 35 個のショートカット（メニューバーにあるものすべて）は、**設定 ▸ キーボード** で変更できます。それ以外（<kbd>⌘W</kbd> や <kbd>⌘Z</kbd> のようなシステムのショートカットや、シートやエディタの中でだけ使えるキー）は固定です。メニューには常に現在のキーが表示され、ここにあるものはすべてコマンドパレット（<kbd>⌘K</kbd>）からも使えます。

## どこでも

| キー | 操作 |
|---|---|
| <kbd>⌘K</kbd> ✎ | コマンドパレット: `>` コマンド、`/` ファイル、`:` コミット、`@` 作成者、`#` プルリクエストとイシュー |
| <kbd>⌘P</kbd> ✎ | リポジトリのファイルをクイックオープン |
| <kbd>⌘F</kbd> / <kbd>⌘G</kbd> / <kbd>⇧⌘G</kbd> ✎ | コミットを検索 / 次の一致 / 前の一致 |
| <kbd>⌘Z</kbd> / <kbd>⇧⌘Z</kbd> | 直前の Git 操作を取り消す / やり直す（テキストフィールドでは入力の取り消し） |
| <kbd>⌘T</kbd> ✎ | 新規タブ |
| <kbd>⌘W</kbd> | タブを閉じる |
| <kbd>⌃⇥</kbd> / <kbd>⌃⇧⇥</kbd> ✎ | 次 / 前のタブ |
| <kbd>⇧⌘C</kbd> ✎ | リポジトリをクローン |
| <kbd>⌘O</kbd> ✎ | リポジトリを開く（このタブにすでにリポジトリがある場合は新しいタブで） |
| <kbd>⇧⌘R</kbd> ✎ | リポジトリを Finder に表示 |
| <kbd>⌥⌘T</kbd> ✎ | リポジトリをターミナルアプリで開く |
| <kbd>⇧⌘K</kbd> | Launchpad（GitHub と GitLab のアカウントのプルリクエストとイシュー） |
| <kbd>⌥⇧⌘L</kbd> ✎ | Git ログ（GitLoom が実行したすべての git コマンド） |
| <kbd>⌘,</kbd> | 設定 |
| <kbd>⌘?</kbd> | GitLoom ヘルプ |

## リポジトリ

| キー | 操作 |
|---|---|
| <kbd>⇧⌘L</kbd> ✎ | すべてのリモートをフェッチ |
| <kbd>⇧⌘↓</kbd> ✎ | プル |
| <kbd>⇧⌘↑</kbd> ✎ | プッシュ |
| <kbd>⌘B</kbd> ✎ | 選択したコミットにブランチを作成 |
| <kbd>⇧⌘S</kbd> ✎ | すべての変更をスタッシュ |
| <kbd>⌥⌘Y</kbd> ✎ | 選択したファイルの履歴 |
| <kbd>⌥⌘B</kbd> ✎ | 選択したファイルの Blame |
| <kbd>⌘0</kbd> ✎ | サイドバーを表示または非表示 |
| <kbd>⌥⌘0</kbd> ✎ | 詳細パネルを表示または非表示 |
| <kbd>⌥⌘L</kbd> ✎ | 詳細パネルを下へ移動 / 右に戻す |

## グラフ、変更、差分

| キー | 操作 |
|---|---|
| <kbd>↑</kbd> <kbd>↓</kbd> または <kbd>J</kbd> <kbd>K</kbd> | 前 / 次のコミット |
| <kbd>⇧</kbd>-クリック、<kbd>⌘</kbd>-クリック | 範囲 / 複数のコミットを選択（比較、スカッシュ、チェリーピック） |
| <kbd>⌘C</kbd> | 選択したコミットの SHA をコピー |
| <kbd>⌘Y</kbd> | 選択したファイルをクイックルック |
| <kbd>⇧⌘A</kbd> | すべてステージ |
| <kbd>⌥⇧⌘A</kbd> | すべてステージ解除 |
| <kbd>⌘↩</kbd> | コミット（コミットメッセージ内で） |
| <kbd>⌥⌘G</kbd> | AI でコミットメッセージを書く（AI がオンのとき） |
| <kbd>⌥↑</kbd> / <kbd>⌥↓</kbd> | ファイル内の前 / 次の変更 |
| <kbd>⌥⌘↑</kbd> / <kbd>⌥⌘↓</kbd> | 前 / 次のファイル |

## エディタ

| キー | 操作 |
|---|---|
| <kbd>⌘E</kbd> ✎ | 開いているファイルを編集 |
| <kbd>⌘S</kbd> ✎ | 保存 |
| <kbd>⌥⌘S</kbd> ✎ | 保存してステージ |
| <kbd>⌘L</kbd> ✎ | 行へ移動 |
| <kbd>⌥⌘F</kbd> ✎ | 検索と置換 |
| <kbd>⌘/</kbd> ✎ | 選択した行をコメント化 / コメント解除 |
| <kbd>⌘]</kbd> / <kbd>⌘[</kbd> ✎ | 選択した行をインデント / インデント解除 |
| <kbd>P</kbd> <kbd>R</kbd> <kbd>E</kbd> <kbd>S</kbd> <kbd>F</kbd> <kbd>C</kbd> <kbd>D</kbd> | インタラクティブリベース: 選択した行を pick、reword、edit、squash、fixup、fixup -C、drop に |
| <kbd>⌥↑</kbd> / <kbd>⌥↓</kbd> | インタラクティブリベース: 選択した行を移動（*マージを保持* のときは自分のブランチ内でのみ） |
| <kbd>⌘Z</kbd> / <kbd>⇧⌘Z</kbd> | インタラクティブリベース: プランへの変更を取り消す / やり直す（開始するまで git には触れません） |
| <kbd>⌘↩</kbd> | インタラクティブリベース: リベースを開始（または残りのプランを保存） |
| Esc | インタラクティブリベース: 何もせずにエディタを閉じる |
| <kbd>⌥⌘↑</kbd> / <kbd>⌥⌘↓</kbd> | マージコンフリクト: 前 / 次のコンフリクト |
| <kbd>⌘S</kbd> | マージコンフリクト: 保存してファイルを解決済みにする |
| <kbd>⌘[</kbd> / <kbd>⌘]</kbd> | ファイルの履歴: 戻る / 進む |

## ターミナル

| キー | 操作 |
|---|---|
| <kbd>⌃`</kbd> ✎ | ターミナルを表示または非表示（フォーカスがあるときは非表示） |
| <kbd>⌃⇧`</kbd> ✎ | 新しいターミナルセッション |
| <kbd>⌘+</kbd> / <kbd>⌘−</kbd> ✎ | ターミナルの文字を大きく / 小さく |
| <kbd>⇥</kbd> または <kbd>→</kbd> | 選択した候補を挿入 |
| <kbd>↑</kbd> <kbd>↓</kbd> | 候補を選ぶ |
| Esc | 候補を閉じる。空のプロンプトではグラフに戻る（ターミナルを隠しても同じ） |
| <kbd>⌘</kbd>-クリック | ポインタの下にあるものを開く: SHA ならコミットを選択、パスならファイルを開く、URL ならブラウザで開く |
