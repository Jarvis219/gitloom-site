GitHub または GitLab のアカウントを追加すると、GitLoom はリポジトリのイシューをサイドバーに表示します。

## 作成と閲覧

- **リポジトリ ▸ GitHub / GitLab ▸ 新規イシュー…** でイシューを作成します。
- リポジトリのイシューは、サイドバーの「イシュー」グループで閲覧できます。ラベルやマイルストーンで絞り込めます。
- イシューを右クリックすると、*イシューからブランチを作成*、*ブラウザで開く*、*リンクをコピー* を選べます。
- コマンドパレット（<kbd>⌘K</kbd>）で `#` と入力すると、プルリクエストとイシューを探せます。
- **Launchpad**（<kbd>⇧⌘K</kbd>）は、リポジトリをまたいで対応待ちのイシューを一覧表示します。

## イシューからブランチを始める

*イシューからブランチを作成* は、イシューにちなんだ名前のブランチを作成します。名前は **設定 ▸ Git ▸ イシューからブランチ** のテンプレートに従い、デフォルトは `{type}/{number}-{slug}` です（`{type}` は `fix` または `feat`）。チームの `.gitloom/team.json` にテンプレートがある場合は、そちらが優先されます。
