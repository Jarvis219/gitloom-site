Mac に `git-lfs` がインストールされていれば、GitLoom は Git LFS に対応します。インストールされていなくても LFS ファイルの一覧は表示できますが、ダウンロードやロックはできません。

## 「GIT LFS」グループ

LFS を使っているリポジトリでは、サイドバーに「GIT LFS」グループがあり、LFS ファイルが一覧表示されます。まだダウンロードされておらず、ディスクにポインタしかないファイルにはダウンロードアイコンが付きます。ロックされたファイルには、ロックした人が表示されます。ファイルをダブルクリックすると開きます。

ファイルを右クリックすると、次の操作ができます:

- *ファイルを開く*。
- *このファイルをダウンロード*（ポインタしかない場合）。
- *ロック* または *ロック解除*。

## すべての LFS ファイルをダウンロードする

**リポジトリ ▸ 詳細 ▸ Git LFS ファイルをダウンロード** は `git lfs pull` を実行し、このチェックアウトの大きなファイルをダウンロードします。

## 新しい種類のファイルを追跡する

ステージ領域で変更されたファイルを右クリック ▸ *LFS で追跡（\*.ext）* を選ぶと、その拡張子のすべてのファイルを追跡します。すでに LFS を使っているリポジトリでは、同じメニューに *ロック（LFS）* と *ロック解除（LFS）* があります。
