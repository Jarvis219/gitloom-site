ほかの AI ツール（Claude Code、Claude Desktop、Cursor、VS Code など）は、GitLoom の MCP サーバーを通してリポジトリを扱えます。オンにするまではオフのままです。

## オンにする

**設定 ▸ 連携 ▸ MCP サーバ** で、*外部の AI ツールに許可する操作* を次のいずれかに設定します:

- *何もしない（オフ）*
- *読み取り：ステータス、履歴、差分、Blame*
- *読み取りと変更：コミット、ブランチ、スタッシュ、プル、プッシュも*

次にツールを接続します。Claude Code の場合は、そこに表示される行をコピーしてターミナルで実行します。次のような行です:

```sh
claude mcp add gitloom -- "/Applications/GitLoom.app/Contents/Helpers/gitloom-mcp"
```

ほかのツールの場合は、そこに表示される JSON をツールの MCP 設定にコピーします。GitLoom がほかのツールのファイルを編集することはありません。`gitloom mcp` コマンドでもサーバーを実行できます（[gitloom コマンドラインツール](/ja/docs/the-gitloom-command-line-tool/)を参照）。

## 読み取り

ツールは、開いているリポジトリやスタートページの最近使った項目にあるリポジトリの、ステータス、履歴、差分、Blame、ブランチ、スタッシュを見られます。GitLoom の実行中は、選択中のコミットや開いているファイルなど、あなたが今見ているものを尋ねることもできます。何かを変更することはできません。

## 読み取りと変更

GitLoom の実行中、タブで開いているリポジトリでは、ツールはステージ、コミット、ブランチの作成と切り替え、スタッシュ、フェッチ、プル（早送りのみ）、プッシュもできます。各変更はツール名と*取り消す* ボタン付きでウインドウに表示され、操作履歴にも記録されます。

*プッシュ前に確認* をオンにすると、プッシュはリポジトリのウインドウであなたの回答を待ちます。60 秒経つと拒否されます。

どのツールも、強制プッシュ、リセット、破棄、削除、履歴の書き換えはできません。

## プルリクエスト、イシュー、CI

*自分のアカウント経由のプルリクエスト、イシュー、CI* をオンにすると、ツールは GitLoom に接続したアカウントを通して、リポジトリのプルリクエスト、イシュー、CI の実行を読めます。*読み取りと変更* の場合は、現在のブランチのプルリクエストを作成したり、プルリクエストにコメントしたりもできます。ツールがトークンを見ることはなく、マージ、承認、クローズはできません。

設定画面の*最近のアクティビティ* に、最近の呼び出しが表示されます。
