マージ、リベース、チェリーピック、プルでコンフリクトが起きると、操作が止まり、バナーが状況を説明します。コンフリクトしたファイルは詳細パネルに一覧表示されます。

![自分側、相手側、結果を表示する 3 方向コンフリクトエディタ](/shots/conflict-light.png)

## マージエディタ

コンフリクトしたファイルを開くと、3 方向マージエディタが表示されます: 自分側、相手側、そして結果です。

- コンフリクトごと、または行ごとにどちらかの側を採用します。
- 結果を直接編集します。
- <kbd>⌥⌘↑</kbd> と <kbd>⌥⌘↓</kbd> でコンフリクト間を移動します。
- *ファイル全体* にチェックを入れると、各側をコンフリクト箇所を含むファイル全体として表示します。列は揃って一緒にスクロールします。

ファイルが正しくなったら、*保存して解決済みにする*（<kbd>⌘S</kbd>）をクリックします。

## 特殊なケース

- 名前変更が原因のコンフリクト（両側で名前変更された、または一方で名前変更されもう一方で削除された）の場合は、その旨が表示されます。
- バイナリファイルは、選ぶ前に両側をプレビューできます。
- 両側の違いが改行コード（CRLF / LF）だけの場合は、バナーで警告します。

## 自分のマージツール

ファイルを外部のマージツールで開くこともできます。GitLoom は git の `merge.tool`、または **設定 ▸ 連携 ▸ マージツール** で選んだツールを使います。

## 完了または中止

すべてのファイルを解決したら、バナーの*続行*をクリックします。*スキップ* はリベースやチェリーピックの現在のコミットを飛ばし、*中止* はすべてを元の状態に戻します。リベースやマージの途中のまま残ったリポジトリは、GitLoom を再起動したときにもバナーを再び表示します。
