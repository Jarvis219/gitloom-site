GitLoom には探し方が 3 つあります。コミットを探す検索、あらゆるものを探すコマンドパレット、ファイルを開くクイックオープンです。

## コミットを検索する

<kbd>⌘F</kbd> で、コミットメッセージ、作成者、SHA、ファイルパス、または変更内容（`-S`、あるテキストを追加または削除したコミット）を検索します。グラフを一致したものだけに絞り込むこともできます。<kbd>⌘G</kbd> と <kbd>⇧⌘G</kbd> で次と前の一致に移動します。

- アクセント記号は区別されません: “nguoi” で “người” が見つかります。
- `re:` を付けるとメッセージ全体に対する正規表現を使えます。例: `re:^fix(ed)?:`。

## コマンドパレット

<kbd>⌘K</kbd> で任意のコマンドを実行し、ブランチ、ファイル、コミット、作成者、プルリクエストにジャンプできます。先頭に記号を入力すると、1 種類だけを検索します:

| プレフィックス | 検索対象 |
|---|---|
| `>` | コマンド |
| `/` | ファイル |
| `:` | コミット |
| `@` | 作成者 |
| `#` | プルリクエストとイシュー |

## クイックオープン

<kbd>⌘P</kbd> でリポジトリ内の任意のファイルを開きます。開いたら、<kbd>⌘E</kbd> で編集できます（[ファイルエディタ](/ja/docs/file-editor/)を参照）。
