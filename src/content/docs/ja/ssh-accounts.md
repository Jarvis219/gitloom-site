仕事用と個人用の GitHub アカウントのように、同じホストに複数のアカウントがある場合、SSH アカウントを使うと、どの鍵がどのログインのものか、どのリポジトリがそれを使うかを GitLoom に伝えられます。

## アカウントを設定する

**設定 ▸ アカウント** を開き、*SSH アカウントを追加…* をクリックします。各アカウントについて:

- ホストと、そのホストでのログイン名を入力します。
- 鍵を追加します: *鍵を読み込む…* で `~/.ssh`、ssh-agent、1Password、Secretive の鍵が一覧表示されます。*生成…* で新しい鍵を作ることもできます。
- *使用するリポジトリ* で、そのアカウントを使うオーナーやフォルダを追加する（*フォルダを追加…*）か、そのホストの*デフォルトアカウント*にします。

これで、フェッチ、プル、プッシュ、クローンが正しい鍵を使います。*各リポジトリにも core.sshCommand を書き込み、ターミナルでも同じ動作にする* をオンにすると、リポジトリの `core.sshCommand` が設定され、ターミナルで普通に `git push` しても同じ動作になります。

独自の `core.sshCommand` を持つリポジトリ、`IdentityFile` を指定した `~/.ssh/config` のエイリアス、シェルの `GIT_SSH_COMMAND` には手を加えません。

## ホストエイリアス

`~/.ssh/config` のホストエイリアス（`github-work` など）を使っている場合は、**リポジトリ ▸ リモート… ▸ SSH エイリアス** でリモートをエイリアスに切り替えられます。

## 鍵をローテーションする

鍵の*ローテーション…* は、新しい鍵を作ってアカウントにアップロードし、新しい鍵が使えることを確認してから古い鍵を削除します。

## SSH アカウントとホスティングのサインイン

SSH アカウントが決めるのは、プッシュとプルに使う鍵だけです。プルリクエストや鍵のアップロードのための GitHub や GitLab へのサインインは別のもので、**設定 ▸ ホスティング** にあります（[GitHub](/ja/docs/github/) と [GitLab](/ja/docs/gitlab/) を参照）。
