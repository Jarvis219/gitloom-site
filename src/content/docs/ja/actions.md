GitHub アカウントを追加すると、GitLoom は GitHub Actions の実行をサイドバーの「アクション」グループと、グラフの CI 列の対応するコミットの横に表示します。

![プルリクエストと GitHub Actions の実行が表示されたサイドバーと、開いた実行の build ジョブ](/shots/actions-light.png)

## 実行とログ

実行を開くと、ジョブ、アノテーション、成果物が表示されます。ジョブを開くとログを読めます。ログ表示では、タイムスタンプの表示、行の折り返し、エラーのみの表示ができ、*ログを保存…* でコピーを保存できます。

## 再実行、キャンセル、開始

- *すべてのジョブを再実行*、*失敗したジョブを再実行*、*このジョブを再実行*。
- *実行をキャンセル*。
- *ワークフローを実行…* は、`workflow_dispatch` トリガーを持つワークフローを入力値付きで開始します。
- 実行の成果物をダウンロードします。

フォークからの実行が承認待ちの場合はその旨が表示され、そのプルリクエストが変更するワークフローファイルが一覧表示されて、*承認して実行…* が提案されます。先に変更内容を確認してください。承認したワークフローはリポジトリの設定で実行されます。

## 通知

自分が開始した実行が終わったときに、GitLoom が通知できます。タイミングは **設定 ▸ Git ▸ GitHub Actions ▸ 自分が開始した CI が終了したら通知** で選びます: 通知しない、失敗したときだけ（デフォルト）、常に通知。

> **Note** Actions は GitHub 専用です。GitLab の CI パイプラインにはまだ対応しておらず、「アクション」グループは非表示になります。
