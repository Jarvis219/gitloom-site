GitHub にサインインすると、GitLoom でプルリクエスト、イシュー、Launchpad、Actions を使えます。

## サインインする

**設定 ▸ ホスティング** を開き、*GitHub でサインイン…* をクリックします。*コードを取得* でコードが表示され、*コードをコピーして GitHub を開く* でそれをコピーし、入力するページを開きます。

*トークンを追加…* で個人アクセストークン（fine-grained またはクラシック）を貼り付けることもできます。GitLoom は確認できる範囲でスコープをチェックします。

トークンは macOS のキーチェーンにのみ保存されます。

## できること

- [プルリクエスト](/ja/docs/pull-requests-and-reviews/)の作成、レビュー、マージ。
- [イシュー](/ja/docs/issues/)の作成と閲覧。
- GitHub [Actions](/ja/docs/actions/) の実行を、対応するコミットの横に表示。
- **Launchpad**（<kbd>⇧⌘K</kbd>）は、リポジトリをまたいで対応待ちのプルリクエストとイシューを一覧表示します。
- **ウインドウ ▸ 組織** には、あなたの組織とそのチーム、メンバーが表示されます。
- **リポジトリ ▸ GitHub / GitLab** には、GitHub にリポジトリを作成して `origin` として追加し、現在のブランチをプッシュする*リポジトリを公開…* と、*GitHub でフォーク* があります。
- アカウントや組織からクローン: <kbd>⇧⌘C</kbd> ▸ *アカウントから選択…*。

## コミットのメール

コミットの前に、メールが GitHub アカウントのメールのどれでもない場合は GitLoom が警告します。GitHub がそのコミットをあなたに関連付けられないためです。

## SSH 鍵

サインインは API のためのものです。どのログインでどの SSH 鍵を使ってプッシュするかは [SSH アカウント](/ja/docs/ssh-accounts/)で設定します。**設定 ▸ ホスティング** のアカウントの *SSH 鍵…* では、GitHub 上の鍵を確認し、自分の鍵をアップロードできます。
