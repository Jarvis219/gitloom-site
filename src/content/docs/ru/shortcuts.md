35 сочетаний, помеченных ✎ (все они есть в строке меню), можно изменить в разделе **Настройки ▸ Клавиатура**. Остальные (системные, например <kbd>⌘W</kbd> и <kbd>⌘Z</kbd>, и клавиши, работающие только внутри окна или редактора) фиксированы. Меню всегда показывает текущую клавишу, а всё перечисленное здесь есть и в палитре команд (<kbd>⌘K</kbd>).

## Везде

| Клавиши | Действие |
|---|---|
| <kbd>⌘K</kbd> ✎ | Палитра команд: `>` команды, `/` файлы, `:` коммиты, `@` авторы, `#` pull request и задачи |
| <kbd>⌘P</kbd> ✎ | Быстро открыть файл репозитория |
| <kbd>⌘F</kbd> / <kbd>⌘G</kbd> / <kbd>⇧⌘G</kbd> ✎ | Найти коммиты / следующее совпадение / предыдущее совпадение |
| <kbd>⌘Z</kbd> / <kbd>⇧⌘Z</kbd> | Отменить / повторить последнюю операцию Git (в текстовом поле — отмена ввода) |
| <kbd>⌘T</kbd> ✎ | Новая вкладка |
| <kbd>⌘W</kbd> | Закрыть вкладку |
| <kbd>⌃⇥</kbd> / <kbd>⌃⇧⇥</kbd> ✎ | Следующая / предыдущая вкладка |
| <kbd>⇧⌘C</kbd> ✎ | Клонировать репозиторий |
| <kbd>⌘O</kbd> ✎ | Открыть репозиторий (в новой вкладке, если в этой уже открыт репозиторий) |
| <kbd>⇧⌘R</kbd> ✎ | Показать репозиторий в Finder |
| <kbd>⌥⌘T</kbd> ✎ | Открыть репозиторий в приложении терминала |
| <kbd>⇧⌘K</kbd> | Launchpad (pull request и задачи ваших учётных записей GitHub и GitLab) |
| <kbd>⌥⇧⌘L</kbd> ✎ | Журнал Git (все команды git, выполненные GitLoom) |
| <kbd>⌘,</kbd> | Настройки |
| <kbd>⌘?</kbd> | Справка GitLoom |

## Репозиторий

| Клавиши | Действие |
|---|---|
| <kbd>⇧⌘L</kbd> ✎ | Получить изменения со всех удалённых репозиториев |
| <kbd>⇧⌘↓</kbd> ✎ | Подтянуть |
| <kbd>⇧⌘↑</kbd> ✎ | Отправить |
| <kbd>⌘B</kbd> ✎ | Создать ветку на выбранном коммите |
| <kbd>⇧⌘S</kbd> ✎ | Спрятать все изменения |
| <kbd>⌥⌘Y</kbd> ✎ | История выбранного файла |
| <kbd>⌥⌘B</kbd> ✎ | Blame выбранного файла |
| <kbd>⌘0</kbd> ✎ | Показать или скрыть боковую панель |
| <kbd>⌥⌘0</kbd> ✎ | Показать или скрыть панель подробностей |
| <kbd>⌥⌘L</kbd> ✎ | Переместить панель подробностей вниз / обратно вправо |

## Граф, изменения и diff

| Клавиши | Действие |
|---|---|
| <kbd>↑</kbd> <kbd>↓</kbd> или <kbd>J</kbd> <kbd>K</kbd> | Предыдущий / следующий коммит |
| Щелчок с <kbd>⇧</kbd>, щелчок с <kbd>⌘</kbd> | Выбрать диапазон / несколько коммитов (сравнение, squash, cherry-pick) |
| <kbd>⌘C</kbd> | Копировать SHA выбранного коммита |
| <kbd>⌘Y</kbd> | Быстрый просмотр выбранного файла |
| <kbd>⇧⌘A</kbd> | Проиндексировать все |
| <kbd>⌥⇧⌘A</kbd> | Убрать все из индекса |
| <kbd>⌘↩</kbd> | Закоммитить (в сообщении коммита) |
| <kbd>⌥⌘G</kbd> | Написать сообщение коммита с помощью ИИ (если ИИ включён) |
| <kbd>⌥↑</kbd> / <kbd>⌥↓</kbd> | Предыдущее / следующее изменение в файле |
| <kbd>⌥⌘↑</kbd> / <kbd>⌥⌘↓</kbd> | Предыдущий / следующий файл |

## Редакторы

| Клавиши | Действие |
|---|---|
| <kbd>⌘E</kbd> ✎ | Редактировать открытый файл |
| <kbd>⌘S</kbd> ✎ | Сохранить |
| <kbd>⌥⌘S</kbd> ✎ | Сохранить и проиндексировать |
| <kbd>⌘L</kbd> ✎ | Перейти к строке |
| <kbd>⌥⌘F</kbd> ✎ | Найти и заменить |
| <kbd>⌘/</kbd> ✎ | Закомментировать или раскомментировать выбранные строки |
| <kbd>⌘]</kbd> / <kbd>⌘[</kbd> ✎ | Увеличить / уменьшить отступ выбранных строк |
| <kbd>P</kbd> <kbd>R</kbd> <kbd>E</kbd> <kbd>S</kbd> <kbd>F</kbd> <kbd>C</kbd> <kbd>D</kbd> | Интерактивное перебазирование: pick, reword, edit, squash, fixup, fixup -C, drop для выбранных строк |
| <kbd>⌥↑</kbd> / <kbd>⌥↓</kbd> | Интерактивное перебазирование: переместить выбранные строки (с *Сохранять слияния* — только внутри своей ветки) |
| <kbd>⌘Z</kbd> / <kbd>⇧⌘Z</kbd> | Интерактивное перебазирование: отменить / повторить изменение плана (git не затрагивается, пока вы не начнёте) |
| <kbd>⌘↩</kbd> | Интерактивное перебазирование: начать перебазирование (или сохранить оставшийся план) |
| Esc | Интерактивное перебазирование: закрыть редактор, ничего не делая |
| <kbd>⌥⌘↑</kbd> / <kbd>⌥⌘↓</kbd> | Конфликты слияния: предыдущий / следующий конфликт |
| <kbd>⌘S</kbd> | Конфликты слияния: сохранить и отметить файл как разрешённый |
| <kbd>⌘[</kbd> / <kbd>⌘]</kbd> | История файла: назад / вперёд |

## Терминал

| Клавиши | Действие |
|---|---|
| <kbd>⌃`</kbd> ✎ | Показать или скрыть терминал (скрывает, когда он в фокусе) |
| <kbd>⌃⇧`</kbd> ✎ | Новый сеанс терминала |
| <kbd>⌘+</kbd> / <kbd>⌘−</kbd> ✎ | Крупнее / мельче текст терминала |
| <kbd>⇥</kbd> или <kbd>→</kbd> | Вставить выбранную подсказку |
| <kbd>↑</kbd> <kbd>↓</kbd> | Выбрать подсказку |
| Esc | Закрыть подсказки; в пустой строке приглашения — вернуться к графу (как и при скрытии терминала) |
| Щелчок с <kbd>⌘</kbd> | Открыть то, что под указателем: SHA выбирает коммит, путь открывает файл, URL открывает браузер |
