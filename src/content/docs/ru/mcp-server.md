Другие ИИ-инструменты (Claude Code, Claude Desktop, Cursor, VS Code и другие) могут работать с вашими репозиториями через сервер MCP в GitLoom. Он выключен, пока вы его не включите.

## Включение

В **Настройки ▸ Интеграции ▸ Сервер MCP** выберите для *Внешние ИИ-инструменты могут* один из вариантов:

- *Ничего не делать (выкл.)*;
- *Чтение: статус, история, diff, blame*;
- *Чтение и изменение: также коммит, ветки, стеш, подтягивание, отправка*.

Затем подключите свой инструмент. Для Claude Code скопируйте показанную там строку и выполните её в терминале; она выглядит так:

```sh
claude mcp add gitloom -- "/Applications/GitLoom.app/Contents/Helpers/gitloom-mcp"
```

Для других инструментов скопируйте показанный там JSON в конфигурацию MCP инструмента. GitLoom никогда не редактирует файлы других инструментов. Сервер запускает и команда `gitloom mcp` (см. [Инструмент командной строки gitloom](/ru/docs/the-gitloom-command-line-tool/)).

## Чтение

Инструменты видят статус, историю, diff, blame, ветки и стеши репозиториев, которые открыты или есть в списке недавних на стартовой странице. Пока GitLoom запущен, они также могут спросить, что вы сейчас смотрите, например выбранный коммит или открытый файл. Изменить они ничего не могут.

## Чтение и изменение

Инструменты также могут индексировать, коммитить, создавать ветки и переключаться на них, прятать изменения, получать, подтягивать (только fast-forward) и отправлять — в репозиториях, открытых во вкладке, пока GitLoom запущен. Каждое изменение появляется в окне с именем инструмента и кнопкой *Отменить*, а также в истории операций.

Если включено *Спрашивать перед отправкой*, отправка ждёт вашего ответа в окне репозитория; через 60 секунд она отклоняется.

Ни один инструмент не может выполнить принудительную отправку, сброс, отбрасывание изменений, удаление или переписывание истории.

## Pull request, задачи и CI

Если включено *Pull request, задачи и CI через мои учётные записи*, инструменты могут читать pull request, задачи и запуски CI репозитория через учётную запись, подключённую в GitLoom. В режиме «Чтение и изменение» они также могут открыть pull request для текущей ветки и прокомментировать pull request. Они никогда не видят ваш токен и не могут ничего слить, одобрить или закрыть.

В настройках под *Недавняя активность* показываются последние вызовы.
