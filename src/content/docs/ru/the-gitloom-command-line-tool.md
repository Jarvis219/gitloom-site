Команда `gitloom` открывает GitLoom из терминала. При необходимости она запускает GitLoom.

## Установка

Выберите **GitLoom ▸ Установить инструмент командной строки…**. Будет добавлена ссылка `~/.local/bin/gitloom`, пароль администратора не нужен. Если `~/.local/bin` ещё нет в PATH, GitLoom сообщит об этом; добавьте в `~/.zshrc` строку:

```sh
export PATH="$HOME/.local/bin:$PATH"
```

Чтобы установить команду для всех оболочек, не меняя PATH, используйте *Установить в /usr/local/bin…* в разделе **Настройки ▸ Интеграции ▸ Инструмент командной строки**. macOS запросит пароль администратора. В этом же разделе показано, где установлен `gitloom`.

GitLoom заменяет только собственную ссылку. Если там уже есть другой файл с именем `gitloom`, он не трогается, и GitLoom сообщает об этом.

## Команды

| Команда | Что делает |
|---|---|
| `gitloom [path]` | Открывает репозиторий, содержащий `path` (по умолчанию — текущая папка) |
| `gitloom clone <url> [dir]` | Открывает заполненное окно клонирования |
| `gitloom diff [<rev>]` | Открывает репозиторий, в котором вы находитесь, и выбирает `<rev>` (по умолчанию — строку незакоммиченных изменений) |
| `gitloom log <file>` | Открывает историю файла |
| `gitloom blame <file>[:<line>]` | Открывает blame файла на указанной строке |
| `gitloom mcp` | Запускает MCP-сервер GitLoom через stdio (см. [MCP-сервер](/ru/docs/mcp-server/)) |

Например:

```sh
cd ~/Projects/my-app
gitloom .
gitloom blame src/main.swift:42
```
