GitLoom — бесплатный Git-клиент для Mac. Он запускает ваш собственный `git`, поэтому ваши настройки, хуки, учётные данные и псевдонимы продолжают действовать.

## Требования

- macOS 14 Sonoma или новее, на Mac с Apple silicon.
- git 2.40 или новее. Подойдёт git из Xcode Command Line Tools, как и git из Homebrew.

Чтобы получить git от Apple, выполните в Терминале:

```sh
xcode-select --install
```

При запуске GitLoom сообщит, если не найдёт достаточно новый git. Если git у вас лежит в необычном месте, укажите его в **Настройки ▸ Git**.

## Загрузка

Скачайте `GitLoom.dmg` (42 МБ) из [последнего релиза](https://github.com/Jarvis219/gitloom-site/releases/latest/download/GitLoom.dmg) или в Терминале:

```sh
curl -LO https://github.com/Jarvis219/gitloom-site/releases/latest/download/GitLoom.dmg
```

Откройте образ диска и перетащите GitLoom в папку «Программы».

## Первый запуск

GitLoom ещё не нотаризован Apple, поэтому macOS блокирует первый запуск. Чтобы открыть его:

1. Откройте GitLoom один раз. macOS сообщит, что его нельзя открыть.
2. Перейдите в **Системные настройки ▸ Конфиденциальность и безопасность** и нажмите *Всё равно открыть* рядом с сообщением о GitLoom.
3. Подтвердите. После этого GitLoom открывается как обычно.

Это нужно сделать только один раз. Следующие версии приходят через встроенное обновление GitLoom (см. [Обновления](/ru/docs/updates/)).

## Дополнительно: инструмент командной строки

Выберите **GitLoom ▸ Установить инструмент командной строки…**, чтобы добавить команду `gitloom`: тогда `gitloom .` открывает папку, в которой вы находитесь. См. [Инструмент командной строки gitloom](/ru/docs/the-gitloom-command-line-tool/).
