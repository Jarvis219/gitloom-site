Когда добавлена учётная запись GitHub или GitLab, GitLoom показывает задачи репозитория на боковой панели.

## Создание и просмотр

- **Репозиторий ▸ GitHub / GitLab ▸ Новая задача…** создаёт задачу.
- Задачи репозитория можно просматривать в группе «Задачи» на боковой панели. Их можно фильтровать по метке и вехе.
- В контекстном меню задачи есть *Создать ветку из задачи*, *Открыть в браузере* и *Копировать ссылку*.
- В палитре команд (<kbd>⌘K</kbd>) введите `#`, чтобы найти pull request и задачи.
- **Launchpad** (<kbd>⇧⌘K</kbd>) показывает задачи, ожидающие вас, во всех репозиториях.

## Ветка из задачи

*Создать ветку из задачи* создаёт ветку, названную по задаче. Имя строится по шаблону из **Настройки ▸ Git ▸ Ветка из задачи**, по умолчанию `{type}/{number}-{slug}`, где `{type}` — `fix` или `feat`. Шаблон команды из `.gitloom/team.json` имеет приоритет над вашим.
