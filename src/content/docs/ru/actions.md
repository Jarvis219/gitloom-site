Когда добавлена учётная запись GitHub, GitLoom показывает запуски GitHub Actions в группе ДЕЙСТВИЯ на боковой панели и рядом с их коммитами в столбце CI графа.

![Боковая панель с pull request и запусками GitHub Actions; у одного запуска открыто задание build](/shots/actions-light.png)

## Запуски и журналы

Откройте запуск, чтобы увидеть его задания, аннотации и артефакты. Откройте задание, чтобы прочитать его журнал. Журнал может показывать метки времени, переносить строки или показывать только ошибки, а *Сохранить журнал…* сохраняет копию.

## Перезапуск, отмена и запуск

- *Перезапустить все задания*, *Перезапустить неудачные задания* или *Перезапустить это задание*.
- *Отменить запуск*.
- *Запустить workflow…* запускает workflow с триггером `workflow_dispatch` и его входными параметрами.
- Скачивайте артефакты запуска.

Запуск из форка, ожидающий одобрения, сообщает об этом, перечисляет файлы workflow, которые меняет его pull request, и предлагает *Одобрить и запустить…*. Сначала проверьте изменения: одобренные workflow выполняются с настройками репозитория.

## Уведомления

GitLoom может уведомлять, когда завершается запущенный вами запуск. Выберите, когда именно, в **Настройки ▸ Git ▸ GitHub Actions ▸ Уведомлять о завершении запущенного мной CI**: никогда, только при сбое (по умолчанию) или всегда.

> **Note** Actions работают только с GitHub. Для GitLab конвейеры CI пока не поддерживаются, и группа «Действия» скрыта.
