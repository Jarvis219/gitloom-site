Если добавлена учётная запись GitHub или GitLab (см. [GitHub](/ru/docs/github/) и [GitLab](/ru/docs/gitlab/)), в боковой панели перечислены pull request репозитория (в GitLab — merge request).

![Боковая панель с pull request и запусками GitHub Actions](/shots/actions-light.png)

## Создание pull request

- **Репозиторий ▸ GitHub / GitLab ▸ Создать pull request…** для текущей ветки.
- Или перетащите одну ветку на другую на графе.

Кнопка ▾ рядом с полями «Ревьюеры», «Исполнители» и «Метки» позволяет выбрать значения из списков репозитория. Если ИИ включён, GitLoom может написать описание (см. [Выбор провайдера](/ru/docs/choosing-a-provider/)).

## Ревью

Откройте pull request, чтобы увидеть его diff. Можно комментировать строки, одобрять и сливать. В diff кнопка *Ответить* отвечает в обсуждении ревью, а *Разрешить* закрывает его.

Комментарии к строкам для GitLab пока недоступны.

## Launchpad

**Launchpad** (<kbd>⇧⌘K</kbd>) показывает pull request и задачи, которые ждут вас, во всех репозиториях и учётных записях. Щёлкните элемент правой кнопкой, чтобы открыть его репозиторий, открыть его в браузере или отложить: на 1 час, до завтра, до следующей недели или пока он не изменится.
