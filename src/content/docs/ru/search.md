В GitLoom есть три способа что-то найти: поиск коммитов, палитра команд для всего остального и быстрое открытие файлов.

## Поиск коммитов

<kbd>⌘F</kbd> ищет по сообщениям коммитов, авторам, SHA, путям файлов или изменениям (`-S` — коммиты, которые добавляют или удаляют фрагмент текста). Поиск может оставить на графе только совпадения. <kbd>⌘G</kbd> и <kbd>⇧⌘G</kbd> переходят к следующему и предыдущему совпадению.

- Диакритика не важна: «nguoi» находит «người».
- `re:` принимает регулярное выражение для всего сообщения, например `re:^fix(ed)?:`.

## Палитра команд

<kbd>⌘K</kbd> выполняет любую команду и переходит к веткам, файлам, коммитам, авторам и pull request. Начните с символа, чтобы искать что-то одно:

| Префикс | Что ищет |
|---|---|
| `>` | команды |
| `/` | файлы |
| `:` | коммиты |
| `@` | авторов |
| `#` | pull request и задачи |

## Быстрое открытие

<kbd>⌘P</kbd> открывает любой файл репозитория. Когда он открыт, <kbd>⌘E</kbd> позволяет его редактировать (см. [Редактор файлов](/ru/docs/file-editor/)).
