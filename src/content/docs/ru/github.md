Войдите в GitHub, чтобы пользоваться в GitLoom pull request, задачами, Launchpad и Actions.

## Вход

Откройте **Настройки ▸ Хостинг** и нажмите *Войти через GitHub…*. *Получить код* выдаёт код; *Копировать код и открыть GitHub* копирует его и открывает страницу, где его нужно ввести.

Можно также выбрать *Добавить токен…* и вставить персональный токен доступа — fine-grained или classic. GitLoom проверяет те области доступа, которые может увидеть.

Токены хранятся только в Связке ключей macOS.

## Что можно делать

- Создавать, проверять и сливать [pull request](/ru/docs/pull-requests-and-reviews/).
- Создавать и просматривать [задачи](/ru/docs/issues/).
- Видеть запуски GitHub [Actions](/ru/docs/actions/) рядом с их коммитами.
- **Launchpad** (<kbd>⇧⌘K</kbd>) показывает pull request и задачи, ожидающие вас, во всех репозиториях.
- **Окно ▸ Организации** показывает ваши организации, их команды и участников.
- В **Репозиторий ▸ GitHub / GitLab** есть *Опубликовать репозиторий…* — создаёт репозиторий на GitHub, добавляет его как `origin` и отправляет текущую ветку — и *Форк на GitHub*.
- Клонирование из ваших учётных записей и организаций: <kbd>⇧⌘C</kbd> ▸ *Выбрать из своей учётной записи…*.

## Почта для коммитов

Перед коммитом GitLoom предупреждает, если почта не входит в адреса вашей учётной записи GitHub, потому что GitHub не свяжет такой коммит с вами.

## SSH-ключи

Вход нужен для API. Какой SSH-ключ используется для отправки под каким логином, задаётся в [SSH-аккаунтах](/ru/docs/ssh-accounts/). Кнопка *SSH-ключи…* у учётной записи в **Настройки ▸ Хостинг** показывает ключи на GitHub и может загрузить туда ваши.
