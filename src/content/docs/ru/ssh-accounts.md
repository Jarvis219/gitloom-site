Если у вас несколько учётных записей на одном хосте, например рабочая и личная на GitHub, учётная запись SSH сообщает GitLoom, какой ключ относится к какому логину и какие репозитории его используют.

## Настройка учётной записи

Откройте **Настройки ▸ Учётные записи** и нажмите *Добавить учётную запись SSH…*. Для каждой учётной записи:

- укажите хост и ваш логин на нём;
- добавьте её ключи: *Импортировать ключи…* показывает ключи из `~/.ssh`, ssh-agent, 1Password и Secretive, а *Сгенерировать…* создаёт новый;
- в разделе *Использовать для репозиториев* добавьте владельцев или папки, которые должны её использовать (*Добавить папку…*), или сделайте её учётной записью по умолчанию для хоста.

После этого получение, подтягивание, отправка и клонирование используют нужный ключ. Если включено *Также записать core.sshCommand в каждый репозиторий*, в репозитории задаётся `core.sshCommand`, и обычный `git push` в терминале делает то же самое.

Репозитории с собственным `core.sshCommand`, псевдонимом в `~/.ssh/config` с `IdentityFile` или с `GIT_SSH_COMMAND` в вашей оболочке не затрагиваются.

## Псевдонимы хостов

Если вы используете псевдонимы хостов из `~/.ssh/config` (например, `github-work`), **Репозиторий ▸ Удалённые репозитории… ▸ Псевдоним SSH** переключает удалённый репозиторий на один из них.

## Замена ключа

Кнопка ключа *Заменить…* создаёт новый ключ, загружает его в учётную запись и удаляет старый, как только новый заработает.

## Учётные записи SSH и вход на хостинги

Учётная запись SSH только выбирает, каким ключом отправлять и подтягивать. Вход в GitHub или GitLab для pull request и загрузки ключей — отдельная вещь, он находится в разделе **Настройки ▸ Хостинг** (см. [GitHub](/ru/docs/github/) и [GitLab](/ru/docs/gitlab/)).
