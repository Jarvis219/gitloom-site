GitLoom работает с Git LFS, если на вашем Mac установлен `git-lfs`. Без него GitLoom может показать список файлов LFS, но не может загружать или блокировать их.

## Группа GIT LFS

В репозитории, использующем LFS, на боковой панели есть группа GIT LFS со списком файлов LFS. У файла, который ещё не загружен (на диске только указатель), есть значок загрузки. Заблокированный файл показывает, кто его заблокировал. Дважды нажмите на файл, чтобы открыть его.

В контекстном меню файла есть:

- *Открыть файл*;
- *Загрузить этот файл*, когда здесь только его указатель;
- *Заблокировать* или *Разблокировать*.

## Загрузка всех файлов LFS

**Репозиторий ▸ Дополнительно ▸ Загрузить файлы Git LFS** выполняет `git lfs pull` и загружает большие файлы этого извлечения.

## Отслеживание нового типа файлов

Правый щелчок на изменённом файле в области индексирования ▸ *Отслеживать через LFS (\*.ext)* — чтобы отслеживать все файлы с этим расширением. В репозитории, который уже использует LFS, в том же меню есть *Заблокировать (LFS)* и *Разблокировать (LFS)*.
