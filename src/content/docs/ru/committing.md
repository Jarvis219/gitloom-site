Выберите строку *Незакоммиченные изменения*, проиндексируйте нужное (см. [Индексирование отдельных строк](/ru/docs/staging-single-lines/)), напишите сообщение и нажмите <kbd>⌘↩</kbd>.

## Форма коммита

- *Исправить* меняет последний коммит вместо создания нового. Пока флажок установлен, в списке показываются и файлы, которые этот коммит уже меняет.
- *Соавторы* предлагает людей из недавней истории, включая соавторов, добавленных вами раньше.
- Во время коммита вывод ваших хуков (линтер `pre-commit`, тесты) показывается под сообщением. Если хук всё ещё работает через минуту, GitLoom сообщит об этом и предложит *Остановить*.
- Отдельная строка показывает, от чьего имени вы коммитите. Она предупреждает, если почта не совпадает с [профилем](/ru/docs/profiles/) репозитория или не входит в адреса вашей учётной записи GitHub (GitHub не свяжет коммит с вами).

Если ИИ включён, <kbd>⌥⌘G</kbd> напишет сообщение за вас (см. [Выбор провайдера](/ru/docs/choosing-a-provider/)).

## Настройки сообщения

В **Настройки ▸ Git ▸ Сообщение коммита** можно задать шаблон, с которого начинается форма, и длину заголовка, при которой счётчик становится жёлтым и красным (по умолчанию 50 и 72 символа). Это только предупреждение — ничего не обрезается. Собственный `commit.template` репозитория имеет приоритет над шаблоном.

## Файлы, которые git не показывает

- Если *Игнорировать* файл, который уже отслеживается, GitLoom предложит *Прекратить отслеживание* (`git rm --cached`): файл уйдёт из репозитория со следующим коммитом и останется на диске.
- Правый щелчок на изменённом файле ▸ *Скрыть локальные изменения* — для отслеживаемого файла, который вы меняете намеренно, например локальной конфигурации. Строка над списком файлов показывает, сколько файлов скрыто, а *Показать…* возвращает их.
- На диске Mac переименование `readme.md` в `README.md` в Finder git не замечает. GitLoom замечает и предлагает *Записать переименование*.

## Отмена коммита

<kbd>⌘Z</kbd> отменяет последний коммит или исправление. См. [Отмена и повтор](/ru/docs/undo-and-redo/).
