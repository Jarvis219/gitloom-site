Большинство проблем в GitLoom можно отменить или объяснить. Начните отсюда.

## В репозитории что-то пошло не так

- **Сначала отмените**: <kbd>⌘Z</kbd> или **Правка ▸ История операций…**. Большинство операций можно отменить (см. [Отмена и повтор](/ru/docs/undo-and-redo/)).
- **Коммиты будто бы пропали**: их найдут **Репозиторий ▸ Reflog…** и **Найти потерянные коммиты…** (см. [Восстановление через reflog](/ru/docs/reflog-recovery/)).
- **Застряли в перебазировании или слиянии**: репозиторий, оставшийся посреди такой операции, показывает баннер с кнопками *Продолжить* и *Прервать*, в том числе после перезапуска GitLoom.

## Что сделал GitLoom

**Окно ▸ Журнал Git** (<kbd>⌥⇧⌘L</kbd>) перечисляет все команды git, выполненные GitLoom: репозиторий, команду, время выполнения и код завершения. Сохраняется только командная строка — никогда её вывод, ввод или учётные данные.

Тонкая движущаяся линия под панелью инструментов означает, что git обменивается данными с удалённым репозиторием; наведите на неё указатель, чтобы узнать, что именно происходит. В сообщении о медленной операции есть кнопка *Отменить*.

## Частые проблемы

- **GitLoom не находит git или сообщает, что он слишком старый.** Установите git 2.40 или новее (см. [Установка](/ru/docs/install/)) либо выберите другой git в разделе **Настройки ▸ Git ▸ Исполняемый файл Git**.
- **Хук не находит node, python или линтер.** Добавьте нужные ему папки в *Дополнительный PATH* в разделе **Настройки ▸ Git ▸ Хуки**. Это действует для репозиториев, открытых после изменения.
- **Хук зависает.** Если хук коммита всё ещё работает через минуту, GitLoom сообщает об этом и предлагает *Остановить*. Параметр *Останавливать хук через* в разделе **Настройки ▸ Git ▸ Хуки** останавливает его автоматически (по умолчанию через 10 минут).
- **Используется не тот SSH-ключ.** Настройте [учётные записи SSH](/ru/docs/ssh-accounts/).

## Журналы и кэши

В разделе **Настройки ▸ Дополнительно**:

- *Вести журнал отладки* записывает команды git, выполняемые GitLoom, с их статусом завершения и временем в файл в папке журналов. Пароли и токены в URL скрываются. *Показать папку журналов* открывает её.
- *Очистить кэши…* удаляет pull request и задачи, сохранённые для работы офлайн, и кешированные версии файлов. При необходимости они будут получены заново.
- Если файл настроек не удаётся прочитать, GitLoom переносит его в сторону, запускается с настройками по умолчанию и сообщает об этом здесь.

Если ничего не помогло, [сообщите о проблеме](/ru/docs/report-an-issue/).
