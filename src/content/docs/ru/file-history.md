История файла показывает все коммиты, которые меняли один файл, прослеживая его через переименования.

## Как открыть

Выберите файл и нажмите <kbd>⌥⌘Y</kbd> или выберите **Репозиторий ▸ История файла…**. Если файл не выбран, откроется палитра команд, чтобы вы могли его выбрать. Из терминала её открывает и `gitloom log <file>` (см. [Инструмент командной строки gitloom](/ru/docs/the-gitloom-command-line-tool/)).

## Как читать

Каждая запись — коммит, изменивший файл, с автором и датой. Переименование показывает, откуда файл пришёл. *Отслеживать переименования* можно выключить. Выберите две версии, чтобы увидеть diff между ними.

<kbd>⌘[</kbd> и <kbd>⌘]</kbd> переходят назад и вперёд. Esc возвращает к графу.

## Старые версии

В контекстном меню записи есть:

- *Просмотреть эту версию* или *Открыть эту версию во внешнем редакторе*;
- *Показать в графе*;
- *Blame на этом коммите* (см. [Blame](/ru/docs/blame/));
- *Восстановить файл до этой версии…*. Если в файле есть незакоммиченные изменения, они заменяются; <kbd>⌘Z</kbd> возвращает их.

## Неполные клоны

В неполном (shallow) клоне история заканчивается там же, где клон, и список об этом сообщает.
