Функции ИИ по умолчанию выключены. Включая их, вы выбираете, кто отвечает: облачный провайдер с вашим собственным ключом или модель, работающая на вашем Mac.

## Включение

Откройте **Настройки ▸ ИИ** и включите *Функции ИИ*. Сначала GitLoom объяснит, что и кому будет отправляться.

Выберите *Провайдер*:

- Anthropic, OpenAI, Google Gemini, OpenRouter, Groq, Mistral, DeepSeek, Qwen (Alibaba Cloud), xAI или Together AI;
- Ollama или LM Studio, запущенные локально, — тогда данные не покидают ваш Mac;
- свой провайдер: любой сервер, поддерживающий API Anthropic, OpenAI, Gemini или Ollama, например корпоративный шлюз. Добавьте его через *Добавить свой провайдер…*.

Вставьте API-ключ и нажмите *Сохранить ключ*. Ключи хранятся в Связке ключей. *Проверить* проверяет ключ и загружает модели провайдера, чтобы вы могли выбрать одну.

## Что умеет ИИ

- Писать сообщения коммитов (<kbd>⌥⌘G</kbd>), описания pull request и сообщения стешей.
- Объяснять коммит, ветку или ваши изменения, с уточняющими вопросами.
- Предлагать разрешение конфликтов.

Ничего не отправляется, пока вы не попросите. Без сети кнопки ✨ приглушены; локальная модель продолжает работать.

## Настройка текста

В разделе *Написание* выберите язык (English или Tiếng Việt) и стиль коммитов: Conventional Commits, как в истории репозитория, или свободный.

*Показать настройки по функциям* даёт каждой функции свою модель и *Свои инструкции*. Меню **Шаблоны** рядом с ними подставляет готовый набор — например, Conventional Commits, ID задачи из имени ветки, структуру pull request или ревью только на ошибки, — который затем можно адаптировать под команду.

## Выключение для одного репозитория

Выберите *Выключить ИИ для этого репозитория* в меню ✨ рядом с сообщением коммита. Включить снова можно в **Настройки ▸ ИИ ▸ ИИ выключен для**.

Перед отправкой можно посмотреть точный запрос. См. [Что отправляется](/ru/docs/what-gets-sent/).
