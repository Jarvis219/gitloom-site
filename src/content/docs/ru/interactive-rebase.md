Интерактивное перебазирование переписывает серию коммитов. GitLoom показывает план в виде редактируемого списка; с репозиторием ничего не происходит, пока вы не начнёте.

## Как открыть редактор

- Правый щелчок на коммите ▸ *Интерактивное перебазирование отсюда…*.
- Или бросьте одну ветку на другую и выберите *Интерактивное перебазирование*.
- Если выбрано несколько коммитов, *Интерактивно перебазировать выбранные коммиты…* открывает редактор с выделенными коммитами.

Работает и с самого первого коммита (`--root`). Редактор заменяет граф.

## Редактирование плана

Каждая строка — коммит, самый старый вверху. Задайте его действие в меню или клавишей:

| Клавиша | Действие |
|---|---|
| <kbd>P</kbd> | pick |
| <kbd>R</kbd> | reword |
| <kbd>E</kbd> | edit |
| <kbd>S</kbd> | squash |
| <kbd>F</kbd> | fixup |
| <kbd>C</kbd> | fixup -C |
| <kbd>D</kbd> | drop |

Чтобы изменить порядок, перетаскивайте строки или используйте <kbd>⌥↑</kbd> и <kbd>⌥↓</kbd>. <kbd>⌘Z</kbd> отменяет изменение плана.

- Новые сообщения для reword можно написать заранее, чтобы перебазирование прошло без остановок.
- В меню строки есть *Добавить команду после…*, чтобы выполнить команду в этой точке (строка `exec`, например тест, который останавливает перебазирование при сбое).
- Ветки, построенные поверх перебазируемых коммитов, перемещаются вместе с ними (`--update-refs`), если вы не снимете этот флажок.
- Слияния в диапазоне по умолчанию выпрямляются. Отметьте *Сохранять слияния*, чтобы сохранить их (`--rebase-merges`). Тогда план показывает также, где начинается каждая сторона слияния и где слияние выполняется заново, а коммиты можно перемещать только в пределах своей стороны.

## Запуск или отмена

<kbd>⌘↩</kbd> запускает, Esc отменяет. После этого всё перебазирование — один шаг отмены.

## Быстрые правки

Не открывая редактор:

- выберите несколько соседних коммитов ▸ *Объединить коммиты (N)* (выполняется сразу, сообщения объединяются, самое старое первым; *…и изменить сообщение*, чтобы написать его самому) или *Выбросить коммиты (N)…*;
- правый щелчок на коммите ▸ *Изменить сообщение…*, *Выбросить коммит…*, *Переместить вверх/вниз*.
