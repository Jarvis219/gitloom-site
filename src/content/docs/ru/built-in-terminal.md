<kbd>⌃`</kbd> открывает терминал под графом, в папке репозитория, с вашей собственной оболочкой входа. Граф обновляется, как только в нём завершается команда git.

## Подсказки и ссылки

Пока вы вводите команду git, GitLoom подсказывает подкоманды, ветки, удалённые репозитории и псевдонимы. <kbd>↑</kbd> <kbd>↓</kbd> выбирают подсказку, <kbd>⇥</kbd> или <kbd>→</kbd> вставляют её, а Esc закрывает список.

Нажмите с <kbd>⌘</kbd> на то, что под указателем: SHA выделяет этот коммит, путь открывает файл, а URL открывает браузер.

## Клавиши

| Клавиши | Действие |
|---|---|
| <kbd>⌃`</kbd> | Показать или скрыть терминал (скрывает, если он в фокусе) |
| <kbd>⌃⇧`</kbd> | Новый сеанс терминала |
| <kbd>⌘+</kbd> / <kbd>⌘−</kbd> | Крупнее / мельче текст терминала |
| Esc | В пустой строке приглашения — вернуться к графу |

Если при закрытии вкладки команда ещё выполняется, GitLoom сначала спросит.

## Настройки

В **Настройки ▸ Интеграции ▸ Терминал** есть:

- *Интеграция с оболочкой*: позволяет GitLoom видеть завершение команды (мгновенное обновление, подсказки). Если выключить, это перестанет работать. Ваши dotfiles не редактируются в любом случае.
- *Подсказывать команды git при вводе* — чтобы отключить только подсказки.
- *Прокрутка назад*: сколько строк хранит каждый сеанс (по умолчанию 10 000).
- *Показывать команды git, которые выполняет GitLoom*: приглушённая строка для каждой команды, которую выполняет приложение, — чтобы изучать git.
- *Защищённый ввод с клавиатуры*: пока клавиатура у терминала, другие приложения не могут читать то, что вы вводите.
- *Оболочка* и *Аргументы*: другая оболочка для новых сеансов, например `/opt/homebrew/bin/fish`. Если путь нельзя запустить, используется ваша оболочка входа.

Изменения применяются к новым сеансам терминала. Терминал использует шрифт кода из **Настройки ▸ Оформление**.

## Ваше обычное приложение терминала

<kbd>⌥⌘T</kbd> открывает репозиторий в вашем приложении терминала. Какое приложение — выберите в **Настройки ▸ Интеграции ▸ «Открыть в Терминале» использует**.
