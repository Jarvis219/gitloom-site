Blame показывает для каждой строки файла коммит, который последним её изменил.

## Как открыть

Выберите файл и нажмите <kbd>⌥⌘B</kbd> или выберите **Репозиторий ▸ Blame…**. Из терминала команда `gitloom blame <file>:<line>` открывает его на этой строке (см. [Инструмент командной строки gitloom](/ru/docs/the-gitloom-command-line-tool/)). Из [истории файла](/ru/docs/file-history/) пункт *Blame на этом коммите* показывает файл таким, каким он был тогда.

## Как проследить строку назад

Нажмите на строку, чтобы увидеть её коммит, а затем:

- *Показать коммит* выделяет этот коммит в графе;
- *Blame родителя* показывает blame на момент непосредственно перед этим коммитом — чтобы узнать, кто написал строку до него.

## Параметры

На панели над файлом есть:

- *Игнорировать пробелы*;
- *Тепловая карта* — окрашивает строки по возрасту;
- в меню *Ещё*: *Находить строки, перемещённые внутри файла (-M)* и *Находить строки, скопированные из других файлов (-C)*;
- *Игнорируемые ревизии* — когда в репозитории есть файл `.git-blame-ignore-revs` (или задан `blame.ignoreRevsFile`). Пропускает перечисленные там коммиты, например изменения форматирования.

Для очень длинного файла blame может занять время. GitLoom предупредит об этом заранее, строки будут заполняться по мере нахождения, и вы можете уйти в любой момент.
