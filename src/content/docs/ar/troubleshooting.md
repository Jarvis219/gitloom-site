يمكن التراجع عن معظم المشكلات في GitLoom أو تفسيرها. ابدأ من هنا.

## حدث خطأ ما في المستودع

- **تراجع أولًا**: <kbd>⌘Z</kbd> أو **تحرير ▸ سجل العمليات…**. يمكن التراجع عن معظم العمليات (راجع [التراجع والإعادة](/ar/docs/undo-and-redo/)).
- **تبدو الـcommits مفقودة**: يعثر عليها **المستودع ▸ Reflog…** و**البحث عن commits مفقودة…** (راجع [الاستعادة من الـreflog](/ar/docs/reflog-recovery/)).
- **عالق في rebase أو دمج**: المستودع الذي تُرك في منتصف أحدهما يعرض شريط تنبيه فيه *متابعة* و*إلغاء العملية*، حتى بعد إعادة تشغيل GitLoom.

## رؤية ما فعله GitLoom

يسرد **نافذة ▸ Git Log** (<kbd>⌥⇧⌘L</kbd>) كل أمر git شغّله GitLoom: المستودع، والأمر، والمدة التي استغرقها، ورمز الخروج. لا يُحتفظ إلا بسطر الأمر، وليس بمُخرَجه أو مُدخَله أو بيانات الاعتماد أبدًا.

الخط الرفيع المتحرك أسفل شريط الأدوات يعني أن git يتواصل مع مستودع بعيد؛ مرّر المؤشر فوقه لترى ما يجري. وتحتوي رسالة العملية البطيئة على *إلغاء*.

## المشكلات الشائعة

- **لا يعثر GitLoom على git، أو يقول إنه قديم جدًا.** ثبّت git 2.40 أو أحدث (راجع [التثبيت](/ar/docs/install/))، أو اختر git آخر في **الإعدادات ▸ Git ▸ ملف git التنفيذي**.
- **لا يعثر أحد الـhooks على node أو python أو أداة فحص.** أضف المجلدات التي يحتاجها إلى *PATH إضافي* في **الإعدادات ▸ Git ▸ Hooks**. ينطبق هذا على المستودعات التي تُفتح بعد ذلك.
- **يتوقف أحد الـhooks عن الاستجابة.** الـcommit الذي لا يزال الـhook الخاص به يعمل بعد دقيقة يذكر ذلك ويعرض *إيقاف*. ويوقفه *إيقاف الخطّاف بعد* في **الإعدادات ▸ Git ▸ Hooks** تلقائيًا (بعد 10 دقائق افتراضيًا).
- **يُستخدم مفتاح SSH الخطأ.** أعدّ [حسابات SSH](/ar/docs/ssh-accounts/).

## السجلات وذاكرات التخزين المؤقت

في **الإعدادات ▸ متقدم**:

- يسجّل *كتابة سجل تصحيح* أوامر git التي يشغّلها GitLoom، مع حالة خروجها ووقتها، في ملف داخل مجلد السجلات. تُخفى كلمات المرور والرموز الموجودة في عناوين URL. ويفتحه *إظهار مجلد السجلات*.
- يزيل *مسح ذاكرات التخزين المؤقت…* طلبات pull request والمشكلات المحفوظة للاستخدام دون اتصال ونسخ الملفات المخزّنة مؤقتًا. وتُجلب مجددًا عند الحاجة.
- إن تعذّرت قراءة ملف إعداداتك، ينقله GitLoom جانبًا، ويبدأ بالإعدادات الافتراضية ويذكر ذلك هنا.

إن لم يُفِد شيء من ذلك، [فأبلغ عن مشكلة](/ar/docs/report-an-issue/).
