يمكن لأدوات الذكاء الاصطناعي الأخرى (Claude Code وClaude Desktop وCursor وVS Code وغيرها) العمل مع مستودعاتك عبر خادم MCP في GitLoom. وهو متوقف حتى تشغّله.

## التشغيل

في **الإعدادات ▸ التكاملات ▸ خادم MCP**، اضبط *يمكن لأدوات الذكاء الاصطناعي الخارجية* على أحد الخيارات:

- *عدم فعل شيء (متوقف)*؛
- *القراءة: الحالة والسجل وملفات الـdiff وblame*؛
- *القراءة والتغيير: أيضًا commit والفروع وstash والسحب والدفع*.

ثم اربط أداتك. في Claude Code، انسخ السطر المعروض هناك وشغّله في طرفية؛ وهو يبدو هكذا:

```sh
claude mcp add gitloom -- "/Applications/GitLoom.app/Contents/Helpers/gitloom-mcp"
```

في الأدوات الأخرى، انسخ JSON المعروض هناك إلى إعداد MCP الخاص بالأداة. لا يعدّل GitLoom ملفات أي أداة أخرى أبدًا. ويشغّل الأمر `gitloom mcp` الخادم أيضًا (راجع [أداة سطر الأوامر gitloom](/ar/docs/the-gitloom-command-line-tool/)).

## القراءة

ترى الأدوات الحالة والسجل وملفات الـdiff والـblame والفروع وعمليات الـstash للمستودعات المفتوحة أو الموجودة في قائمة المستودعات الحديثة في صفحة البداية. وما دام GitLoom يعمل، يمكنها أيضًا أن تسأل عمّا تنظر إليه، مثل الـcommit المحدد أو الملف المفتوح. ولا يمكنها تغيير أي شيء.

## القراءة والتغيير

يمكن للأدوات أيضًا التجهيز وإنشاء الـcommits وإنشاء الفروع والتبديل بينها والـstash والجلب والسحب (fast-forward فقط) والدفع، في المستودعات المفتوحة في علامة تبويب، ما دام GitLoom يعمل. يظهر كل تغيير في النافذة مع اسم الأداة وزر *تراجع*، وفي سجل العمليات.

عند تشغيل *السؤال قبل الدفع*، ينتظر الدفع إجابتك في نافذة المستودع؛ وبعد 60 ثانية يُرفض.

لا تستطيع أي أداة الدفع القسري أو reset أو تجاهل التغييرات أو الحذف أو إعادة كتابة السجل.

## طلبات pull request والمشكلات وCI

عند تشغيل *طلبات pull request والمشكلات وCI عبر حساباتي*، يمكن للأدوات قراءة طلبات pull request والمشكلات وتشغيلات CI الخاصة بالمستودع عبر الحساب المرتبط في GitLoom. ومع *القراءة والتغيير*، يمكنها أيضًا فتح طلب pull request للفرع الحالي والتعليق على طلب. ولا ترى الرمز الخاص بك أبدًا، ولا تستطيع دمج أي شيء أو الموافقة عليه أو إغلاقه.

تعرض الإعدادات أحدث الاستدعاءات ضمن *النشاط الأخير*.
