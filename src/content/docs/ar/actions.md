بعد إضافة حساب GitHub، يعرض GitLoom تشغيلات GitHub Actions في مجموعة «الإجراءات» في الشريط الجانبي، وبجانب الـcommits الخاصة بها في عمود CI في الرسم البياني.

![الشريط الجانبي مع طلب pull request وتشغيلات GitHub Actions، ومهمة build لأحد التشغيلات مفتوحة](/shots/actions-light.png)

## التشغيلات والسجلات

افتح تشغيلًا لترى مهامه وتعليقاته التوضيحية وملفاته الناتجة (artifacts). وافتح مهمة لقراءة سجلها. يمكن لعرض السجل إظهار الطوابع الزمنية، أو التفاف الأسطر، أو إظهار الأخطاء فقط، ويحتفظ *حفظ السجل…* بنسخة منه.

## إعادة التشغيل والإلغاء والبدء

- *إعادة تشغيل كل المهام* أو *إعادة تشغيل المهام الفاشلة* أو *إعادة تشغيل هذه المهمة*.
- *إلغاء التشغيل*.
- *تشغيل سير العمل…* يبدأ سير عمل له مُشغِّل `workflow_dispatch`، مع مُدخلاته.
- تنزيل الملفات الناتجة عن تشغيل.

التشغيل القادم من fork والذي ينتظر الموافقة يذكر ذلك، ويسرد ملفات سير العمل التي يغيّرها طلب الـpull request الخاص به، ويعرض *موافقة وتشغيل…*. راجع التغييرات أولًا: سير العمل الذي توافق عليه يعمل بإعدادات المستودع.

## الإشعارات

يمكن لـ GitLoom إشعارك عندما ينتهي تشغيل بدأتَه. اختر متى في **الإعدادات ▸ Git ▸ GitHub Actions ▸ الإشعار عند انتهاء CI الذي بدأتُه**: أبدًا، أو عند الفشل فقط (الإعداد الافتراضي)، أو دائمًا.

> **Note** ميزة Actions مخصّصة لـ GitHub فقط. أما في GitLab فخطوط CI غير مدعومة بعد، وتُخفى مجموعة «الإجراءات».
