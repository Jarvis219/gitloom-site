في GitLoom ثلاث طرق للعثور على الأشياء: البحث للـcommits، ولوحة الأوامر لأي شيء، والفتح السريع للملفات.

## العثور على commits

يبحث <kbd>⌘F</kbd> في رسائل الـcommits أو المؤلفين أو قيم SHA أو مسارات الملفات أو التغييرات (`-S`، أي الـcommits التي تضيف نصًا ما أو تزيله). ويمكنه تصفية الرسم البياني ليقتصر على النتائج المطابقة. وينتقل <kbd>⌘G</kbd> و<kbd>⇧⌘G</kbd> إلى النتيجة التالية والسابقة.

- علامات التشكيل لا تهمّ: «nguoi» يعثر على «người».
- يقبل `re:` تعبيرًا نمطيًا (regular expression) للرسالة كاملةً، مثل `re:^fix(ed)?:`.

## لوحة الأوامر

يشغّل <kbd>⌘K</kbd> أي أمر وينتقل إلى الفروع والملفات والـcommits والمؤلفين وطلبات pull request. ابدأ بحرف للبحث في نوع واحد:

| البادئة | يبحث في |
|---|---|
| `>` | الأوامر |
| `/` | الملفات |
| `:` | الـcommits |
| `@` | المؤلفين |
| `#` | طلبات pull request والمشكلات |

## الفتح السريع

يفتح <kbd>⌘P</kbd> أي ملف في المستودع. وبعد فتحه، يتيح لك <kbd>⌘E</kbd> تحريره (راجع [محرر الملفات](/ar/docs/file-editor/)).
