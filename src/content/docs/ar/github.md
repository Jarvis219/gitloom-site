سجّل الدخول إلى GitHub لاستخدام طلبات pull request والمشكلات وLaunchpad وActions في GitLoom.

## تسجيل الدخول

افتح **الإعدادات ▸ الاستضافة** وانقر *تسجيل الدخول باستخدام GitHub…*. يمنحك *الحصول على رمز* رمزًا؛ ويقوم *نسخ الرمز وفتح GitHub* بنسخه وفتح الصفحة التي تُدخله فيها.

يمكنك أيضًا استخدام *إضافة رمز…* ولصق رمز وصول شخصي (personal access token)، دقيق الصلاحيات أو كلاسيكي. يتحقق GitLoom من النطاقات التي يمكنه رؤيتها.

تُحفظ الرموز في سلسلة مفاتيح macOS فقط.

## ما يمكنك فعله

- إنشاء [طلبات pull request](/ar/docs/pull-requests-and-reviews/) ومراجعتها ودمجها.
- إنشاء [المشكلات](/ar/docs/issues/) وتصفّحها.
- رؤية تشغيلات GitHub [Actions](/ar/docs/actions/) بجانب الـcommits الخاصة بها.
- يسرد **Launchpad** (<kbd>⇧⌘K</kbd>) طلبات pull request والمشكلات التي تنتظرك في كل المستودعات.
- يعرض **نافذة ▸ المؤسسات** مؤسساتك وفرقها وأعضاءها.
- يحتوي **المستودع ▸ GitHub / GitLab** على *نشر المستودع…*، الذي ينشئ المستودع على GitHub ويضيفه باسم `origin` ويدفع الفرع الحالي، وعلى *Fork على GitHub*.
- النسخ من حساباتك ومؤسساتك: <kbd>⇧⌘C</kbd> ▸ *الاختيار من حسابك…*.

## بريد الـcommit الخاص بك

قبل الـcommit، يحذّرك GitLoom حين لا يكون البريد الإلكتروني من عناوين بريد حسابك على GitHub، لأن GitHub لن يربط الـcommit بك.

## مفاتيح SSH

تسجيل الدخول مخصّص للواجهة البرمجية (API). أما مفتاح SSH الذي يدفع لكل حساب فيُحدَّد في [حسابات SSH](/ar/docs/ssh-accounts/). ويعرض *مفاتيح SSH…* الخاص بالحساب في **الإعدادات ▸ الاستضافة** المفاتيح الموجودة على GitHub ويمكنه رفع مفاتيحك.
