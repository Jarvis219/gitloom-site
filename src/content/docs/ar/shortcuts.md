يمكن تغيير الاختصارات الخمسة والثلاثين المعلَّمة بـ ✎، وكلها في شريط القوائم، في **الإعدادات ▸ لوحة المفاتيح**. أما البقية (اختصارات النظام مثل <kbd>⌘W</kbd> و<kbd>⌘Z</kbd>، والمفاتيح التي تعمل داخل ورقة أو محرر فقط) فثابتة. تُظهر القائمة دائمًا المفتاح الحالي، وكل ما هنا موجود أيضًا في لوحة الأوامر (<kbd>⌘K</kbd>).

## في كل مكان

| المفاتيح | الإجراء |
|---|---|
| <kbd>⌘K</kbd> ✎ | لوحة الأوامر: `>` الأوامر، `/` الملفات، `:` الـcommits، `@` المؤلفون، `#` طلبات pull request والمشكلات |
| <kbd>⌘P</kbd> ✎ | فتح سريع لملف في المستودع |
| <kbd>⌘F</kbd> / <kbd>⌘G</kbd> / <kbd>⇧⌘G</kbd> ✎ | البحث عن commits / النتيجة التالية / النتيجة السابقة |
| <kbd>⌘Z</kbd> / <kbd>⇧⌘Z</kbd> | التراجع عن آخر عملية Git / إعادتها (في حقل نص: التراجع عن الكتابة) |
| <kbd>⌘T</kbd> ✎ | علامة تبويب جديدة |
| <kbd>⌘W</kbd> | إغلاق علامة التبويب |
| <kbd>⌃⇥</kbd> / <kbd>⌃⇧⇥</kbd> ✎ | علامة التبويب التالية / السابقة |
| <kbd>⇧⌘C</kbd> ✎ | نسخ مستودع (clone) |
| <kbd>⌘O</kbd> ✎ | فتح مستودع (في علامة تبويب جديدة إن كانت الحالية تعرض مستودعًا) |
| <kbd>⇧⌘R</kbd> ✎ | إظهار المستودع في Finder |
| <kbd>⌥⌘T</kbd> ✎ | فتح المستودع في تطبيق الطرفية لديك |
| <kbd>⇧⌘K</kbd> | Launchpad (طلبات pull request والمشكلات من حساباتك على GitHub وGitLab) |
| <kbd>⌥⇧⌘L</kbd> ✎ | Git Log (كل أوامر git التي شغّلها GitLoom) |
| <kbd>⌘,</kbd> | الإعدادات |
| <kbd>⌘?</kbd> | مساعدة GitLoom |

## المستودع

| المفاتيح | الإجراء |
|---|---|
| <kbd>⇧⌘L</kbd> ✎ | الجلب من كل المستودعات البعيدة |
| <kbd>⇧⌘↓</kbd> ✎ | سحب |
| <kbd>⇧⌘↑</kbd> ✎ | دفع |
| <kbd>⌘B</kbd> ✎ | إنشاء فرع عند الـcommit المحدد |
| <kbd>⇧⌘S</kbd> ✎ | Stash لكل التغييرات |
| <kbd>⌥⌘Y</kbd> ✎ | سجل الملف المحدد |
| <kbd>⌥⌘B</kbd> ✎ | Blame للملف المحدد |
| <kbd>⌘0</kbd> ✎ | إظهار الشريط الجانبي أو إخفاؤه |
| <kbd>⌥⌘0</kbd> ✎ | إظهار لوحة التفاصيل أو إخفاؤها |
| <kbd>⌥⌘L</kbd> ✎ | نقل لوحة التفاصيل إلى الأسفل / إعادتها إلى اليمين |

## الرسم البياني والتغييرات والـdiff

| المفاتيح | الإجراء |
|---|---|
| <kbd>↑</kbd> <kbd>↓</kbd> أو <kbd>J</kbd> <kbd>K</kbd> | الـcommit السابق / التالي |
| النقر مع <kbd>⇧</kbd>، النقر مع <kbd>⌘</kbd> | تحديد نطاق / عدة commits (للمقارنة أو squash أو cherry-pick) |
| <kbd>⌘C</kbd> | نسخ SHA الـcommit المحدد |
| <kbd>⌘Y</kbd> | معاينة سريعة (Quick Look) للملف المحدد |
| <kbd>⇧⌘A</kbd> | تجهيز الكل |
| <kbd>⌥⇧⌘A</kbd> | إلغاء تجهيز الكل |
| <kbd>⌘↩</kbd> | إنشاء الـcommit (في رسالة الـcommit) |
| <kbd>⌥⌘G</kbd> | كتابة رسالة الـcommit بالذكاء الاصطناعي (حين يكون مشغّلًا) |
| <kbd>⌥↑</kbd> / <kbd>⌥↓</kbd> | التغيير السابق / التالي في الملف |
| <kbd>⌥⌘↑</kbd> / <kbd>⌥⌘↓</kbd> | الملف السابق / التالي |

## المحررات

| المفاتيح | الإجراء |
|---|---|
| <kbd>⌘E</kbd> ✎ | تحرير الملف المفتوح |
| <kbd>⌘S</kbd> ✎ | حفظ |
| <kbd>⌥⌘S</kbd> ✎ | حفظ وتجهيز |
| <kbd>⌘L</kbd> ✎ | الانتقال إلى سطر |
| <kbd>⌥⌘F</kbd> ✎ | بحث واستبدال |
| <kbd>⌘/</kbd> ✎ | تعليق الأسطر المحددة أو إلغاء تعليقها |
| <kbd>⌘]</kbd> / <kbd>⌘[</kbd> ✎ | زيادة / إنقاص إزاحة الأسطر المحددة |
| <kbd>P</kbd> <kbd>R</kbd> <kbd>E</kbd> <kbd>S</kbd> <kbd>F</kbd> <kbd>C</kbd> <kbd>D</kbd> | Rebase تفاعلي: ‏pick وreword وedit وsquash وfixup وfixup -C وdrop للصفوف المحددة |
| <kbd>⌥↑</kbd> / <kbd>⌥↓</kbd> | Rebase تفاعلي: نقل الصفوف المحددة (مع *إبقاء عمليات الدمج*، داخل فرعها فقط) |
| <kbd>⌘Z</kbd> / <kbd>⇧⌘Z</kbd> | Rebase تفاعلي: التراجع عن تغيير في الخطة / إعادته (لا يُمَسّ git حتى تبدأ) |
| <kbd>⌘↩</kbd> | Rebase تفاعلي: بدء الـrebase (أو حفظ ما تبقى من الخطة) |
| Esc | Rebase تفاعلي: إغلاق المحرر دون فعل أي شيء |
| <kbd>⌥⌘↑</kbd> / <kbd>⌥⌘↓</kbd> | تعارضات الدمج: التعارض السابق / التالي |
| <kbd>⌘S</kbd> | تعارضات الدمج: حفظ الملف ووضع علامة «تم الحل» عليه |
| <kbd>⌘[</kbd> / <kbd>⌘]</kbd> | سجل الملف: رجوع / تقدّم |

## الطرفية

| المفاتيح | الإجراء |
|---|---|
| <kbd>⌃`</kbd> ✎ | إظهار الطرفية أو إخفاؤها (تُخفى إن كانت في موضع التركيز) |
| <kbd>⌃⇧`</kbd> ✎ | جلسة طرفية جديدة |
| <kbd>⌘+</kbd> / <kbd>⌘−</kbd> ✎ | تكبير / تصغير نص الطرفية |
| <kbd>⇥</kbd> أو <kbd>→</kbd> | إدراج الاقتراح المحدد |
| <kbd>↑</kbd> <kbd>↓</kbd> | اختيار اقتراح |
| Esc | إغلاق الاقتراحات؛ وعند موجّه فارغ، العودة إلى الرسم البياني (وكذلك إخفاء الطرفية) |
| النقر مع <kbd>⌘</kbd> | فتح ما تحت المؤشر: الـSHA يحدّد الـcommit، والمسار يفتح الملف، وعنوان URL يفتح المتصفح |
