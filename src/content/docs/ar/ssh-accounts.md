إن كان لديك عدة حسابات على المضيف نفسه، كحساب GitHub للعمل وآخر شخصي، فإن حساب SSH يخبر GitLoom أي مفتاح يخص أي اسم دخول، وأي المستودعات تستخدمه.

## إعداد حساب

افتح **الإعدادات ▸ الحسابات** وانقر *إضافة حساب SSH…*. ولكل حساب:

- أدخل المضيف واسم الدخول الخاص بك عليه؛
- أضف مفاتيحه: يسرد *استيراد المفاتيح…* المفاتيح من `~/.ssh` وssh-agent و1Password وSecretive، أو ينشئ *توليد…* مفتاحًا جديدًا؛
- ضمن *الاستخدام للمستودعات*، أضف المالكين أو المجلدات التي يجب أن تستخدمه (*إضافة مجلد…*)، أو اجعله *الحساب الافتراضي* للمضيف.

عندئذٍ تستخدم عمليات الجلب والسحب والدفع والنسخ المفتاح الصحيح. ومع تشغيل *كتابة core.sshCommand أيضًا في كل مستودع*، يُضبط `core.sshCommand` الخاص بالمستودع فيفعل `git push` العادي في الطرفية الشيء نفسه.

تُترك كما هي المستودعات التي لها `core.sshCommand` خاص بها، أو اسم مستعار في `~/.ssh/config` مع `IdentityFile`، أو `GIT_SSH_COMMAND` في صدفتك.

## الأسماء المستعارة للمضيف

إن كنت تستخدم أسماء مستعارة للمضيف من `~/.ssh/config` (مثل `github-work`)، فإن **المستودع ▸ المستودعات البعيدة… ▸ اسم SSH المستعار** يحوّل مستودعًا بعيدًا إلى أحدها.

## تدوير مفتاح

ينشئ *تدوير…* الخاص بالمفتاح مفتاحًا جديدًا، ويرفعه إلى الحساب، ويزيل القديم بعد أن يعمل الجديد.

## حسابات SSH وتسجيلات الدخول إلى الاستضافة

حساب SSH يختار فقط المفتاح الذي يدفع ويسحب. أما تسجيل الدخول إلى GitHub أو GitLab، لطلبات pull request ورفع المفاتيح، فمنفصل ويوجد في **الإعدادات ▸ الاستضافة** (راجع [GitHub](/ar/docs/github/) و[GitLab](/ar/docs/gitlab/)).
