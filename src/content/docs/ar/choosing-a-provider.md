ميزات الذكاء الاصطناعي متوقفة افتراضيًا. وعند تشغيلها تختار من يجيب: مزوّد سحابي بمفتاحك الخاص، أو نموذج يعمل على جهاز Mac.

## التشغيل

افتح **الإعدادات ▸ الذكاء الاصطناعي** وشغّل *ميزات الذكاء الاصطناعي*. يشرح GitLoom أولًا ما الذي سيُرسل وإلى من.

اختر *المزوّد*:

- Anthropic أو OpenAI أو Google Gemini أو OpenRouter أو Groq أو Mistral أو DeepSeek أو Qwen (Alibaba Cloud) أو xAI أو Together AI؛
- Ollama أو LM Studio يعملان محليًا، حيث لا تغادر البيانات جهاز Mac؛
- مزوّد مخصص: أي خادم يتحدث واجهة Anthropic أو OpenAI أو Gemini أو Ollama البرمجية، مثل بوابة شركة. أضفه بـ *إضافة مزوّد مخصص…*.

الصق مفتاح API وانقر *حفظ المفتاح*. تُحفظ المفاتيح في سلسلة المفاتيح. ويتحقق *اختبار* من المفتاح ويحمّل نماذج المزوّد، لتختار منها.

## ما يمكن للذكاء الاصطناعي فعله

- كتابة رسائل الـcommit (<kbd>⌥⌘G</kbd>) وأوصاف طلبات pull request ورسائل الـstash.
- شرح commit أو فرع أو تغييراتك، مع أسئلة متابعة.
- اقتراح حلول للتعارضات.

لا يُرسل شيء حتى تطلب. ومن دون اتصال بالشبكة تصبح أزرار ✨ باهتة؛ لكن النموذج المحلي يظل يعمل.

## ضبط الكتابة

ضمن *الكتابة*، اختر اللغة (English أو Tiếng Việt) ونمط الـcommit: ‏Conventional Commits، أو مثل سجل المستودع، أو حر.

يمنح *إظهار الإعدادات لكل ميزة* كل ميزة نموذجها و*تعليمات مخصصة* خاصة بها. وتملأ قائمة **القوالب** بجانبها مجموعة جاهزة، مثل Conventional Commits، أو معرّف تذكرة من الفرع، أو مخطط لطلب pull request، أو مراجعة للأخطاء فقط، ويمكنك بعد ذلك تكييفها لفريقك.

## إيقافه لمستودع واحد

اختر *إيقاف الذكاء الاصطناعي لهذا المستودع* من قائمة ✨ بجانب رسالة الـcommit. وأعد تشغيله في **الإعدادات ▸ الذكاء الاصطناعي ▸ الذكاء الاصطناعي متوقف لـ**.

قبل إرسال أي شيء يمكنك رؤية الطلب كما هو بالضبط. راجع [ما الذي يُرسل](/ar/docs/what-gets-sent/).
