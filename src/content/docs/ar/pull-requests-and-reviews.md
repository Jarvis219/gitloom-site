بعد إضافة حساب GitHub أو GitLab (راجع [GitHub](/ar/docs/github/) و[GitLab](/ar/docs/gitlab/))، يسرد الشريط الجانبي طلبات pull request الخاصة بالمستودع (طلبات الدمج في GitLab).

![الشريط الجانبي مع طلب pull request وتشغيلات GitHub Actions](/shots/actions-light.png)

## إنشاء طلب pull request

- **المستودع ▸ GitHub / GitLab ▸ إنشاء طلب pull request…** للفرع الحالي.
- أو أفلِت فرعًا على فرع آخر في الرسم البياني.

يختار الرمز ▾ بجانب المراجعون والمُكلَّفون والتصنيفات من قوائم المستودع. وعند تشغيل الذكاء الاصطناعي، يمكن لـ GitLoom كتابة الوصف (راجع [اختيار مزوّد](/ar/docs/choosing-a-provider/)).

## المراجعة

افتح طلب pull request لرؤية الـdiff الخاص به. يمكنك التعليق على الأسطر والموافقة والدمج. وفي الـdiff، يردّ *رد* في سلسلة مراجعة ويغلقها *حل*.

التعليقات على الأسطر غير متاحة لـ GitLab بعد.

## Launchpad

يسرد **Launchpad** (<kbd>⇧⌘K</kbd>) طلبات pull request والمشكلات التي تنتظرك في كل المستودعات والحسابات. انقر بالزر الأيمن على عنصر لفتح مستودعه أو فتحه في المتصفح، أو لتأجيله: لمدة ساعة، أو حتى الغد، أو حتى الأسبوع القادم، أو حتى يتغيّر.
