يستطيع GitLoom عرض ملفات مستودعك وتحريرها، فلا يحتاج الإصلاح الصغير إلى تطبيق آخر.

## فتح ملف

- يفتح <kbd>⌘P</kbd> (فتح سريع) أي ملف في المستودع.
- يعرض مفتاح التبديل المراجع/الملفات في الشريط الجانبي شجرة الملفات. ويمكنك هناك أيضًا إنشاء *ملف جديد…* أو *مجلد جديد…*، و*إعادة التسمية…* أو *نقل إلى سلة المهملات*، و*إظهار الملفات المتجاهَلة*.

يُفتح الملف للعرض. اضغط <kbd>⌘E</kbd>، أو انقر *تحرير الملف*، لتحريره. ويعيدك Esc إلى الرسم البياني.

## مفاتيح التحرير

| المفاتيح | الإجراء |
|---|---|
| <kbd>⌘S</kbd> | حفظ |
| <kbd>⌥⌘S</kbd> | حفظ وتجهيز |
| <kbd>⌘L</kbd> | الانتقال إلى سطر |
| <kbd>⌥⌘F</kbd> | بحث واستبدال |
| <kbd>⌘/</kbd> | تعليق الأسطر المحددة أو إلغاء تعليقها |
| <kbd>⌘]</kbd> / <kbd>⌘[</kbd> | زيادة / إنقاص إزاحة الأسطر المحددة |

تتضمن خيارات المحرر *التفاف الأسطر* و*إظهار المسافات وعلامات الجدولة* و*إغلاق الأقواس وعلامات الاقتباس* و*الهامش يقارن مع HEAD*. ويُضبط خط الشيفرة وحجمه في **الإعدادات ▸ المظهر**.

## حين يتغيّر الملف على القرص

إن غيّر تطبيق آخر الملف وأنت لديك تعديلات غير محفوظة، يخبرك GitLoom ويعرض *إبقاء نسختي* أو *إعادة التحميل* أو *مقارنة*. والملف الذي يحتوي على علامات تعارض يذكر أن حفظه لا يجعله محلولًا؛ استخدم [محرر التعارضات](/ar/docs/resolving-conflicts/) لذلك.

ينتظر GitLoom أيضًا قبل تثبيت التحديث ما دام في ملف تغييرات غير محفوظة.

## محرر آخر

يفتح *فتح في محرر خارجي* الملف في التطبيق المختار في **الإعدادات ▸ التكاملات ▸ فتح الملفات باستخدام**. و*أمر مخصص* هناك يتقدّم عليه؛ وتُملأ `$FILE` و`$LINE` و`$REPO`، مثلًا:

```sh
code -g $FILE:$LINE
```
