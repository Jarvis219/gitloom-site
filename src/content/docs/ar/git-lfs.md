يعمل GitLoom مع Git LFS حين يكون `git-lfs` مثبّتًا على جهاز Mac. ومن دونه، يظل GitLoom قادرًا على سرد ملفات LFS لكنه لا يستطيع تنزيلها أو قفلها.

## مجموعة GIT LFS

في المستودع الذي يستخدم LFS، يحتوي الشريط الجانبي على مجموعة GIT LFS تسرد ملفات LFS. والملف الذي لم يُنزَّل بعد، أي لا يوجد منه على القرص سوى المؤشر، تظهر بجانبه أيقونة تنزيل. والملف المقفل يُظهر من قفله. انقر نقرًا مزدوجًا على ملف لفتحه.

انقر بالزر الأيمن على ملف لتحصل على:

- *فتح ملف*؛
- *تنزيل هذا الملف*، حين لا يوجد هنا سوى مؤشره؛
- *قفل* أو *إلغاء القفل*.

## تنزيل كل ملفات LFS

يشغّل **المستودع ▸ متقدم ▸ تنزيل ملفات Git LFS** الأمر `git lfs pull` وينزّل الملفات الكبيرة لهذه النسخة.

## تتبّع نوع جديد من الملفات

انقر بالزر الأيمن على ملف متغيّر في منطقة التجهيز ▸ *التتبع باستخدام LFS ‏(\*.ext)* لتتبّع كل ملف بهذا الامتداد. وفي المستودع الذي يستخدم LFS بالفعل، تحتوي القائمة نفسها على *قفل (LFS)* و*إلغاء القفل (LFS)*.
